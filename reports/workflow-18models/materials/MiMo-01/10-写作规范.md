# 10 - 写作规范

## 一、文风定位

### 整体风格
- **基调**：热血、硬朗、有家国情怀
- **文笔**：简洁有力，不拖泥带水，网文节奏感强
- **叙事**：第三人称全知视角为主，偶尔切入闰土内心独白
- **节奏**：张弛有度，打斗场面快节奏，日常修炼可以稍慢

### 参考作品
- 《龙蛇演义》（梦入神机）——国术流标杆，武打描写参考
- 《精武门》（影视）——热血民族主义基调
- 《霍元甲》（影视）——打洋人的经典叙事
- 鲁迅《故乡》——闰土的形象底色和时代感

## 二、爽点设计规范

### 爽点类型与频率

| 爽点类型 | 描述 | 频率建议 | 示例 |
|----------|------|----------|------|
| **打脸爽** | 有人看不起主角 → 被打脸 | 每5-8章 | 洋人嘲笑中国功夫 → 一拳打飞 |
| **逆袭爽** | 处于劣势 → 绝地翻盘 | 每10-15章 | 被围攻 → 突破境界反杀 |
| **装逼爽** | 低调出场 → 实力碾压 | 每8-10章 | 老头/少年看着不起眼 → 一掌推飞壮汉 |
| **家国爽** | 为中国人争光 | 每15-20章 | 踢碎东亚病夫牌匾 |
| **成长爽** | 突破境界，实力质变 | 每20-30章 | 明劲→暗劲→化劲 |
| **打脸反派** | 反派嚣张 → 被收拾 | 每5-8章 | 买办仗势欺人 → 被闰土教训 |

### 爽点节奏公式
```
压抑（3-5章）→ 蓄力（1-2章）→ 爆发（1章）→ 余韵（1章）
```

**关键原则**：
1. **先压后爽**：每次爽点前必须有足够的压抑/蓄力
2. **递进升级**：爽的程度要越来越大，不能虎头蛇尾
3. **多线穿插**：打脸爽、成长爽、家国爽交替出现，不让读者审美疲劳
4. **每卷大高潮**：每一卷结尾必须有一个超级爽点

## 三、战斗描写规范

### 战斗描写三要素

#### 1. 感官细节（让读者"看到"）
- **视觉**：拳风、身影、血花、碎石
- **听觉**：骨裂声、拳风呼啸、倒地闷响
- **触觉**：拳头的触感、身体的冲击
- **慢镜头**：关键一击时放慢节奏，详细描写

#### 2. 心理活动（让读者"感受到"）
- 主角的判断与决策过程
- 对手的恐惧与震惊
- 围观者的反应

#### 3. 武学原理（让读者"懂"）
- 每一招的发力原理简要说明
- 暗劲/化劲的质感描写
- 武学境界的差距通过战斗体现

### 战斗描写模板
```
[距离感] → [出招] → [发力描写] → [对手反应] → [效果] → [心理/旁观者反应]
```

### 战斗描写示例

❌ **差的写法**：
> 闰土一拳打过去，那个人就飞了出去。

✅ **好的写法**：
> 闰土脚下一蹬，三体式的根基让他像钉子一样扎在地上。崩拳从腰间打出，力从脚底起，过膝盖、经胯骨、传脊背，最后汇聚在拳面上——这一拳，带着形意拳百年传承的力量。
>
> 对面的英国水手还没反应过来，胸口就像被铁锤砸中，整个人倒飞出去三步，重重摔在码头的木板上，滑出一道长长的痕迹。
>
> 码头上一片寂静。
>
> 然后，爆发出震天的欢呼声。

## 四、国术描写术语表

### 常用术语
| 术语 | 含义 | 使用场景 |
|------|------|----------|
| 整劲 | 全身力量整合 | 明劲阶段的标志 |
| 暗劲 | 力量内敛，透入体内 | "打人如挂画" |
| 化劲 | 化解对手力量 | "四两拨千斤" |
| 听劲 | 感知对手力量方向 | 近身缠斗时 |
| 三体式 | 形意拳基本桩功 | 修炼场景 |
| 崩拳 | 形意拳核心拳法 | 闰土的招牌招式 |
| 虎扑 | 形意十二形之一 | 气势型攻击 |
| 铁山靠 | 八极拳招牌招式 | 刘振东的绝招 |
| 穿掌 | 八卦掌核心招式 | 柳如烟的招式 |
| 拳意 | 武术中的"意" | 高境界描写 |

### 感官描写词汇库

**力量感**：铁锤、开山、裂石、雷霆、万钧
**速度感**：闪电、箭矢、疾风、残影、瞬移
**防御感**：铁壁、磐石、铜墙、不可撼动
**内劲感**：透骨、入髓、暗流、绵里藏针
**化劲感**：流水、春风、落叶、云淡风轻
**拳意感**：山岳、大海、苍穹、万物归一

## 五、人物语言规范

### 闰土的语言风格
- **日常**：简短、朴实、不善言辞
- **战斗时**：极少说话，用行动表达
- **关键台词**：偶尔说出震撼人心的话（少而精）
- **穿越者痕迹**：偶尔冒出一两个现代词汇（"这波操作""没毛病"），然后自我纠正

示例：
> "没……没什么。"闰土挠挠头，差点说出"没毛病"三个字，赶紧改口，"我是说，没什么大不了的。"

### 老梁师父的语言风格
- 古怪、刻薄、但藏着关怀
- "你这臭小子，骨头倒是硬"
- "练拳不是用蛮力，是用脑子"
- "国术不只是一拳一脚……"

### 迅哥儿的语言风格
- 聪明、敏感、文绉绉
- "闰土，你变了，但又好像没变"
- "这个国家需要改变，但我不知道该怎么改"

### 反派语言风格
- 洋人：傲慢、蔑视（"Chinese dog""东亚病夫"）
- 买办：谄媚、卑鄙
- 藤田：阴冷、执着（"中国国术，不过如此"）

## 六、节奏控制规范

### 章节节奏类型

| 类型 | 占比 | 描述 | 适合内容 |
|------|------|------|----------|
| 快节奏 | 40% | 2-3个场景切换，信息量大 | 战斗、冲突、追逐 |
| 中节奏 | 35% | 1-2个场景，有对话有描写 | 日常、修炼、社交 |
| 慢节奏 | 25% | 1个场景，深入描写 | 情感、思考、顿悟 |

### 每章结构建议
```
开头钩子（前200字抓人）
    ↓
主体内容（2000-2500字）
    ↓
结尾钩子（最后200字留悬念）
```

### 节奏检查清单
- [ ] 每章是否有至少一个"钩子"（悬念/爽点/转折）？
- [ ] 连续3章是否避免了同类型内容（如连续3章纯修炼）？
- [ ] 高潮前是否有足够的铺垫和压抑？
- [ ] 高潮后是否有适当的"余韵"和过渡？
- [ ] 感情线是否穿插得当，不影响主线节奏？

## 七、禁忌事项

### 绝对禁忌
1. **不写真正的历史人物死亡场景**（可以侧面提及，不正面描写）
2. **不涉及敏感政治话题**（写打洋人可以，但不要涉及具体的国际关系论述）
3. **不写过度血腥的战斗**（国术打斗要"痛快"而不是"残忍"）
4. **不抄袭鲁迅原文**（可以致敬和引用，但不能大段复制）

### 风格禁忌
1. 不要过度使用"之乎者也"的文言文（清末白话为主）
2. 不要让主角变成"圣人"（要有普通人的弱点和情绪）
3. 不要让反派太脸谱化（洋人反派也要有合理的动机）
4. 不要让感情线喧宾夺主（热血爽文，打斗为主）
5. 不要让修炼过程太枯燥（修炼章节要穿插故事和冲突）
