# 核心配角总表

---

## 一、鲁迅（周树人）—— 一生挚友

| 项目 | 内容 |
|------|------|
| **姓名** | 周树人，字豫才，笔名鲁迅 |
| **年龄** | 比闰土大1岁（1881年生） |
| **身份** | 士绅家庭子弟→留学生→文人→文坛巨匠 |
| **外貌** | 少年时瘦弱，戴眼镜。成年后标志性的隶书"一"字胡须，短发，瘦削但目光锐利 |
| **性格** | 少年：好奇、叛逆、同情底层。成年：冷峻、犀利、深情（对朋友）。嘴毒心软 |
| **武学** | 无。纯粹的文人。但他理解闰土的武道，是闰土精神世界的镜子 |

**与主角的关系弧线：**
- **卷一（少年）**：周家少爷与帮工儿子的友谊。鲁迅教闰土读书识字，闰土带鲁迅看海边沙地、月下刺猹。两人约定"一个用笔，一个用拳，都要让中国人站起来"。
- **卷二（分离）**：闰土闯荡江湖，鲁迅去南京求学。两人书信往来渐少。
- **卷三（重逢）**：在日本短暂重逢。鲁迅已弃医从文，闰土已是武林新秀。两人彻夜长谈："你的笔和我的拳，哪个更有用？"没有答案。
- **卷四（并行）**：鲁迅以笔为剑写杂文，闰土以拳为剑护革命。两人偶尔见面，话不多但默契深。
- **卷五（终章）**：1919年鲁迅写《故乡》，以闰土为原型。小说中两人重逢，闰土笑着说："树人，你把我写得太惨了。"鲁迅说："那是旧社会的你。新的你，我写不出来。"

**写作要点：**
- 鲁迅的台词要有"鲁迅味"：冷幽默、反讽、一针见血
- 不能神化鲁迅，要写出他的矛盾、痛苦、自我怀疑
- 鲁迅是全书的"思想锚点"，当闰土迷茫时，鲁迅的话总能点醒他

## 二、师父①：陈守拙（形意门流浪拳师）

| 项目 | 内容 |
|------|------|
| **姓名** | 陈守拙 |
| **年龄** | 约50岁（1895年时） |
| **身份** | 形意门弟子，因得罪权贵流落江湖 |
| **外貌** | 干瘦老头，其貌不扬，但一出手气势惊人。左手缺了小指（旧伤） |
| **性格** | 沉默寡言，嗜酒，看似邋遢实则心思通透。对徒弟严厉到近乎苛刻 |
| **武学** | 形意拳暗劲大成（接近化劲），五行拳、十二形俱全。大枪术精湛 |

**与主角的关系：**
- 卷一中段出现，在绍兴集市上卖艺为生
- 闰土用现代运动科学知识帮他治好了旧伤，陈守拙收他为徒
- 教闰土形意五行拳（劈崩钻炮横）和三体式站桩
- 卷一末段，为保护闰土被洋人枪杀（或重伤后去世）
- 临终遗言："形意拳的根在山西，你以后去河北找李家的后人……"（引出卷二线索）

**写作要点：**
- 典型的"扫地僧"形象，但要有血有肉
- 他的死是闰土第一次经历"失去"，是成长的催化剂
- 死前不能太煽情，要符合老派武人的性格："哭什么，练拳去。"

## 三、师父②：董海川后人·董振堂（八卦门）

| 项目 | 内容 |
|------|------|
| **姓名** | 董振堂（虚构，设定为董海川再传弟子） |
| **年龄** | 约55岁（1898年时） |
| **身份** | 天津八卦门掌门，开镖局为生 |
| **外貌** | 身材高大，圆脸，总是笑眯眯的。但走起八卦步来如鬼魅 |
| **性格** | 豪爽、爱交朋友、好面子。嘴上说"不教外人"，身体很诚实 |
| **武学** | 八卦掌化劲小成，身法天下第一。兼修形意（与形意门有渊源） |

**与主角的关系：**
- 卷二在天津码头结识，闰土帮他打跑了找茬的俄国水手
- 收闰土为记名弟子，教八卦掌走转和身法
- 亦师亦父，弥补了陈守拙去世后闰土缺失的长辈关怀
- 卷二末段，庚子国变中率镖局弟子抵抗联军，重伤（未死，卷三仍有出场）

## 四、妻子：秀姑

| 项目 | 内容 |
|------|------|
| **姓名** | 秀姑（本名李秀兰） |
| **年龄** | 比闰土小2岁 |
| **身份** | 绍兴邻村农家女 |
| **外貌** | 圆脸，大眼睛，手上有做农活的茧子。不是绝世美人，但耐看、温暖 |
| **性格** | 温柔但不软弱，有主见。闰土常年在外，她独自撑起一个家 |

**与主角的关系：**
- 卷一末段/卷二初段成婚（闰土离乡前）
- 不是"花瓶"角色。她代表闰土守护的"家"，是闰土每次受伤后回去的港湾
- 卷三卷四出场不多，但每次出场都是闰土最柔软的时刻
- 卷五中，她支持闰土创办国术馆："你去教天下的孩子，家里的孩子我来教。"

## 五、儿子：水生

| 项目 | 内容 |
|------|------|
| **姓名** | 章水生 |
| **年龄** | 约1905年生（卷三末段） |
| **身份** | 闰土之子，国术传承者 |

**与主角的关系：**
- 鲁迅《故乡》原文中闰土带着儿子水生，小说中延续这一设定
- 水生是闰土"传承"主题的具象化
- 卷五中，水生已长成少年，开始跟闰土学拳
- 终极一战后，闰土把国术馆交给水生："爹打了一辈子，该你们这代人接着练了。"

## 六、精武门创始人：霍元甲原型·霍振东

| 项目 | 内容 |
|------|------|
| **姓名** | 霍振东（以霍元甲为原型，但做艺术加工） |
| **年龄** | 比闰土大3岁 |
| **身份** | 天津静海人，迷踪拳传人，精武门创始人 |
| **外貌** | 中等身材，但浑身肌肉如铁铸。面容刚毅，络腮胡 |
| **性格** | 正直、豪迈、有大局观。"尚武强国"理念的践行者 |
| **武学** | 迷踪拳暗劲大成，兼修多家。实战能力极强 |

**与主角的关系：**
- 卷二在天津结识，英雄惜英雄
- 卷三共同创办精武门（上海），霍振东任门主，闰土任首席教习
- 两人是"战友"关系，共同对抗洋人武道势力
- 霍振东在卷四中被日本人下毒暗害（参考霍元甲真实死因），闰土悲愤

## 七、秋瑾（历史人物）

| 项目 | 内容 |
|------|------|
| **姓名** | 秋瑾，字璿卿，号竞雄 |
| **身份** | 浙江绍兴人，革命党，女权先驱 |
| **武学** | 略通剑术（历史上秋瑾确实习武） |

**与主角的关系：**
- 卷四重要角色。浙江同乡，闰土敬重她的胆识
- 闰土试图营救她（知道历史结局），但失败
- 秋瑾就义是闰土丹劲大成的催化剂
- 秋瑾遗言（小说中）："闰土，别哭。我这一剑，替天下女子先砍了。你那一拳，该替四万万人打了。"

## 八、杨二嫂（鲁迅原文人物）

| 项目 | 内容 |
|------|------|
| **姓名** | 杨二嫂（"豆腐西施"） |
| **身份** | 绍兴镇上开豆腐店的寡妇 |
| **性格** | 泼辣、市侩、爱占小便宜，但本质不坏 |

**与主角的关系：**
- 卷一中的喜剧角色，调节气氛
- 闰土打擂时她是最大声的啦啦队："闰土！揍他！揍那个洋鬼子！"
- 后期偶尔出场，代表"普通百姓"的视角
