# 配角卡

> 配角按出场顺序与重要程度分类，每个角色注明与主角的关系、功能定位与成长弧光。

---

## 一、核心配角

### 1. 陈守义（师父·陈老）

| 项目 | 内容 |
|---|---|
| 身份 | 隐世国术宗师，形意拳嫡传 |
| 年龄 | 魂穿时约六十岁 |
| 外貌 | 干瘦老头，貌不惊人，佝偻着背像个普通老农。但一动手，身如惊龙，眼若寒星。 |
| 境界 | 化劲（当年）→ 退隐后停滞 → 受主角激励重燃心气，晚年窥丹劲 |
| 性格 | 古怪孤僻，嘴硬心软。嗜酒，好骂人，但骨子里是个重情重义的老武人。 |

**背景**：陈守义年轻时是形意门翘楚，一身化劲功夫走遍大江南北罕逢敌手。三十年前曾与洋人拳师交手获胜，却因此惹怒洋人势力，连累师门遭难、师弟惨死。他自责避世，隐居海边村野，誓不再收徒传拳，怕害人害己。

**与主角关系**：主角魂穿后偶然救下醉酒落水的陈老，又被其拳法折服，死皮赖脸求拜师。陈老起初拒绝，后被主角的韧劲与"不认命"的心性打动，破例收徒。师徒关系是全书最动人的情感线——陈老在主角身上看到了当年的自己，主角在陈老身上找到了武道的根与家的暖。

**功能**：
- 主角国术的引路人，负责"教"与"喂劲"。
- 提供门派江湖的历史背景信息。
- 中后期重燃斗志，参与抗敌，是"老一辈国术人不屈精神"的代表。
- 师徒传承的主题载体。

**弧光**：避世老人 → 因徒弟重燃热血 → 晚年出山护道 → 壮烈或安详落幕（留待大纲细化）。

### 2. 周树人（挚友·"迅哥儿"）

| 项目 | 内容 |
|---|---|
| 身份 | 原著"迅哥儿"原型，即青年鲁迅。本书中以少年/青年知识分子形象出现。 |
| 年龄 | 与主角相仿（原著中略长于闰土） |
| 外貌 | 清瘦文秀，目光锐利，常着长衫。 |
| 才能 | 文学、思想，以笔为刀。 |

**与主角关系**：原著中闰土与"迅哥儿"少年是玩伴，中年却隔了"可悲的厚障壁"。本书中穿越者主动维护这段情谊，打破阶层隔阂。二人一武一文，代表救国的两条路——闰土以拳唤醒国人体魄，树人以笔唤醒国人精神。互相理解、互相砥砺。

**功能**：
- 提供"文"的视角，与主角的"武"形成双线映照。
- 原著情怀的核心载体——每次二人重逢都有原著梗与反转。
- 关键时刻提供思想指引与情报资源（知识分子人脉）。
- 不全程在场，但每次出现都推动主题升华。

**设计注意**：使用鲁迅原型需把握分寸——不强行替鲁迅代言名篇金句，而是展现其青年时期的思想成长，与主角互相影响。"希望论"作为全书精神内核，可由二人的对话自然引出，而非生硬照搬。

### 3. 苏婉清（红颜知己）

| 项目 | 内容 |
|---|---|
| 身份 | 新式学堂女学生 → 女子国术教育推动者 |
| 年龄 | 比主角小一两岁 |
| 外貌 | 清秀中带着英气，不缠足，着新式学堂装束，后期习武后身形矫健。 |
| 性格 | 外柔内刚，思想开明，有主见，不服"女子不如男"的旧念。 |

**背景**：绍兴乡绅之女，父亲开明送她进新式学堂。她既受新思想熏陶，又对传统国术有好奇与敬意。与主角相识于第二卷，因一场变故结缘。

**与主角关系**：从"互相看不顺眼"（她嫌他粗鲁，他嫌她娇气）到"志同道合"。她不是需要被保护的花瓶，而是主动投身女子国术教育，与主角并肩推动"国术强国"的理想。感情线走"并肩成长"路线，不喧宾夺主。

**功能**：
- 代表"新女性"与"新思想"，呼应时代主题。
- 女子国术支线，拓宽主角的影响力维度。
- 主角的情感锚点与精神支撑，但绝非附庸。
- 提供乡绅阶层与教育界的人脉资源。

## 二、伙伴与同道

### 4. 水生（大徒弟）

| 项目 | 内容 |
|---|---|
| 身份 | 原著中闰土之子，本书中改为主角后期收的大徒弟 |
| 出场 | 第四卷前后 |

**设计**：原著中水生是沉默木讷的下一代，象征被命运继续碾压的闰土家族。本书中，主角收水生为徒，亲口说"爹没跪，你也别跪"。水生代表传承与希望，是全书"薪火相传"主题的落点。

### 5. 铁柱（同门师兄弟/挚友）

| 项目 | 内容 |
|---|---|
| 身份 | 陈老早年故交之子，后也成为陈老弟子，主角的师弟 |
| 性格 | 憨厚直爽，力气大心思直，对主角忠心耿耿 |
| 功能 | 主角的左膀右臂，插科打诨调节气氛，关键时刻挡刀挡枪的热血兄弟。后期成长为明劲好手，守馆主力。 |

### 6. 林墨（江湖浪子·情报贩子）

| 项目 | 内容 |
|---|---|
| 身份 | 江湖三教九流中人，原镖局镖师，后落魄为情报贩子/中间人 |
| 性格 | 油滑世故，但讲江湖义气。嘴碎，消息灵通。 |
| 功能 | 江湖情报来源，引线人，带主角入江湖。亦正亦邪，偶尔捅娄子，但大是大非不含糊。提供上海滩地下世界的视角。 |

### 7. 赵铁山（八极拳宗师）

| 项目 | 内容 |
|---|---|
| 身份 | 八极拳传人，北方武林领袖之一 |
| 境界 | 暗劲大成 |
| 性格 | 豪爽刚烈，重规矩，起初瞧不起主角"野路子"，后折服。 |
| 功能 | 第四、五卷重要配角，代表传统门派势力。从"门户之见"到"联手抗敌"的转变，是"打破门派壁垒"主题的体现。其八极拳与主角形意拳在擂台有一场精彩切磋。 |

### 8. 孙鹤鸣（太极名家）

| 项目 | 内容 |
|---|---|
| 身份 | 太极拳传人，化劲高手，国术界德高望重的长者 |
| 境界 | 化劲 |
| 性格 | 温和睿智，胸襟开阔，主张国术界团结。 |
| 功能 | 主角暗劲、化劲修炼的指路人之一（非师父，是点拨者）。国术界"桥梁"角色，促成各派联合。代表"开放包容"的国术理想。 |

### 9. 杨圆嫂（市井线人·杨二嫂原型）

| 项目 | 内容 |
|---|---|
| 身份 | 原著"圆规"杨二嫂的改造版，市井中卖豆腐/杂货的精明妇人 |
| 性格 | 刻薄势利，嘴碎如刀，但底层人自有底层人的义气与机灵。 |
| 功能 | 市井情报、烟火气担当。初期是主角的麻烦来源，后发展为不情不愿的线人。关键时刻有出人意料的义举。原著情怀彩蛋。 |

## 三、配角群像（次要角色，简表）

| 角色 | 身份 | 功能 |
|---|---|---|
| 闰土之父 | 佃农 | 主角亲情线，"不让爹再受欺"的动力源 |
| 闰土之母 | 农妇 | 主角软肋，温情担当 |
| 王地主 | 乡间地主 | 第一卷地方反派，压迫佃农 |
| 刘教头 | 绍兴本地拳师 | 第二卷，明劲好手，主角初入江湖的试金石，后化敌为友 |
| 查理·温斯顿 | 英商 | 第三卷，洋人买办代表，设擂挑衅的幕后金主 |
| 藤田一郎 | 日本柔道高手 | 第三卷反派，藤田道场场主 |
| 伊万诺夫 | 俄国大力士 | 第三卷反派，力量型代表 |
| 杜月笙式人物 | 青帮大佬 | 第四卷，上海滩地下势力，与主角既有合作又有博弈 |
| 霍师兄 | 已故国术宗师（致敬霍元甲） | 背景人物，前人打擂抗洋的先驱，主角的精神偶像之一 |

> 注：涉及真实历史人物（如鲁迅、霍元甲等），本书做"虚实结合"处理——借用精神与影响，角色细节虚构化，避免对历史人物的不当演绎。具体尺度在大纲创作时再细化。
