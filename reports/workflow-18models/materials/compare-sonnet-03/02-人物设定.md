# 人物设定

## 一、主角

### 章闰水（乳名闰土）/ 前世：陆战

- **前世身份**：中国现代特种部队退役教官，精通综合格斗、擒拿、军体拳，执行境外任务时中弹殉职，灵魂穿越附身于1893年11岁的绍兴少年闰土（原著中"月夜刺猹"的少年正是他）
- **性格**：外表憨厚朴实（保留原著闰土的农家子弟气质：黑黝黝的圆脸、颈上银项圈、活泼勇敢），内里是历经生死的军人心性——冷静、坚韧、有战术头脑、认死理但不愚忠、重情重义
- **身体底子**：农家少年，常年干活、看瓜刺猹、下海捕鱼，筋骨天然结实，是练武的绝佳"璞玉"之身（原著细节：手捏钢叉向猹尽力刺去——天生的爆发力和胆气）
- **金手指**：
  1. 前世实战经验与"打人的直觉"——套路生疏但实战嗅觉一流，早期靠"糙"打赢"花架子"
  2. 武道识海：能将看过、练过的招式在脑海中反复推演拆解，相当于"过目不忘+反复默练"，大幅压缩传统拳师"十年一小成"的周期，但绝非无师自通，仍需真师传授+苦练打熬
  3. 无系统面板、无数值化——一切进境靠具体的实战场面和身体反应来体现
- **弱点/成长阻力**：读书识字少（原著闰土没读过书），在讲究文墨、涉外交涉的场合会吃亏，这是贯穿全书需要弥补的短板，也给"迅哥儿"提供了帮衬的戏份（教他认字、讲外面的世界）
- **成长弧光**：怕鬼神迷信的乡下孩子 → 敢闯江湖的少年拳师 → 名震租界的国术宗师 → 心怀家国、见证民国建立的一代大侠

## 二、重要配角

### 迅哥儿（周樟寿，即鲁迅原型）

- **关系**：闰土儿时最要好的少爷玩伴，本书情感暗线担当，与原著"我"（迅哥儿）身份呼应
- **人物弧光**：从"少年斜照柴门外"的富家少爷 → 外出求学（日本留学，学医又弃医从文）→ 成为新文化运动的思想旗手
- **在本书中的作用**：
  1. 提供"读书人视角"，弥补闰土文化短板，教他认字明理
  2. 二人关系随时代变迁产生微妙张力（原著"厚障壁"的伏笔）——但本书可以让这层"障壁"因闰土这一世的强大与担当被打破或部分消解，形成暖心反转
  3. 后期可安排闰土在上海/东京暗中保护留学中的迅哥儿，形成"我不能读书明理，但我能用拳头护你周全"的双向奔赴桥段
  4. 结尾呼应《故乡》名句，做主题升华（"我想：希望是本无所谓有，无所谓无的...")

### 师父：燕山（虚构人物，形意拳一脉隐世高手）

- 早年镖师，因看不惯官场腐败隐居绍兴乡下开一间不起眼的武馆兼药铺
- 慧眼识才，见闰土刺猹之勇、根骨之佳而收其为徒
- 教拳同时教做人道理："练拳先练品，欺软怕硬者，学了拳也是祸害"
- 后期在庚子国难中为护乡民牺牲/或隐退，成为主角"为什么而战"的精神源头

### 女主：柳如烟（暂定名，可后续调整）

- 身份可选：镖局大小姐/江湖女侠/教会学校归国女学生（建议采用"镖局女儿"，江湖气与本书基调最贴合）
- 性格：泼辣直爽，武艺不俗（可设计为摔跤/枪法见长，与主角拳法形成互补）
- 感情线：从欢喜冤家的比武打闹开始，历经江湖磨难、租界危局并肩作战，逐渐相知相守
- 功能：给主角提供除"迅哥儿"外的第二重情感支点，也是主角"江湖资源"的重要来源（镖局人脉、江湖消息）

### 杨二嫂（原著彩蛋角色）

- 原著中"豆腐西施"，本书可保留其精明市侩但不失善良的市井小人物形象，作为绍兴乡土篇章的调剂型配角，制造幽默和烟火气

## 三、反派阵营设计

### 前期反派：赵举人（本土劣绅代表）

- 绍兴当地举人老爷，仗着功名鱼肉乡里，闰土一家佃农受其盘剥（呼应原著"多子，饥荒，苛税，兵，匪，官，绅"的苦难根源）
- 作为闰土"练拳第一战"的对手，打脸爽点起手式

### 中期反派：柯尔文神父/杜邦领事（洋人在华既得利益代表，虚构）

- 教会/领事馆背景，仗着治外法权横行租界，手下豢养洋拳师、买办打手
- 与本土买办汉奸勾结，是上海租界篇章的核心反派线

### 中后期反派："铁腕"麦格雷戈（英国拳王，虚构）

- 职业拳击手出身，受雇于洋行/领事馆，是主角在上海擂台最大的宿敌
- 前期数次交手各有胜负，最终决战成为该卷高潮

### 高潮反派：八国联军散兵队长+义和团极端分子（双重压迫的象征）

- 庚子国难篇章，既要打洋人的侵略暴行，也要理性批判义和团盲目排外、滥杀无辜的极端行为，体现主角"不盲目排外，只反抗强权暴力"的价值观深度

### 终极对手（可选，压轴国际线）：俄国大力士/日本柔道宗师

- 南洋/海外篇章的终极擂台对手，代表"世界级武力"，主角战而胜之，完成"扬威海外"的终极爽点
