# 《魂穿闰土：国术镇山河》 小说策划案

## 一、题材定位

- **类型**：晚清民国+国术+热血爽文（起点/番茄风格"历史+功夫流"）
- **体量**：约100万字，预计120-150章（每章6000-8000字）或240-300章（每章3000-4000字，视平台习惯定）
- **卖点标签**：魂穿闰土 / 传统国术 / 打洋人 / 清末民初 / 江湖恩仇 / 热血护国 / 拳打洋教士脚踢洋大人
- **对标作品风格**：《逝去的武林》的写实国术质感 + 网文"废柴逆袭""爽文打脸"节奏 + 《我的1919》《一代宗师》式民族气节

## 二、核心创意（一句话概括）

> 现代特种兵魂穿附身鲁迅笔下"少年闰土"，凭借前世格斗经验与一身不服输的血性，在清末乱世中习练濒临失传的传统国术，从绍兴乡下的"迅哥儿"发小，一路打出乡野、打进江湖、打上擂台、打出国门，用拳头告诉洋人：这身板子，这口气，谁也别想弯下去。

## 三、核心卖点设计（爽文机制）

1. **反差萌开局**：原著里那个"苦得像个木偶人"的中年闰土命运，被现代灵魂强势改写——这一世，闰土绝不苦熬，绝不麻木。
2. **国术写实流+合理升级**：不搞飞天遁地，招式、内劲、桩功都有真实武术原型（形意、八极、心意六合、太极等），练到高深处"寸劲透甲、听劲先手、内劲外放"，热血而不悬浮。
3. **打脸爽点密集**：乡霸→镖局比武→租界洋拳师→教会武力→八国联军散兵→万国格斗擂台→海外唐人街踢馆，冲突层层升级，每卷都有"扬眉吐气"的高潮戏。
4. **家国情怀**：不是单纯个人爽文，而是贯穿"强身即强国"的主线，融入庚子国难、义和团、辛亥革命等大历史节点，让主角的每一次出拳都有历史分量。
5. **原著彩蛋呼应**：借用鲁迅《故乡》的经典意象（月夜刺猹、西瓜地、迅哥儿、五猖会、豆腐西施杨二嫂等），开篇即原著名场面，之后与"迅哥儿"（鲁迅原型）保持发小情谊贯穿全书，暗线呼应"这一次，故乡不再是苦故乡"的主题升华，但不被原著束缚，剧情完全原创展开。

## 四、主角设定速览

- **姓名**：章闰水（乳名闰土），后世人称"闰土爷""铁拳闰土"
- **穿越前身份**：现代特种兵/退役格斗教练"陆战"（详见02-人物设定），因任务殉职，灵魂逆流附身于1893年绍兴少年闰土之身（附身时间点即原著"月夜刺猹"前后，闰土11岁）
- **金手指**：
  - 前世刻入骨髓的实战格斗经验、抗击打意志、战术思维（非武功招式，是"打人的直觉"）
  - "武道识海"空间：能将亲眼所见、亲身习练的拳法内劲进行"拆解-推演-融合"，大幅缩短传统武术"入门-明劲-暗劲-化劲"的苦修周期
  - 无系统面板、无数值化, 全靠"练"字，保持写实质感，升级节点用身体感受和实战表现呈现，不搞数字化装逼
- **成长路线**：明劲（形似）→暗劲（力沉）→化劲（拳无拳意无意）→先天劲（人体潜能巅峨，历史上如孙禄堂等宗师级别），全程有真实武学理论支撑

## 六、后续写作建议（写完策划案后的实操流程）

1. 先完成开篇10万字（约15-20章），验证读者反馈和数据（追读、收藏、评论）
2. 每卷写作前，先细化该卷的"小高潮清单"（每3-5章一个小高潮，每卷一个大高潮）
3. 保持"迅哥儿"这条情感暗线贯穿全书，定期回收原著彩蛋，强化差异化记忆点
4. 历史大事件（甲午、庚子、辛亥）作为剧情脚手架，不需要严格考据，但关键節点要查证增加质感
5. 每10章左右安排一次"文戏"（人物关系、家国情怀、感情线）平衡纯打斗的节奏
