# 主角：闰土（魂穿）

## 基本信息
| 项 | 内容 |
|----|------|
| 姓名 | 闰土（乳名；正式文书或作「闰土」即可） |
| 年龄（开书） | 17 岁（可 ±1） |
| 身份 | 绍兴平桥乡贫农/兼渔猎子弟 |
| 穿越 | 现代男魂（业余格斗+体育生底子，非科学家） |
| 外貌 | 紫红圆脸渐褪，少年骨架拉开；手粗脚大；眉心有晒痕；眼渐由「孩童亮」转「压住的狠」 |
| 标志 | 旧银项圈（父亲留下的念想，可作情感道具）；后来腰带上多一根短棍/刀穗 |

## 性格（双层）
### 原身底色（保留）
- 识天气、懂泥土与潮汛、忍、孝、对「老爷」有骨子里的距离感
- 话不多，但记住一切欺负过家里的脸

### 现代魂叠加
- **尊严敏感**：可穷，不能跪着穷
- **护短**：动家人、动乡里孩子，立刻从隐忍切到进攻
- **务实**：不逞口舌之勇；能用计不用蛮；能借官借势就借
- **学习快**：把拳谱当训练计划，把冲突当战术题
- **底线**：不虐弱、不卖友、不甘当汉奸走狗

一句话人物核：  
> 看起来还是那个叫人「少爷」的闰土，骨子里已经不准备再把命交出去。

## 能力与成长
- **开局**：筋骨好、能跑能扛、会使一点叉/棍赶贼（原身）
- **金手指**：《混元桩劲谱》+ 现代训练直觉
- **短板**：读书少（需秀才朋友补）、不会官话洋话（卷三再补）、初期没钱没人
- **成长弧**：
  1. 为活 → 2. 为家人脸面 → 3. 为乡里一口气 → 4. 为「中国人也能打」→ 5. 为把拳头教给更多人

## 语言风格
- 对乡人：短句、土话气息（点到为止，不堆方言障碍）
- 对官绅：表面恭敬，句句有刺
- 对敌人：少废话，打完再讲
- 内心：现代人吐槽可有，但**不要**动辄「我是穿越的哈哈」破戏；一年内逐渐与身份融合

## 欲望清单（写冲突时用）
1. 立刻：今晚有饭、地不被夺
2. 短期：拳能打死护院、家里不再跪人
3. 中期：在县城有名有地盘，乡里有庇护
4. 长期：让洋人/买办明白「这地界不是随便踩」
5. 终局：国术传人，不只是一个人横

## 主角爽点表演方式
- 先被看不起（粗人、泥腿）→ 当场打脸
- 用最「土」的东西赢最「洋」的人（石锁、木杆、河滩步）
- 赢了不演讲，最多一句：「下次，带枪也没用。」

## 不可做（人设崩坏线）
- 突然变成全能谋士/发明家
- 无故屠乡、杀无辜
- 见强跪、见弱狠
- 恋爱脑压过主线

## 章节出场注意
- 每场战斗前后给一个「身体感觉」（拳风、虎口裂、肋骨疼）增加真实
- 每卷至少一次「回家」：看地、看人、看自己变没变
