# 《闰土国术传》国术体系设定

## 一、国术总纲

### 核心理念
- **国术者，杀人之术也**——不是花架子，不是养生术，是在战场上、在搏杀中取人性命的手段。
- **"功夫"二字，一横一竖**——横的倒下，竖的站着。站着的才有资格说话。
- **打法、练法、演法三分**：练法是根基（慢、稳、养），打法是杀招（快、狠、准），演法是给人看的（花、飘、好看）。三者绝不混为一谈。市面上卖艺的大多只会演法。

### 三大要素
1. **筋骨**：筋骨皮是外在，决定力量和抗击打。
2. **气血**：内气是核心，决定发劲和续航。
3. **精神**：意念胆气是灵魂，决定反应和杀气。
三关通不过，永远是门外汉。

## 二、境界划分（五重境界）

### 第一重：明劲（铜皮铁骨，一拳十响）
- **别称**：拙劲、刚劲、整劲
- **核心标志**：**"明劲落地，响"**——一拳打出，骨节齐鸣，筋骨炸响，有"虎豹雷音"的雏形。力量从脚跟起，顺腿、腰、肩、拳，完整一气。
- **外在表现**：
  - 一拳能打碎青砖、打裂厚木板、打断肋骨；
  - 步法沉稳，落地生根；
  - 肌肉结实如铁，但不是健美那种死肌肉，是活劲；
  - 打沙袋/木桩，声音是"闷雷"不是"脆响"。
- **战力**：可敌三五个壮汉；对阵兵器（刀矛）有风险；对阵枪必死。
- **主角进度**：卷一中后期突破明劲入门（约13岁），卷二突破明劲大成。
- **细分阶段**：
  - 明劲入门（整劲初成，一拳有响）
  - 明劲小成（骨节齐鸣，能开碑裂石）
  - 明劲大成（虎豹雷音初成，一拳可震伤内腑）

### 第二重：暗劲（气贯周身，伤人无形）
- **别称**：内劲、透劲、寸劲
- **核心标志**：**"暗劲透体，伤"**——力不外露，一拳打在身上，外面看着没事，内里五脏俱碎。隔着厚棉袍也能打伤人。
- **外在表现**：
  - 手心、丹田、脚心能发劲，浑身无处不是拳；
  - 可发"寸劲"，一寸距离内爆发出全身力量；
  - 脚步轻盈无声，但落地有千斤；
  - 打在棉花、稻草上能透过去；
  - 暗劲高手能"听"到对手的呼吸、心跳、肌肉微动。
- **战力**：可敌十余人；可对付持短兵器的人；对暗器、弓箭有一定闪避/格档能力；暗劲中后期能闪单发手枪子弹。
- **主角进度**：卷二末突破暗劲入门，卷三中后期达暗劲大成。
- **细分阶段**：
  - 暗劲入门（能透一掌，内伤初显）
  - 暗劲小成（寸劲连发，听劲初成）
  - 暗劲大成（周身无处不发劲，可"听"杀机）

### 第三重：化劲（接化发劲，浑身是拳）
- **别称**：懂劲、化境、沾衣十八跌
- **核心标志**：**"化劲圆融，空"**——对手的力量过来，如拳打空气、如击棉絮，能引、能化、能发。"一羽不能加，蝇虫不能落"，周身皆有感应。
- **外在表现**：
  - "四两拨千斤"不再是形容词，而是真实可做到；
  - 对手一拳打来，不用看，皮肤就能感知气流，身体自动反应；
  - 能借力打力，对手越重摔得越惨；
  - 可在万人中来去自如，不为兵阵所困；
  - 暗劲可透甲（隔着铁甲、棉甲也能震伤内腑）；
  - 听劲达到极致，能"听"到对方扣扳机的微动作。
- **战力**：化劲高手是陆地神仙级存在，可闯刀阵、可斗群狼、可近距离对抗持手枪的人。江湖上化劲高手屈指可数，每一个都是开宗立派的宗师。
- **主角进度**：卷四后期突破化劲入门，卷五达化劲中后段，结局化劲巅峰。
- **细分阶段**：
  - 化劲入门（听劲入微，接化发自如）
  - 化劲小成（周身感应，一羽不加）
  - 化劲大成（气贯周身，可避短枪）
  - 化劲巅峰（半步抱丹，陆地神仙）

### 第四重：抱丹（金丹内结，超凡入圣）
- **别称**：丹劲、金丹、虎豹雷音大成
- **核心标志**：**"抱丹坐胯，神"**——内气在丹田凝练成"丹"（非道教金丹，是气血精神高度凝聚的一种状态），一发动，虎豹雷音大作，周身筋骨齐鸣如炸雷。
- **外在表现**：
  - 速度可超常人肉眼捕捉；
  - 可在枪炮战场上来去如风（但非无敌）；
  - 体力耐力远超常人，连战数日不疲；
  - 一掌可碎石碑，一指可穿铁板；
  - 衰老极慢，可保青春。
- **战力**：抱丹高手在近代几乎是传说级别。全书仅出现1-2位（主角师父/某位隐世宗师），主角结局仅触及边缘（半步抱丹），不完全突破（保持合理性）。
- **主角进度**：结局半步抱丹，作为后续传说。

### 第五重：见神不坏（陆地神仙，破虚空）
- **别称**：罡劲、打破虚空
- **核心标志**：传说中的境界，史书上偶有记载，但近百年无人练成。
- **定位**：本书作为背景传说存在，主角永远不达到此境界，避免玄幻化。作为武道终极追求的象征。

## 三、国术流派（主角修法融合百家）

### 主角的拳路设计
主角不属单一门派，走**"形意为骨、八极为用、太极为化、八卦为步"**的融合路线：

#### 核心主修：形意拳
- **特点**：刚猛无俦，直来直去，"硬打硬进无遮拦"，有"半年打死人"之说，最适合杀伐。
- **五行拳**：劈、崩、钻、炮、横——对应金、木、水、火、土，五种基本劲力。
  - 劈拳（金）：如斧劈物，主攻上盘；
  - 崩拳（木）：如箭离弦，直进中门，最狠；
  - 钻拳（水）：如水钻隙，曲中求直；
  - 炮拳（火）：如炮炸裂，刚猛暴烈；
  - 横拳（土）：如横棍堵截，化防合一。
- **十二形**：龙、虎、猴、马、鼍、鸡、鹞、燕、蛇、骀、鹰、熊——取十二种动物之形。
- **来源**：主角第一位师父（鲁镇隐者）传的是残缺形意。

#### 近身爆发：八极拳
- **特点**："文有太极安天下，武有八极定乾坤"。贴身靠打，爆发力极强。"打人如亲嘴"，贴身后以肘、靠、挤、撞致命。
- **六大开**：顶、抱、担、提、挎、缠。
- **来源**：卷二在绍兴遇八极拳传人学艺。

#### 化劲根本：太极拳
- **特点**：不是公园养生太极，是**陈式/杨式实战太极**，以柔克刚、借力打力、化发合一。
- **核心**：听劲、化劲、引劲、发劲。
- **来源**：卷三/卷四遇太极大师点化（不是拜师，是一次关键交手后的领悟）。

#### 步法身法：八卦掌
- **特点**：走转拧翻，步法如游龙，以走为打，以斜取正。
- **核心**：走圈、掌法、身法拧转。
- **来源**：卷四天津卫遇八卦门宗师。

#### 其他兼修
- **心意把/少林寺武僧**：硬功、抗击打（卷三上海遇）
- **查拳/弹腿**：腿法（卷二绍兴镖师）
- **咏春/南拳**：桥手、短桥发力（江南武师）
- **日本柔术**：反关节、地面技（击败日本柔术家后参悟，化敌为我用）

## 四、兵器设定

### 兵器定位
国术家主要**徒手**，但高境界后兵器是"手臂的延伸"，不依赖但精通：
- **短兵**：匕首、短刀、剑（八卦剑、形意剑）
- **长兵**：六合枪、形意枪、棍、大刀（抗战大刀前身）
- **暗器**：飞镖、石子、金钱镖（暗劲以上才可精准远程）
- **特殊**：大枪（白蜡杆）——战场国术的终极兵器，"月棍年刀一辈子枪"

### 主角兵器
- 前期：一根钢叉（少年闰土的家传钢叉，银圈为辅）
- 中期：一把短匕首/短刀
- 后期：白蜡杆大枪（战场杀敌用）
- 终极：拳（国术最高境界是"无兵器"，拳脚即杀器）

## 五、练功体系（主角成长路线）

### 基础阶段（卷一·鲁镇）
1. **站桩**：三体式（形意根本桩）——每天站3个时辰起，站到大腿发抖、汗透衣衫。
2. **筋骨锻炼**：举石锁、打沙袋、劈柴、挑水、爬树——用农家活+古法练筋骨。
3. **呼吸法**：腹式呼吸→逆腹式呼吸→胎息雏形。
4. **十二形象形功**：模仿动物动作，练身法协调性。
5. **五行拳单练**：一拳一拳磨，每个动作练到万遍以上。

### 入门阶段（卷二·绍兴）
1. **整劲训练**：从"拙力"到"整劲"，把全身力量凝成一股。
2. **发劲训练**：明劲发劲——打千层纸、打沙袋、打树。
3. **实战训练**：巷战、擂台战、与帮会打手搏杀。
4. **八极拳六大开**：贴靠打。
5. **步法训练**：趟泥步、磨胫步。

### 进阶阶段（卷三·上海）
1. **内气培养**：丹田气感，从"力"到"气"。
2. **暗劲透劲**：打棉砂掌、打软物、练透劲。
3. **听劲训练**：蒙眼过招、皮肤感知。
4. **对战各国高手**：实战中提升。
5. **硬功**：铁砂掌、排打功。

### 高阶阶段（卷四·天津）
1. **化劲参悟**：通过与各派宗师交手，领悟"化"的精髓。
2. **融铸百家**：把形意、八极、太极、八卦熔于一炉。
3. **枪术**：大枪白蜡杆，战场杀招。
4. **精神修炼**：胆气、杀气、临阵不乱的定境。

### 巅峰阶段（卷五·战场）
1. **战场杀拳**：国术在战场上的真正应用（不是擂台比武，是一招杀一个）。
2. **极限突破**：生死之间突破化劲中后段。
3. **枪拳合一**：大枪术与拳法合一，千军万马中取上将首级。

## 六、战力对标（方便写作参考）

### 明劲
- 明劲入门≈3-5个普通壮汉 / 1个持短刀的普通江湖人
- 明劲小成≈七八个壮汉 / 1个镖师级武师
- 明劲大成≈十几个壮汉 / 一个捕头/武馆教头

### 暗劲
- 暗劲入门≈30个壮汉 / 普通帮派香主 / 日本普通浪人
- 暗劲小成≈一二十个持兵器的武师 / 日本柔术二段 / 西洋职业拳击手
- 暗劲大成≈镖行总镖头级 / 日本柔术名家 / 俄国大力士 / 化劲以下无敌

### 化劲
- 化劲入门≈开宗立派宗师 / 可闯百人刀阵 / 近距避手枪
- 化劲小成≈一代宗师 / 千军辟易
- 化劲大成≈传说级 / 万人敌（非真杀万人，是可在万军中进退）
- 化劲巅峰（主角结局）≈近神 / 抱丹以下无敌 / 战场上可来去

## 七、国术描写原则（写作时遵守）

1. **招式有名，发劲有感**：每次出手要写清楚用的是什么招式、什么劲，不能模糊。
2. **物理感**：一拳打出要有重量感、速度感、声音感。被打中的人要有具体的伤（口吐鲜血、肋骨断裂、飞出几丈）。
3. **节奏感**：打斗要分节奏——试探、换招、险象、爆发、一击必杀。不要一上来就全力。
4. **杀招不华丽**：真正杀人的招式往往很朴素——一拳打心口、一掌拍天灵、一肘击咽喉。花架子是演法。
5. **受伤真实**：主角也会受伤、会疼、会流血，不是金刚不坏。每次战斗都有消耗。
6. **境界差距明显但可跨越**：高一个境界通常碾压，但主角凭借不要命的打法、现代格斗理念、巧劲，可在小级差下越级挑战，但大级差（暗劲打化劲）必须靠机缘和智取，不能硬刚。
