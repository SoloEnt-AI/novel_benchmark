# 第四卷：实业救国

## 卷概述

| 项目 | 内容 |
|------|------|
| **字数** | 20万字（约60章） |
| **时间** | 1905-1912年 |
| **地点** | 全国+政治舞台 |
| **主角年龄** | 27-34岁 |
| **武学境界** | 丹劲→罡劲 |
| **核心主题** | 商业帝国、参与革命 |

---

## 第一幕：商业帝国（第201-225章）

### 第201-203章：银行创办
- 主角创办闰氏银行
- 为民族企业提供低息贷款
- 打破洋行对金融的垄断

### 第204-206章：铁路投资
- 主角投资铁路建设
- 与洋行争夺路权
- 民族工业的命脉

### 第207-209章：军工厂
- 秘密创办军工厂
- 为革命党提供武器
- 暗中支持革命事业

### 第210-212章：洋行反击
- 洋行联盟全面反击
- 价格战、暗杀、政治打压
- 主角陷入困境

### 第213-215章：商战巅峰
- 主角以现代商业手段反击
- 联合本土商帮，形成合力
- 商战进入白热化

### 第216-218章：吞并洋行
- 主角趁洋行内部分裂
- 逐一吞并多家洋行
- 商业帝国版图扩大

### 第219-220章：沈清韵生子
- 沈清韵生下长子
- 主角事业家庭双丰收
- 人生巅峰

### 第221-225章：山田樱子叛族
- 山田樱子因爱慕主角
- 与日本家族决裂
- 来到中国追随主角

---

## 第二幕：革命暗线（第226-250章）

### 第226-228章：同盟会
- 主角秘密加入同盟会
- 提供资金和武力支持
- 成为革命党的幕后金主

### 第229-231章：萍浏醴起义
- 1906年，同盟会第一次起义
- 主角派出武林高手支援
- 起义虽败，但救出部分人员

### 第232-234章：影佐出场
- 日本特务影佐出场
- 奉命暗杀主角和革命党人
- 主角与日本特务机关的对抗开始

### 第235-237章：暗杀与反杀
- 影佐多次派人暗杀主角
- 主角以丹劲实力轻松化解
- 反杀多名日本特务

### 第238-240章：黄花岗起义
- 1911年4月，黄花岗起义
- 主角提供武器和人员支援
- 起义失败，但影响深远

### 第241-243章：光绪慈禧去世
- 1908年，光绪帝和慈禧太后相继去世
- 政局动荡，主角趁机扩张
- 商业帝国进一步巩固

### 第244-250章：罡劲突破
- 主角在一次生死搏杀中突破罡劲
- 内气外放，隔空伤人
- 成为当世最强者之一

---

## 第三幕：辛亥革命（第251-275章）

### 第251-253章：武昌起义
- 1911年10月10日，武昌起义爆发
- 各省纷纷独立
- 清朝统治摇摇欲坠

### 第254-256章：上海光复
- 主角率武林人士参与上海光复
- 攻克清军据点
- 上海光复，主角立下大功

### 第257-259章：击杀清将
- 主角在战斗中击杀清军将领
- 展现罡劲的恐怖实力
- 名震全国

### 第260-262章：民国成立
- 1912年1月1日，中华民国成立
- 主角被邀请参政

### 第263-265章：清帝退位
- 1912年2月，清帝退位
- 主角感慨万千
- "这一世，我改写了一些历史"

### 第266-268章：袁世凯
- 袁世凯就任总统
- 主角看出其野心
- 保持警惕

### 第269-271章：霍元甲中毒
- 霍元甲被日本特务下毒
- 主角及时救治，保住性命
- 日本特务的阴谋曝光

### 第272-275章：影佐的复仇
- 影佐亲自出手，挑战主角
- 丹劲对罡劲，实力悬殊
- 主角轻松击败影佐，但未取其性命

## 第四卷高潮：上海光复

### 战斗描写要点
```
主角一掌拍出，罡气如刀。
清军据点的城门轰然碎裂。
"杀！"武林人士蜂拥而入。
主角身形如电，所过之处，清军纷纷倒地。
"罡劲！"清军将领脸色大变。
主角一步踏出，气势如山岳。
"今日，上海光复！"
一掌拍出，清军将领口吐鲜血，倒飞而出。
城头升起革命旗帜，百姓欢呼雀跃。
```

## 第四卷写作要点

1. **节奏**：商战与武斗双线并行
2. **爽点**：商业帝国成型，参与历史大事件
3. **革命**：主角暗中支持革命，但不改变历史大势
4. **感情**：山田樱子的追随，感情线收束
5. **历史**：辛亥革命要写出热血沸腾的感觉
