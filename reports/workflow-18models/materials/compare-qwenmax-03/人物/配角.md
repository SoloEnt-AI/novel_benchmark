# 《闰土：国术宗师》配角设定

## 一、师父：李存义

### 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 李存义 |
| **身份** | 形意拳大师，中华武士会创始人 |
| **年龄** | 出场时50岁 |
| **实力** | 化劲巅峰 |
| **出场** | 第一卷前期 |
| **特点** | 刚正不阿、武学宗师、爱国情怀 |

### 外貌描写

```
身材中等，但骨架宽大，站在那里如同一座铁塔。
面容刚毅，颧骨高耸，一双虎目炯炯有神。
蓄着短须，一身灰色长衫，腰板挺直如松。
举手投足间，带着武林宗师的威严。
```

### 性格设定
- **刚正不阿**：嫉恶如仇，不与恶势力同流合污
- **武学宗师**：对武学有极高追求，严格要求弟子
- **爱国情怀**：忧国忧民，支持革命
- **严厉慈爱**：对徒弟要求严格，但内心关爱

### 与主角关系
- **师徒**：传授主角形意拳基础
- **伯乐**：看出主角天赋，倾囊相授
- **引路人**：引领主角进入武林

### 人物结局
- 第三卷：在与洋人高手对决中重伤
- 第四卷：将毕生武学传给主角后去世
- 遗愿：希望主角振兴国术，扬我国威

---

## 二、好友：鲁迅（周树人）

### 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 周树人（笔名鲁迅） |
| **身份** | 文学家、思想家 |
| **年龄** | 比主角大5岁 |
| **出场** | 第一卷（青梅竹马） |
| **特点** | 思想犀利、文笔如刀、忧国忧民 |

### 外貌描写

```
瘦削的面容，浓密的胡须，一双眼睛深邃如渊。
常穿一件黑色长衫，头发竖立如刺猬。
手里总夹着一支烟，烟雾缭绕中，目光如电。
```

### 性格设定
- **思想犀利**：看问题一针见血
- **文笔如刀**：用文字唤醒国人
- **忧国忧民**：弃医从文，以笔为武器
- **重情重义**：与主角是青梅竹马的好友

### 与主角关系
- **青梅竹马**：原著中的"迅哥儿"
- **思想盟友**：主角用武力和商业救国，他用文字救国
- **殊途同归**：两人选择不同的道路，但目标一致

### 经典对话
```
鲁迅："闰土，你习武救国，我以笔救国，孰优孰劣？"
主角："迅哥儿的笔，能唤醒千万人的灵魂。我的拳，只能打倒眼前的敌人。殊途同归罢了。"
鲁迅大笑："说得好！那我们便各尽其力，共赴国难！"
```

## 三、战友：霍元甲

### 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 霍元甲 |
| **身份** | 武术家，精武体育会创始人 |
| **年龄** | 比主角大15岁 |
| **实力** | 化劲巅峰 |
| **出场** | 第二卷 |
| **特点** | 侠义精神、打破门户、强身健体 |

### 外貌描写

```
身材高大，虎背熊腰，站在那里如同一座山岳。
面容方正，浓眉大眼，一脸正气凛然。
常穿白色练功服，腰间系着黑色腰带。
```

### 性格设定
- **侠义精神**：路见不平，拔刀相助
- **打破门户**：不拘泥于门派之见
- **强身健体**：提倡全民健身
- **爱国情怀**：与洋人比武，扬我国威

### 与主角关系
- **战友**：共同创办精武体育会
- **亦师亦友**：武学上互相切磋
- **知己**：共同的理想和抱负

### 人物结局
- 第三卷：被日本特务下毒，主角救下
- 第四卷：退居幕后，专心武学传承
- 成为武林传说

## 八、配角使用原则

1. **服务主角**：配角的存在是为了衬托主角
2. **各有特色**：每个配角都有独特的性格和作用
3. **合理出场**：不要一次性出场太多配角
4. **有始有终**：重要配角要有完整的结局
5. **历史真实**：真实历史人物要符合历史形象
