# 《闰土：国术宗师》主角设定

## 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 闰土（原名章闰水，鲁迅《故乡》原型） |
| **穿越前身份** | 现代格斗爱好者、某公司高管（35岁） |
| **穿越后身份** | 绍兴农村少年（12岁起步） |
| **穿越时间** | 1890年（光绪十六年） |
| **性格** | 沉稳老练、深藏不露、心思缜密 |
| **外号** | "铁项圈"（少年）、"闰宗师"（后期） |

## 外貌描写

### 少年期（12-16岁）
```
紫色的圆脸，头戴一顶小毡帽，颈上套一个明晃晃的银项圈。
身材虽不高大，但筋骨结实，站在那里如同一株小松树。
一双眼睛深邃明亮，与同龄孩子的懵懂不同，透着超越年龄的沉稳。
```

### 青年期（17-25岁）
```
身高七尺有余，肩宽腰窄，虎背熊腰。
面容坚毅，颧骨略高，一双鹰眼精光内敛。
穿一件青色长衫，看起来像个读书人，但举手投足间隐含杀机。
颈上的银项圈已隐入衣内，只在运功时隐隐发光。
```

### 壮年期（26-35岁）
```
身材挺拔如松，气势渊渟岳峙。
面容棱角分明，双目如电，却内敛如渊。
一袭灰色长衫，布鞋布袜，朴素如老农。
但任何人见了他，都不敢小觑——那是大宗师的气度。
```

## 性格设定

### 核心性格：沉稳老练

#### 表现
1. **遇事不慌**：泰山崩于前而色不变
2. **深藏不露**：不轻易展露实力，一鸣惊人
3. **心思缜密**：走一步看三步，运筹帷幄
4. **隐忍克制**：能忍常人不能忍，但触底线必反击
5. **重情重义**：对亲人朋友极好，但有原则

#### 内心独白风格
```
（表面微笑）"承让了。"
（内心）这人的暗劲还差得远，不过是个明劲巅峰的货色。
若是全力出手，一招就能废了他。但现在不是时候，先探探他背后是谁。
```

### 性格成长
| 阶段 | 年龄 | 性格特点 |
|------|------|----------|
| 初期 | 12-16 | 谨慎低调，暗中积蓄力量 |
| 中期 | 17-25 | 锋芒渐露，有勇有谋 |
| 后期 | 26-35 | 大宗师风范，举重若轻 |

## 金手指设定

### 1. 现代格斗知识
- **内容**：现代搏击理论、人体解剖学、运动力学
- **优势**：
  - 理解国术原理更快
  - 能将现代训练方法融入传统修炼
  - 对敌时能精准攻击要害
- **限制**：需要配合身体修炼才能发挥作用

### 2. 现代商业头脑
- **内容**：现代企业管理、营销策略、资本运作
- **优势**：
  - 商业嗅觉敏锐
  - 能建立现代化的企业体系
  - 在商业竞争中碾压对手
- **限制**：需要考虑时代背景，不能太超前

### 3. 银项圈传承（核心金手指）
- **来历**：祖上传下的神秘物件
- **秘密**：
  - 内藏一套上古内家拳功法《混元真解》
  - 附带一份藏宝图（前期不揭开，后期揭秘）
  - 可加速修炼，突破瓶颈
- **激活条件**：穿越者的灵魂+特定的修炼法门
- **限制**：
  - 功法需要循序渐进，不能一步登天
  - 每次突破都需要实战磨砺
  - 藏宝图线索分散，需要时间收集

## 武学路线

### 修炼历程

| 阶段 | 年龄 | 境界 | 修炼内容 | 代表战绩 |
|------|------|------|----------|----------|
| 筑基 | 12-14 | 入门→明劲 | 形意拳基础、银项圈传承 | 打败村中恶霸 |
| 小成 | 14-17 | 明劲→暗劲 | 形意拳进阶、内功入门 | 击杀地方恶霸头目 |
| 中成 | 17-22 | 暗劲→化劲 | 太极拳、八卦掌 | 击败洋人拳王 |
| 大成 | 22-28 | 化劲→丹劲 | 融合各家、自创武学 | 击杀日本武道高手 |
| 巅峰 | 28-35 | 丹劲→罡劲 | 自创"闰氏国术" | 横扫欧美高手 |
| 至高 | 35 | 打破虚空 | 天人合一 | 大结局 |

### 代表招式
1. **形意崩拳**：入门招牌，刚猛无比
2. **太极化劲**：中期防御，以柔克刚
3. **八卦游身**：身法如鬼魅
4. **混元一气**：银项圈传承的绝招
5. **闰氏十三式**：自创武学，集百家之长

## 人物弧光

### 成长主线
1. **初期**：生存（在这个时代活下去）
2. **中期**：崛起（成为一方霸主）
3. **后期**：救国（实现民族复兴的理想）

### 内心变化
- 从"旁观者"到"参与者"
- 从"利己"到"利国"
- 从"小人物"到"大宗师"

### 人物主题
**以武入道，以商救国，以一人之力，改写一个时代的命运。**
