# 配角与反派卡

按阵营与登场顺序整理。每个角色标注**功能**（在剧情中的作用）与**结局**，确保无冗余角色、无遗漏功能。

---

## 一、盟友阵营

### 1. 闰土之父·章老爹

| 项目 | 内容 |
|------|------|
| **身份** | 绍兴乡下农民，闰土之父 |
| **性格** | 老实、怯懦、逆来顺受，典型旧式农民 |
| **功能** | 主角穿越后的第一个情感锚点。他的"弱"反衬主角的"强"；他的受欺压是主角第一次出拳的动机。后期是主角的人性温情锚点——主角变强后护着他，让他过上好日子。 |
| **结局** | 存活至全书结尾。见证儿子成为一代宗师，老怀大慰。是全书少数"好人有好报"的温暖角色。 |

### 2. 乡间老拳师·刘三爷

| 项目 | 内容 |
|------|------|
| **身份** | 隐居绍兴乡下的老拳师，义和团余部，年逾七旬 |
| **境界** | 化劲（年老体衰，实力降至暗劲巅峰） |
| **性格** | 沉默寡言，眼神锐利，身怀绝技而隐忍不露 |
| **功能** | 主角的引路人。传承手札主人是他的师兄。他指点了主角国术门径，讲述了师兄抗洋殉国的往事，点燃主角使命感。第一卷情感高潮的制造者——临终嘱托。 |
| **结局** | 卷一末病逝（旧伤复发）。临终将手札来历告知主角，嘱托"走出去，莫让国术断了脊梁"。其死是主角离开乡野、踏上征途的直接动因。 |

### 3. 形意门馆主·戴拳师（戴沧海）

| 项目 | 内容 |
|------|------|
| **身份** | 上海形意门馆主，主角正式拜的师父 |
| **境界** | 化劲入门（全书后期未再突破） |
| **性格** | 方正刚直，不苟言笑，极重规矩与气节。对徒弟严厉，内心却极护短。 |
| **功能** | 主角国术根基的奠基人，亦师亦父。师徒线是全书最重要的情感线。其武学理念影响主角一生。卷四被害，是主角化劲→丹劲破境的核心驱动。 |
| **结局** | 卷四中段被黑龙会宫本设计害死（或伤重不治）。临终传主角形意门核心心法，将门派托付主角。其死引爆卷四"血海深仇"主线。 |

### 4. 八极门·霍拳师（霍铁山）

| 项目 | 内容 |
|------|------|
| **身份** | 上海八极门馆主，主角擂台对手变挚友 |
| **境界** | 暗劲巅峰→化劲（后期突破） |
| **性格** | 暴烈刚直，直肠子，嗓门大，重义气。典型的北方汉子。 |
| **功能** | 主角的挚友与性格互补。擂台上是对手，擂台下是过命兄弟。负责"热血兄弟情"戏份，也提供江湖情报与援手。卷四后与主角并肩作战。 |
| **结局** | 存活至结尾。主角开宗立派后，八极门与主角门派结盟，共御外侮。 |

### 5. 沈若兰

| 项目 | 内容 |
|------|------|
| **身份** | 爱国女学生，后习武成为女拳师；家族被洋行迫害破产 |
| **境界** | 明劲→暗劲（非战斗主力，但有自保之力） |
| **性格** | 外柔内刚，聪慧果敢，有家国情怀。不矫情、不拖后腿。 |
| **功能** | 女主角。感情线克制，服务于主线。她是主角与"知识界/革命思潮"的连接点，也为主角提供情报与后方支援。卷四后协助主角开宗立派、办学传武。 |
| **结局** | 存活至结尾。与主角并肩见证国术传承，开放式感情归宿。 |

### 6. 迅哥儿（章迅）

| 项目 | 内容 |
|------|------|
| **身份** | 鲁迅笔下"我"的化身，主角童年故交，文人 |
| **性格** | 敏感、悲悯、有思想，以笔为刀 |
| **功能** | 原著彩蛋角色。以文人视角见证闰土的蜕变。卷三、卷五两次客串出场，点题"这一世，闰土不低头"。非战斗角色，纯情感升华。 |
| **结局** | 卷末重逢闰土，原作中"闰土喊老爷"的悲剧被改写——闰土以宗师之姿与故交平等重逢。全书最大的情感彩蛋。 |

### 7. 大弟子·石头

| 项目 | 内容 |
|------|------|
| **身份** | 码头苦力出身，天赋异禀，主角开宗立派后收的首徒 |
| **境界** | 明劲→暗劲（成长中） |
| **性格** | 憨厚老实，力气大，忠心耿耿 |
| **功能** | "底层逆袭"镜像叙事，承载国术传承希望。也是主角"师如父"身份的体现——他怎样被刘三爷/戴拳师指引，他就怎样指引下一代。 |
| **结局** | 存活。结尾暗示他将继承衣钵，国术代代相传。 |

## 二、反派阵营（按梯度排列）

### 第一梯队：乡野小反派（卷一）

#### 钱老爷

| 项目 | 内容 |
|------|------|
| **身份** | 绍兴乡下一方恶霸地主 |
| **性格** | 贪婪、欺软怕硬、为富不仁 |
| **境界** | 无武功，靠手下打手 |
| **功能** | 主角明劲初成的试金石。代表旧社会底层压迫。 |
| **结局** | 卷一末被主角打服/驱逐，家产散于乡民。小爽点收束。 |

#### 铁砂掌·王麻子

| 项目 | 内容 |
|------|------|
| **身份** | 钱老爷手下打手头目，练过铁砂掌入门 |
| **境界** | 明劲入门（外家硬功，有蛮力无整劲） |
| **功能** | 主角第一个"会武功"的对手。让主角意识到"乡野把式不够，要学真功夫"。 |
| **结局** | 被主角明劲击败，折服。可留作后期路人，偶尔提供乡野情报。 |

### 第二梯队：江湖争锋反派（卷二）

#### 太极门·杨馆主

| **境界** | 暗劲巅峰 |

### 第三梯队：租界洋人反派（卷三）——打洋人核心

| **身份** | 流亡白俄贵族，西洋摔跤与拳击手 |

## 三、角色功能检查表

确保以下叙事功能均有角色承担：

| 功能 | 承担角色 |
|------|---------|
| 引路人（指引主角入门） | 刘三爷（卷一）→ 戴拳师（卷二起） |
| 情感锚点（温情/牵绊） | 章老爹、沈若兰、石头 |
| 兄弟热血 | 霍铁山 |
| 原著呼应/情感彩蛋 | 迅哥儿 |
| 传承象征 | 石头（下一代） |
| 阶梯式反派（逐级打脸） | 王麻子→杨馆主→汤姆斯→伊万诺夫→藤场次郎→宫本 |
| 汉奸型反派（更招恨） | 赵德海 |
| 灰色势力（格局复杂化） | 徐镇邦 |
| 终极反派 | 宫本武藏 + 洋人军方联军 |
| 破境献祭（之死激发主角突破） | 戴拳师 |

## 写作注意

- **反派不降智**：洋人反派傲慢但有实力，日寇反派阴险且有真本事。主角赢要赢得惊险，打脸才爽。
- **反派有层次**：伊万诺夫是"力量傲慢"，宫本是"阴险算计"，赵德海是"数典忘祖"——不同反派给主角不同的"打脸快感"。
- **灰色角色增加厚度**：徐镇邦、杨馆主这类非纯反派角色，让世界不非黑即白，增加格局厚度。
