# 写作流程SOP

## 一、整体时间规划（100万字）

| 阶段 | 时间 | 产出 | 说明 |
|------|------|------|------|
| 设定固化 | 2周 | 5个核心设定文档 | 世界观、国术体系、人物卡、金手指细则、历史时间线 |
| 大纲细化 | 2周 | 25卷细纲（每卷5000字） | 每卷章节分配、爽点分布、伏笔位置 |
| 试写3章 | 1周 | 开篇1万字 | 测试节奏、文风、国术描写手感 |
| 批量创作 | 6-9个月 | 100万字存稿 | 每日4000字，分阶段完成 |
| 修订 | 1个月 | 全文修订 | 战力检查、时间线检查、bug修复 |

## 三、大纲细化阶段（第3-4周）

### 细化要求
1. **每卷5000字细纲**：包含章节分配、爽点分布、伏笔位置、人物出场
2. **章细纲模板**：
   ```
   【章目标题】（9-15字，要有网感）
   【章节定位】（所属卷幕、人物出场、核心事件）
   【开篇钩子】（前情回顾+悬念引入，100字内）
   【正文内容】
     1. 场景展开（200字）
     2. 冲突升级（400字）
     3. 武道对决/智斗（核心，1000-1500字）
     4. 收尾与下章伏笔（200字）
   【爽点设计】（升级/打脸/收获/美人/名声）
   【章节字数】（目标3000-4000字）
   ```

### 爽点节奏（每4万字一卷）
- 第1章：钩子+日常+铺垫
- 每5000字一个小爽点（小打脸/小突破）
- 第8-10章：中高潮（大战反派）
- 最后一章：下卷伏笔+境界突破/名声扩大

## 四、试写阶段（第5周）

### 试写目标
- 写前三章，约1万字
- 测试节奏、文风、国术描写手感
- 确定叙述视角（建议第三人称限知视角，跟随主角视线）

### 试写检查清单
- [ ] 开篇钩子是否吸引人？
- [ ] 国术描写是否"实"？（劲力传导、实战细节）
- [ ] 人物性格是否立得住？
- [ ] 金手指是否自然？（不突兀、不喧宾夺主）
- [ ] 历史背景是否自然融入？
- [ ] 节奏是否紧凑？（无尿点）

## 五、批量创作阶段（第6周-第9个月）

### 创作节奏
- **每日目标**：4000-6000字
- **每周目标**：20000-30000字
- **每月目标**：80000-120000字
- **总目标**：100万字，约9-12个月完成

### 创作顺序
1. **先写第一卷**（4万字），存稿完成后发布前3章
2. **根据反馈调整**，然后继续写第二卷
3. **保持每月一卷**的进度，确保故事连贯性

### 每卷创作流程
1. **第1天**：细读该卷细纲，标注关键场景
2. **第2-3天**：写第1-3章（铺垫+第一个小高潮）
3. **第4-6天**：写第4-7章（中段发展）
4. **第7-8天**：写第8-10章（大高潮+收尾）
5. **第9天**：复盘，检查战力、时间线、伏笔

### 写作原则
1. **国术描写要"实"**：写出劲力传导、实战细节
2. **爽点要足**：每章至少一个小爽点
3. **历史要准**：真实历史事件不能错，但可虚构细节
4. **人物要立**：配角要有高光，反派不能弱智
5. **金手指要克制**：系统只辅助，不直接给力量

## 六、修订阶段（第10个月）

### 修订清单
1. **战力检查**：境界体系是否一致？主角升级速度是否合理？
2. **时间线检查**：历史事件时间是否准确？人物出场时间是否合理？
3. **伏笔检查**：前期埋的伏笔是否回收？是否有遗漏？
4. **人物检查**：人物性格是否一致？成长弧线是否完整？
5. **文风检查**：前后文风是否统一？国术描写是否一致？

### 修订流程
1. **第一轮**：通读全文，标注问题
2. **第二轮**：逐章修订，修复bug
3. **第三轮**：润色文字，提升文笔
4. **第四轮**：最终检查，确保无误

## 七、发布策略

### 发布平台
- 起点中文网、纵横中文网、17K小说网等主流网文平台
- 建议同时发布2-3个平台，扩大受众

### 发布节奏
- **存稿策略**：至少存稿30章（12万字）后再开始发布
- **更新节奏**：每日2更，每更4000字，共8000字/日
- **发布时间**：早8点、晚8点（读者活跃高峰）

### 营销策略
1. **开篇三章**：免费，吸引读者
2. **上架前**：积累粉丝，建立书友群
3. **上架后**：保持稳定更新，与读者互动
4. **推荐位**：争取平台推荐，扩大曝光

## 九、常见问题与解决方案

### Q1：卡文怎么办？
- **原因**：大纲不够细，或人物动机不清晰
- **解决**：回头细化大纲，或暂时跳过该场景，写后面的内容

### Q2：战力体系崩了怎么办？
- **原因**：升级太快，或对手太弱/太强
- **解决**：建立战力对照表，每卷复盘一次

### Q3：历史事件融入不自然怎么办？
- **原因**：为了写历史而写历史，忽略了人物动机
- **解决**：从主角视角出发，让历史事件影响主角决策

### Q4：金手指太强/太弱怎么办？
- **原因**：系统没有明确规则
- **解决**：建立金手指使用规则，明确限制条件

### Q5：人物脸谱化怎么办？
- **原因**：配角没有自己的动机和高光
- **解决**：给每个重要配角写人物小传，明确其动机和行为逻辑
