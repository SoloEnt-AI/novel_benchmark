# 人物设定

## 一、主角

### 陈锋（穿越后身份：闰土）

**基本信息**
| 项目 | 内容 |
|------|------|
| 原名 | 陈锋（现代名） |
| 穿越身份 | 闰土（章闰土） |
| 年龄 | 穿越时12岁 |
| 籍贯 | 浙江绍兴 |
| 家庭 | 贫苦农民家庭 |

**穿越前身份**
- 现代国术爱好者，武术教练
- 精通形意、八卦、太极、咏春等多派武术
- 因意外身亡，灵魂穿越到少年闰土身上

**性格特点**
- 热血正义，嫉恶如仇
- 聪明机智，善于谋略
- 坚韧不拔，永不言弃
- 重情重义，关爱百姓
- 有现代人的见识，不拘泥于旧俗

**外貌描写**
- 穿越后保留闰土的外貌：紫色圆脸，头戴银项圈
- 身材结实，肌肉匀称
- 眼神锐利，有武者之气
- 成年后身高八尺，威风凛凛

**能力成长**
| 阶段 | 境界 | 年龄 | 实力 |
|------|------|------|------|
| 初入江湖 | 明劲初期 | 12-14岁 | 以一敌十 |
| 小有名气 | 明劲巅峰 | 14-16岁 | 击败地方高手 |
| 名震一方 | 暗劲 | 16-20岁 | 以一敌百 |
| 武林新秀 | 化劲 | 20-24岁 | 百人敌 |
| 一代宗师 | 丹劲 | 24-28岁 | 千人敌 |
| 国术巅峰 | 罡劲 | 28-30岁 | 万人敌 |
| 打破虚空 | 见神不坏 | 30岁+ | 陆地神仙 |

**金手指：国术传承系统**
- **功能**：
  1. 击杀/击败敌人获得"武道点"
  2. 兑换各派武学秘籍
  3. 悟道空间（时间流速1:10）
  4. 任务系统触发奖励
  5. 武学融合功能

- **限制**：
  1. 武道点只能用于武学相关
  2. 悟道空间有时间冷却
  3. 高阶武学需要前置条件

**人物弧光**
- 从农家少年成长为一代宗师
- 从个人复仇到以武救国
- 从独善其身到兼济天下
