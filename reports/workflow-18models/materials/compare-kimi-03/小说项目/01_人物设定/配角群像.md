# 配角群像

## 一、红颜知己

### 沈婉清（女主之一）

| 项目 | 内容 |
|------|------|
| **身份** | 绍兴沈家大小姐，留洋归来的新女性 |
| **年龄** | 初登场14岁，比主角大2岁 |
| **外貌** | 端庄秀丽，气质温婉，常穿旗袍或洋装 |
| **性格** | 外柔内刚，思想开明，有强烈的爱国情怀 |
| **特长** | 精通英语、法语，熟悉西方文化和科技 |
| **与主角关系** | 青梅竹马，后期成为主角的左膀右臂和红颜知己 |

**人物背景**：
- 沈家是绍兴当地的名门望族，世代经商
- 沈婉清5岁时随父亲去上海，10岁时被送往英国留学
- 1898年回国，对国内的落后现状深感痛心
- 立志用所学知识改变国家命运

**与主角的交集**：
- 第一卷：回乡探亲时与闰土相识，被闰土的"与众不同"吸引
- 第二卷：为主角提供情报和翻译，帮助主角了解洋人势力
- 第三卷：参与革命活动，成为主角的"军师"
- 后期：与主角并肩作战，成为不可或缺的伙伴

**经典台词**：
- "闰土，你变了。但我喜欢这样的变化。"
- "洋人也是人，也有值得我们学习的地方。但学习不等于屈服。"
- "我要让全世界知道，中国不仅有功夫，还有智慧。"

### 柳如烟（女主之一）

| 项目 | 内容 |
|------|------|
| **身份** | 江湖侠女，峨眉派弃徒 |
| **年龄** | 初登场16岁，比主角大4岁 |
| **外貌** | 英姿飒爽，眉目如画，常穿劲装 |
| **性格** | 豪爽直率，嫉恶如仇，内心有柔软一面 |
| **特长** | 峨眉剑法、轻功，擅长暗杀和情报收集 |
| **与主角关系** | 不打不相识，后期成为生死之交和红颜知己 |

**人物背景**：
- 原为峨眉派掌门亲传弟子，天赋异禀
- 因揭露门派内勾结洋人的叛徒，被逐出师门
- 流落江湖，以行侠仗义为生
- 一直在寻找机会重回峨眉，清理门户

**与主角的交集**：
- 第二卷：在江湖中偶遇主角，因误会大打出手
- 不打不相识，被主角的武功和人格折服
- 成为主角的"护卫"和"刺客"
- 后期：帮助主角清理峨眉派叛徒，重归师门

**经典台词**：
- "小弟弟，你的拳头很硬，但姐姐的剑更快。"
- "我柳如烟这辈子只佩服两种人：一种是真英雄，一种是真小人。你是第一种。"
- "峨眉派的叛徒，我一个个杀。洋人的走狗，我一个不留。"
