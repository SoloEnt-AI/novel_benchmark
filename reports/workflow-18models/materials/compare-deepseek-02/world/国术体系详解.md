# 国术体系详解

> 本文档定义《国术闰土》中的完整修炼体系。国术讲究"拳拳到肉"，拒绝浮夸玄幻，强调真实感与爽感的平衡。

---

## 一、总纲：国术三层境界

传统国术修炼，从外到内，由形入神，分为三大境界：

### 第一境：明劲（炼精化气）

| 特征 | 说明 |
|------|------|
| **核心** | 筋骨力。拳脚打人，力从地起，走的是"刚猛"路线 |
| **表现** | 一拳可碎石碑，一脚可断木桩。普通人挨上一拳，非死即残 |
| **瓶颈** | 练到"筋骨齐鸣、虎豹雷音"即为明劲巅峰，再往上需悟"松沉"二字 |
| **参考门派** | 少林拳、洪拳、八极拳的刚猛路数 |

**小境界划分：**
- 明劲初期：力贯四肢，拳出有声（虎虎生风）
- 明劲中期：筋骨齐鸣，身如铁桶（抗普通钝器击打）
- 明劲巅峰：虎豹雷音，一拳千斤（可正面硬撼持冷兵器的多人围攻）

---

### 第二境：暗劲（炼气化神）

| 特征 | 说明 |
|------|------|
| **核心** | 气劲。劲走内里，表面不显，一击之下内脏俱碎 |
| **表现** | 一掌按在石板上，石板表面完好，底下已碎成粉末。隔山打牛，劲力穿透 |
| **瓶颈** | 暗劲消耗极大，不能久战。需悟"化"字方能突破 |
| **参考门派** | 太极拳、八卦掌、形意拳的内家路数 |

**小境界划分：**
- 暗劲初期：劲入脏腑，一掌透体（可一击毙敌而不留外伤）
- 暗劲中期：劲随意走，周身皆可发劲（肩膀、后背、膝盖皆能伤人）
- 暗劲巅峰：举重若轻，暗劲绵长（可连续发暗劲数十次而不力竭）

---

### 第三境：化劲（炼神还虚）

| 特征 | 说明 |
|------|------|
| **核心** | 神意。不拘泥于招式，身体本能反应已达"秋风未动蝉先觉"的境界 |
| **表现** | 一羽不能加，蝇虫不能落。敌未动，我已感应其杀意。出手即致命，不需要思考 |
| **瓶颈** | 化劲已是人力的极限。传说中仍有"抱丹""见神不坏"等至高境界，但已属传说 |
| **参考** | 杨露禅、董海川等清末国术宗师所处的境界 |

**小境界划分：**
- 化劲初期：神明体净，一羽不加（感应超常，可预判敌人出招）
- 化劲大成：至诚之道，可以前知（战斗中近乎"预知"，秋毫之末皆可察觉）
- 化劲圆满·抱丹坐胯（传说）：气血内敛如金丹，返老还童，寿元大增
- 至境·见神不坏（传说）：打破虚空，肉身成圣。清末以来无人确证达到

## 二、主角国术路线

闰土的主修路线设计为 **形意拳 → 八卦掌 → 太极拳** 的渐进式进阶：

1. **形意拳打底（明劲期）**：形意拳讲究"硬打硬进无遮拦"，最适合少年闰土血气方刚的年纪，也是最快形成战斗力的路数。十二形（龙虎猴马鸡鹞燕蛇鹰熊骀）各有所长。
2. **八卦掌转圜（暗劲期）**：当闰土意识到单靠刚猛不能应对所有敌人时，开始习练八卦掌。八卦掌走转翻拧，以巧破力，弥补形意拳直线进攻的不足。
3. **太极拳归宗（化劲期）**：太极是国术的终极形态，刚柔并济、阴阳合一。当闰土融会贯通形意与八卦之后，在太极拳中找到"化劲"的钥匙。

## 三、各大流派简介（世界观中的势力分布）

| 流派 | 特点 | 代表人物（可创作） | 势力范围 |
|------|------|-------------------|---------|
| **形意门** | 直打直进，以硬破硬 | 李存义（真实人物） | 河北、天津 |
| **八卦门** | 走转翻拧，以巧破力 | 董海川传人 | 北京 |
| **太极门** | 刚柔并济，阴阳合一 | 杨氏太极传人 | 京畿、江南 |
| **八极拳** | "文有太极安天下，武有八极定乾坤" | 八极拳门人 | 河北沧州 |
| **洪拳** | 桥手硬马，大开大合 | 南方拳师 | 广东、南洋 |
| **少林** | 七十二绝技，博大精深 | 少林武僧 | 河南嵩山 |
| **民间散手** | 义和拳残余、地方拳种 | 各色江湖人物 | 各地乡村 |

这些门派在清末民初的乱世中各有立场——有的投靠洋人做买办保镖，有的暗中支持革命党，有的固守传统避世不出。这将构成小说中的江湖势力网。

## 四、战斗系统的表现原则

为了保持"拳拳到肉"的真实爽感，遵循以下写作守则：

1. **禁止"一拳打爆一座山"**：国术再强，仍是血肉之躯。化劲宗师也怕火枪齐射，这是时代悲剧也是看点。
2. **每一个敌人都有威胁**：即使是明劲期的小喽啰，如果人数够多、手持兵器，也能对暗劲高手构成威胁。战斗永远有悬念。
3. **修炼有代价**：练武不是打怪升级，需要时间、师傅、实战磨砺，以及身体损耗。明劲期练过头会留下暗伤，暗劲使用过度会折寿。
4. **招式要有名有姓**：每次出招尽量写清楚用了什么招式（如"半步崩拳""转身摆莲""白鹤亮翅"），增加专业感和画面感。
5. **洋人的枪械是真实威胁**：主角不能靠肉身硬抗子弹（至少前期不能），需要用智慧、走位、环境来应对火器。这也是"国术 vs 现代武器"的核心冲突。

## 五、主角专属绝招（预设计，随剧情解锁）

| 境界 | 绝招名称 | 来源 | 效果 |
|------|---------|------|------|
| 明劲中期 | **半步崩拳** | 形意拳郭云深绝技 | 半步入位，一拳崩出。在极近距离爆发出千斤之力，防不胜防 |
| 明劲巅峰 | **虎形劈劲** | 形意十二形 | 模仿猛虎扑食，以腰胯带动双臂同时劈下，可断刀剑 |
| 暗劲初期 | **单换掌·透骨劲** | 八卦掌 | 表面轻描淡写一推，暗劲已透入骨骼内脏 |
| 暗劲中期 | **游身八卦连环掌** | 八卦掌精髓 | 以身法走转同时连发数掌，每一掌都带暗劲，如暴风骤雨 |
| 化劲初期 | **揽雀尾** | 太极拳 | 看似极轻柔的四字诀（掤捋挤按），实则蕴含化劲巅峰的妙谛，可化解一切刚猛攻击 |
| 化劲大成 | **太极圆转·四两拨千斤** | 太极拳终极奥义 | 以彼之道还施彼身，甚至可将子弹的动能引导偏转（非硬抗，是"化"） |
