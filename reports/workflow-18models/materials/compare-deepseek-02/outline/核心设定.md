# 核心设定总纲

> 本文档是《国术闰土》的"宪法"，所有剧情、人物、设定的最终依据。后续大纲和正文若与此冲突，以此为准。

---

## 一、故事前提（一句话卖点）

> 现代人魂穿少年闰土，从浙江绍兴的瓜田出发，以形意拳为起点踏上国术之路，在清末民初的乱世中拳打洋人走狗、脚踏买办势力，最终成为一代国术宗师，以一双铁拳为民族争一口气。

---

## 二、穿越设定

### 前世身份
- **姓名**：陈岳（暂定，可修改）
- **年龄**：28岁（穿越时）
- **职业**：省级武术队退役运动员 + 历史系研究生（或武术教练兼历史爱好者）
- **性格**：理性、坚韧，但穿越前在现实生活中感到压抑——传统武术在现代被嘲笑为"花架子"，他的理想和现实之间有巨大落差
- **穿越契机**：在一次传统武术表演赛上被意外重击头部，醒来后发现自己变成了少年闰土

👉 **职业设计的意义**：
- 武术底子 → 解释了为何他能快速上手国术，不是无脑开挂
- 历史知识 → 他知道这个时代即将发生什么（甲午、庚子、辛亥革命），这是最大的金手指
- 对国术有执念 → 前世他没机会证明传统武术的价值，这一世他要让国术在乱世中发光

### 穿越时间点
- **现实历史锚点**：1895年（光绪二十一年），甲午战争刚结束，《马关条约》签订之年
- **闰土的年龄**：15岁，正是鲁迅小说《故乡》中"项带银圈，手捏一柄钢叉"的少年时期
- **地点**：浙江绍兴府城外，闰土家所在的乡村

### 穿越后的记忆融合
- 主角拥有陈岳的全部记忆（现代知识、武术理论、历史走向）
- 同时融合了闰土原本的部分身体记忆（乡土生活的肌肉记忆、对家人的情感印记）
- 两者不是简单的覆盖，而是融合——陈岳的意识为主，但会带着闰土的情感底色

## 三、金手指详解

| 金手指 | 等级 | 说明 |
|--------|------|------|
| **武术理论与现代训练法** | S级 | 前世运动员生涯让他掌握了科学训练方法（营养学、人体力学、运动康复），这些在清末是降维打击。例如：他知道如何通过饮食和拉伸最大化训练效果，知道如何避免练功留下的暗伤 |
| **历史预知** | S级 | 知道1895-1912年间的大事件走向，可以在关键节点做出正确选择。但随着时间的推移，蝴蝶效应会让历史逐渐偏离轨道 |
| **国术天赋（身体）** | A级 | 少年闰土本就身体强健（能在瓜田刺猹、能在海边捡贝壳，身体素质远超同龄读书人），加上陈岳的灵魂带来了对身体的精准控制力，修炼速度是常人的数倍 |
| **真传机缘** | A级 | 穿越初期会因"巧合"获得某位隐世高人的真传。这不是无脑送挂——师傅选择他的原因，是他展现出了"不一样"的气质（现代人的眼光和思维方式打动了老师傅） |
| **语言与见识** | B级 | 会说一些英语（前世基础），这在清末是稀有能力；懂基础数理化，比 99% 的同时代人强 |

## 四、核心矛盾体系

小说围绕着三个层次的矛盾展开：

### 第一层：生存矛盾（卷一 ~ 卷二前期）
- 农家少年如何在乱世中保护家人和自己？
- 如何在温饱线上挣扎的同时坚持练武？
- 初次面对洋人走狗（买办、教民、地痞），从忍气吞声到挺身反抗

### 第二层：力量矛盾（卷二后期 ~ 卷四）
- 国术的极限在哪里？能抗衡火枪吗？
- 个人武力 vs 系统性的压迫——打跑一个洋人，还有十个洋人
- 武术门派的立场分歧：是明哲保身，还是站出来？

### 第三层：道路矛盾（卷五 ~ 卷六）
- 什么是真正的"强国"？靠武术精神，还是靠制度变革？
- 革命党、保皇党、江湖势力——主角选择哪条路？
- 化劲宗师的终极使命是什么？是独善其身还是兼济天下？

## 五、爽点设计清单

按网文"爽点即正义"的原则，预埋以下核心爽点场景：

### 初期爽点（卷一）
- [ ] 穿越醒来，发现自己是闰土——经典反差萌 + 身份认同悬念
- [ ] 首次展示"现代人的眼光"——用基础物理知识帮乡亲解决实际问题，惊艳众人
- [ ] 第一次用武术打赢地痞/洋人走狗——"原来这个时代，拳头真的能说话"
- [ ] 拜师名场面——高人慧眼识珠，收徒考验过程充满戏剧性
- [ ] 第一次击败外国武者——"东亚病夫？你再说一遍"

### 中期爽点（卷二 ~ 卷三）
- [ ] 建立自己的势力或武馆，开宗立派的雏形
- [ ] 在洋行/租界门口以一敌十，一战成名
- [ ] 与义和拳残余的正面交锋——"你们这样不是救国，是害国"
- [ ] 以拳法折服不同门派的武师，整合各派力量
- [ ] 在众目睽睽之下击败西洋拳王/日本柔道高手

### 后期爽点（卷四 ~ 卷六）
- [ ] 暗劲大成，在火枪齐射中七进七出
- [ ] 以化劲宗师之身，正面对话革命党领袖（孙文/黄兴等历史人物）
- [ ] 在历史的转折点上，用自己的方式影响民族命运
- [ ] 终局之战：化劲圆满，完成前世今生两个灵魂的终极和解
- [ ] 尾声：传承——国术的火种在新一代中延续

## 六、创作禁忌

为了避免踩雷，以下是需要避开的内容：

1. ❌ **不要纯系统面板流**：国术修炼不是点技能点，需要真实的苦练和感悟
2. ❌ **不要过度民族主义**：爽文可以"打洋人"，但避免无脑妖魔化所有外国人。要有立体的外国角色（有正义感的传教士、有良知的商人等）
3. ❌ **不要美女无脑倒贴**：女性角色要有独立人格和成长线
4. ❌ **不要悬浮历史**：历史大事件的时间线要基本准确，细节可虚构，框架不能歪
5. ❌ **不要战力通胀**：境界提升要有代价和时间跨度，不能一个月从明劲跳到化劲
