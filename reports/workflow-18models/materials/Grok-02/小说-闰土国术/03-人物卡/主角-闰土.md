# 主角：闰土（魂穿）

## 基本信息
- **姓名**：闰土（原身小名；文书或登记可用“润土”等谐写，正文以闰土为主）
- **年龄（开篇）**：约十四五岁（少年体，便于长线成长）
- **身份**：绍兴海边沙地佃农/渔猎少年 → 拳师 → 武馆主 → 国术教范创立者
- **外貌**：紫红圆脸逐渐被风吹日晒与拳伤改写；项带银圈的记忆尚在，后自觉摘下；眉目由呆滞变沉静锋利；手粗、肩宽、步稳
- **魂穿来源**：现代武术爱好者（业余馆教练/体院旁听均可），车祸或意外身亡，醒来已是闰土

## 性格内核
- **表层**：话不多，做事狠而稳，对乡亲软、对压迫硬
- **里层**：现代人的尊严敏感 + 原身记忆里的屈辱与亲情
- **缺陷**：早期易低估治外法权与舆论战；有时太信“打赢就有理”
- **执念**：不让自己、家人、身边人再活成“苦得只剩木然”的样子
- **人物弧光**：个人复仇/活命 → 护乡 → 立武名 → 组织起来 → 武以载国（尊严）

## 能力与成长
- **开局优势**：现代对抗意识、训练法、基本拳理；原身熟悉地形与渔猎
- **短板**：年幼体未成、无资财、无功名、不识官场深浅
- **卷一末**：明劲稳固，暗劲初窥，沙地有名
- **卷三**：化劲门槛，敢在租界规则里打公开战
- **卷五**：宗师级 + 可复制的国术教范

## 语言风格
- 对乡人：短句、土话底色、不端着
- 对敌人：少废话，赢了才说一句压场的
- 内心：现代吐槽适度，不破坏沉浸；关键抉择时冷静像教练看盘

## 人际关系
- **韩老枪**：师徒，亦父亦兵
- **沈晚筝**：淡感情，药与伤、理解与同行
- **周树人**：偶尔深谈，一个执笔一个执拳
- **阿刺等**：兄弟团，绝对信任的基本盘
- **高子敬**：理念宿敌，贯穿中后期

## 经典行为标签（写作抓手）
1. 战前摸场地、算步数
2. 穷人练功：砖、沙袋、船桨、潮汐作息
3. 打完先看自己人伤没伤，再说话
4. 成名后仍亲自教最苦的那批孩子桩功

## 禁止写法
- 变成油腻全能嘴炮
- 动辄“老子前世…”大段说教
- 无视时代直接屠洋不承担后果
