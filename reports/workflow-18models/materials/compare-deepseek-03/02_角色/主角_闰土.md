# 主角：闰土（穿越者）

---

## 一、身份档案

### 穿越前
- **姓名**：陈锐（暂定，小说中可以不提原名，只在内心独白中偶尔流露）
- **身份**：现代青年，约25-30岁
- **职业**：可能是历史系研究生/武术爱好者/普通上班族
- **性格底色**：略有愤世嫉俗但不失热血，对近代史有基本了解，看过不少国术类网文
- **穿越契机**：意外（车祸/溺水/梦中穿越均可），开篇一笔带过，不过分纠结原因
- **穿越后记忆状态**：完整保留前世记忆，但关于具体历史日期和细节逐渐模糊——只留下大趋势判断和现代思维方式

### 穿越后
- **姓名**：闰土（原名章闰水，鲁迅《故乡》中的少年闰土）
- **年龄**：穿越时约14岁（1895年）
- **家庭**：
  - 父亲章福庆（原作中"闰土的父亲"）：老实巴交的农民，有一手好农活，身体硬朗，懂一些乡下把式
  - 母亲：农家妇女，善良勤劳，后因病需要药材费用，成为主角初期赚钱的动力之一
  - 弟弟妹妹若干：增加主角的责任感
- **家境**：贫苦佃农，给地主家种西瓜地，勉强度日

### 外貌演变
- **少年时期**（14-19岁）：紫棠色圆脸，头戴小毡帽，颈挂银项圈（《故乡》经典形象）→ 随练武逐渐褪去圆润，脸型显棱角
- **青年时期**（19-25岁）：身材精瘦修长，肌肉如铁线般缠绕骨骼，目光锐利如刀，肤色仍黝黑但光泽如玉（药浴+练功效果）
- **壮年时期**（25-35岁）：宗师气质，不动如山，一看就有"能打死人"的气场，但又温润内敛，返璞归真

## 二、性格塑造

### 核心性格
- **底色**：骨子里的不屈与热血——现代人的尊严感+农民儿子的淳朴韧劲
- **外在表现**：
  - 平时沉默寡言，不喜废话（农民本色+现代人懒得跟古人哔哔）
  - 但面对欺压时绝不沉默，一言不合就动手
  - 对家人极温柔孝顺，对外人铁血冷酷

### 性格驱动力
- **核心执念**：不能接受"东亚病夫"四个字
- **底层视角**：深知穷人的苦，所以格外痛恨仗势欺人的洋人和汉奸
- **穿越者自觉**：知道历史走向，有一种"既然来了就要做点什么"的使命感

### 性格成长弧线
| 阶段 | 性格特征 | 转变点 |
|------|----------|--------|
| 第一卷 | 沉默少年，内心热血但不知所措 | 第一次打死人后，接受"这是一个吃人的时代" |
| 第二卷 | 锋芒毕露，拳下无情 | 遇到更大格局的引路人，开始思考"国术救国" |
| 第三卷 | 沉稳大气，已有宗师雏形 | 经历生死大关，悟到"武为止戈" |
| 第四卷 | 返璞归真，不动如山 | 见天地、见众生、见自己 |

## 四、成长主线

### 第一卷：觉醒（约160章，25万字）
**核心主题**：从农民儿子到国术武者

**关键节点**：
1. 穿越醒来，发现自己变成了闰土（第1-3章）
2. 目睹洋人欺压乡亲，第一次产生"我要变强"的念头（第5-10章）
3. 阴差阳错遇到隐世拳师拜师（第10-15章）
4. 站桩三年，初窥明劲（第20-30章，可压缩时间跨度）
5. 第一次实战——打死乡间恶霸/汉奸走狗（第50章左右）
6. 义和团运动波及乡间，主角经历残酷的冷兵器vs火器现实（第70-90章）
7. 明劲大成，决定走出乡间，去更大的世界（第140-160章）

### 第二卷：扬名（约160章，25万字）
**核心主题**：上海滩立威，国术镇洋人

**关键节点**：
1. 初到上海，被当成乡下人看不起（第161章）
2. 在码头/工厂当苦力，目睹工人被洋人欺压
3. 第一次与外国拳师交手，险胜（暗劲入门）
4. 挑战各租界武馆，连胜扬名
5. 遇到更大的国术界人物，被引入江湖
6. 暗劲大成，与日本柔道高手决战上海滩（本卷高潮）

### 第三卷：纵横（约180章，28万字）
**核心主题**：京津风云，国术界扛鼎

**关键节点**：
1. 八国联军侵华背景，京津大乱
2. 在战场上救下关键人物，名动京城
3. 南北国术界大会，主角崭露头角
4. 化劲突破——与太极/八卦宗师切磋顿悟
5. 与日本剑道/空手道顶尖高手生死决战（化劲期巅峰对决）
6. 辛亥革命前后，国术界分裂，主角选择

### 第四卷：宗师（约150章，22万字）
**核心主题**：海外远征，天下无敌

**关键节点**：
1. 走出国门——日本武道挑战/南洋华侨邀请
2. 丹劲突破——生死战中悟生死
3. 欧美远征——对决各国顶尖高手
4. 罡劲大成——欧洲格斗皇帝之战（全书最高潮）
5. 一战爆发，主角在战场上的终极拷问

### 结局：开宗（约50章，8万字）
**核心主题**：国术传承，民族复兴

1. 归国创立国术馆
2. 培养下一代弟子
3. 隐约触摸"见神不坏"的境界
4. 在一个新的时代，国术找到了自己的位置

## 五、写作注意事项

### 对话风格
- 平时话少，但出手前有一句固定台词——每卷可以有一个标志性的战前宣言
- 例如："我不是来跟你讲道理的，我是来打死你的。"
- 或者更简洁："你是自己跪下，还是我帮你？"
- 随着成长，战前宣言从锋芒毕露变为低调内敛

### 内心独白
- 穿越者的内心吐槽适度使用，不要过多破坏历史氛围
- 关键抉择时的内心挣扎要写出力量感
- 对现代生活的偶尔怀念（如"如果有抗生素就好了"）可增加真实感

### 动作戏原则
- 每场打斗都有明确的目的——不是为了打而打
- 对手越强，描写越详细——小角色一招秒，大对手写满半章
- 突出"国术之美"：力量美、速度美、技巧美
- 把"整劲""听劲"这些核心概念在实战中反复展示，建立读者认知

### 情绪控制
- 爽点：击败外国高手后的民族自豪感
- 燃点：在绝境中突破境界，极限反杀
- 痛点：同胞受辱、战友牺牲——但点到为止，不过度煽情
- 泪点：家人、恩师相关的温情时刻

## 六、禁则（底线）

1. **不亲日**：日本人是头号对手，可以有值得尊敬的日本武者对手，但立场必须分明
2. **不汉奸**：主角在任何情况下不与侵略者妥协
3. **不圣母**：该杀就杀，不搞"以德报怨"
4. **不龟缩**：遇到欺压同胞的情节，主角必须出手——哪怕打不过也要上
5. **不崇洋**：外国有好人有坏人，但主角的核心立场永远是"中国优先"
