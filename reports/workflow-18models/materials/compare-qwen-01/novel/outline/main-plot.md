# 主线剧情大纲

## 一、核心主题

**穿越闰土，修炼国术，扬我国威，一代宗师**

## 二、主线脉络

```
穿越觉醒 → 拜师学艺 → 初露锋芒 → 闯荡上海 → 击败洋人 → 开宗立派 → 一代宗师
```

## 三、主线分阶段

### 阶段一：觉醒（第一卷）
- **核心**：穿越适应 + 拜师学艺 + 初战告捷
- **主线**：
  1. 穿越成闰土，适应民国初年生活
  2. 发现形意拳师父李仲甫，拜师学艺
  3. 村霸赵太爷欺压百姓，闰土忍无可忍
  4. 击败护院李铁拳，名震乡里
  5. 决定离开绍兴，去上海闯荡

### 阶段二：成长（第二卷）
- **核心**：上海闯荡 + 结识英豪 + 首战洋人
- **主线**：
  1. 初到上海，见识繁华与黑暗
  2. 结识王二、张三，组建小团队
  3. 进入精武体育会，学习太极拳
  4. 洋人拳师史密斯挑衅，打伤中国武师
  5. 闰土挺身而出，擂台击败史密斯
  6. 名震上海，被称为"国术新星"

### 阶段三：扬名（第三卷）
- **核心**：开馆授徒 + 连战高手 + 三派融合
- **主线**：
  1. 开设"闰土武馆"，传授国术
  2. 天津八卦掌高手程海庭来访，切磋后传授八卦掌
  3. 法国格斗家皮埃尔挑战，被闰土击败
  4. 各路高手前来挑战，闰土连战连胜
  5. 形意、太极、八卦三派融合，自创武学
  6. 成为上海武术界领袖

### 阶段四：抗争（第四卷）
- **核心**：对抗外敌 + 民族英雄 + 罡劲大成
- **主线**：
  1. 日本武士鬼冢来华挑战，连败中国高手
  2. 闰土与鬼冢激战，险胜
  3. 德国军官汉斯、俄国大力士伊万相继挑战
  4. 闰土一一击败，扬我国威
  5. 突破罡劲，成为一代宗师
  6. 被推举为全国国术馆馆长

### 阶段五：宗师（第五卷）
- **核心**：巅峰对决 + 国术推广 + 一代宗师
- **主线**：
  1. 美国拳王杰克逊来华挑战
  2. 闰土苦战三百回合，最终获胜
  3. 日本武道宗师山下太郎来华，巅峰对决
  4. 闰土突破丹道，完胜山下太郎
  5. 推广国术，培养后辈
  6. 成为一代宗师，受人敬仰

## 六、主线冲突

### 核心冲突
1. **个人 vs 强权**：农民 vs 乡绅
2. **中国 vs 外国**：国术 vs 洋武术
3. **传统 vs 现代**：武术传承 vs 时代变革
4. **民族 vs 侵略**：保家卫国 vs 外敌入侵

### 冲突升级
```
乡绅欺压 → 洋人挑衅 → 日本入侵 → 民族危机
```
