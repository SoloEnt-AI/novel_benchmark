# 第三卷「国术宗师」—— 分卷细纲

---

## 一、卷信息

| 项目 | 内容 |
|------|------|
| **卷名** | 国术宗师 |
| **字数** | 约25万字（60-70章） |
| **时间跨度** | 1898年 — 1905年 |
| **主要场景** | 天津、北京 |
| **主角境界** | 化劲初入 → 化劲圆满 |
| **核心主题** | 升华·家国 |

---

## 二、本卷核心爽点

1. **化劲质变**：周身一体，沾衣十八跌，实力飞跃
2. **八国联军大背景**：最屈辱的时代，最大的危机
3. **师父牺牲**（方案A）：最强催泪弹
4. **擂台救国**：中外武学大碰撞，民族热血
5. **历史名场面**：与霍元甲等同台

---

## 三、分章细纲概要

| 章节范围 | 核心事件 | 爽点设计 |
|----------|----------|----------|
| **第1-8章** | 天津篇。天津是武术重镇，高手云集。闰土刚到天津就遇到地头蛇挑战。以化劲初入的实力轻松化解，赢得尊重。 | **新地图碾压** |
| **第9-15章** | 接触天津国术界核心圈。见识到真正的国术大师（各派掌门）。闰土眼界大开，虚心求教。博采众家之长。 | **世界观升级** |
| **第16-20章** | 义和团运动兴起。闰土不认同义和团的盲目排外，但也理解他们的愤怒。**化劲小成。** | **立场抉择** |
| **第21-25章** | **伊藤龙之介再战**。伊藤经过两年修炼变得更加强大，再次挑战闰土。这一次闰土以化劲小成之力正面压制。伊藤惨败，但不甘心。 | **宿敌再战**：碾压式胜利 |
| **第26-30章** | 八国联军侵华。天津陷落，洋人军队烧杀抢掠。闰土第一次见识到现代军队+枪炮的威力。 | **时代碾压**：个体的无力感 |
| **第31-38章** | **师父陈铁山之死**（方案A）。陈铁山为保护天津百姓/为给闰土争取撤离时间，以残躯挡住洋人追兵，力战而死。闰土赶到时只看到师父最后的背影。 | **全书最大泪点** |
| **第39-40章** | 闰土悲痛欲绝，但也明白——师父用自己的死告诉他：**有些东西比个人的命更重要。** 闰土的精神升华。**化劲圆满。** | **精神觉醒** |
| **第41-45章** | 北京陷落。闰土在乱世中救人。与俄国大力士**伊万·彼得罗夫**初遇。伊万在街头欺凌百姓，闰土出手，但被洋人军队干扰。 | **铺垫boss** |
| **第46-50章** | 闰土联合天津/北京残存的国术高手，组织对洋人的游击抵抗。展现国术在战场上的实用价值。 | **国术战争场面** |
| **第51-55章** | 中外擂台赛。洋人为了"展示文明优越性"，组织中外武学对抗赛。闰土代表中国武者出战。与**伊万·彼得罗夫**决战。 | **本卷最高潮** |
| **第56-60章** | 以化劲之巧破万钧之力，击败俄国大力士。全场中国人沸腾。但洋人势力不认账，试图抓捕闰土。闰土被迫转入地下。 | **惨胜+逃亡** |
| **第61-65章** | 闰土在流亡中反思——国术不能只停留在擂台和街头。要去更大的天地。**抱丹境界的门槛开始显现。** | **沉淀** |
| **第66-70章** | 同盟会成立的消息传来。顾明远受革命思想影响，开始和革命党接触。闰土看到新的希望。卷末，闰土决定去北京/南方。**跨入抱丹之境。** | **新目标**：革命的时代来了 |
