# 《国术闰土》项目说明

## 项目概述

**书名**：《国术闰土》
**类型**：历史架空 + 国术流 + 爱国流
**字数**：100万字（500章）
**风格**：热血爽文，升级打脸，扬我国威

## 核心创意

现代人魂穿成鲁迅笔下的闰土，凭借现代知识和国术传承，在清末民初的时代背景下修炼国术，打击洋人，最终成为一代武道宗师，为国家和民族的振兴做出贡献。

## 文件结构

### 1. world_setting.md - 世界观设定
- 历史背景（1895-1928年）
- 国术体系（九境划分）
- 势力分布（国内、国外）
- 特殊设定（系统、金手指）
- 故事舞台（绍兴、上海、北京、天津）
- 主题思想（民族自强、文化自信）

### 2. character_setting.md - 人物设定
- 主角：章闰水（闰土）
- 重要配角：鲁迅、霍元甲、黄飞鸿、孙禄堂
- 主要反派：宫本武藏、约翰逊、赵铁柱
- 其他人物：阿长、王五、林婉儿
- 人物关系图谱
- 人物成长弧线

### 3. outline.md - 卷章大纲
- **第一卷：少年崛起**（1-100章）
  - 穿越觉醒、修炼国术、击败恶霸、结识鲁迅
  
- **第二卷：江湖风云**（101-200章）
  - 闯荡江湖、加入义和团、抗击八国联军、拜师学艺
  
- **第三卷：扬我国威**（201-300章）
  - 开设武馆、万国武术大会、击败日本武士、成为宗师
  
- **第四卷：革命风云**（301-400章）
  - 参与辛亥革命、保护革命党人、军阀混战、五四运动
  
- **第五卷：武道巅峰**（401-500章）
  - 开宗立派、培养人才、抗日战争、武道巅峰

- 人物塑造技巧

- 对话设计技巧

- 应急预案
- 成功案例参考

## 快速开始

### 第一步：熟悉设定
1. 阅读 `world_setting.md` 了解世界观
2. 阅读 `character_setting.md` 了解人物
3. 阅读 `outline.md` 了解剧情走向

### 第二步：准备写作
1. 阅读 `writing_plan.md` 了解写作方法
2. 制定个人写作计划
3. 准备写作工具和环境

### 第三步：开始写作
1. 从第一卷第一章开始
2. 按照大纲推进剧情
3. 保持每日更新频率

## 写作建议

### 1. 保持节奏
- 每章2000字，保持稳定
- 每天2章，保持更新
- 每周14章，保持进度

### 2. 注重爽点
- 每章至少1个小爽点
- 每5章1个中爽点
- 每20章1个大爽点

### 3. 人物塑造
- 主角要有成长弧线
- 配角要有鲜明特点
- 反派要有威胁感

### 4. 场景描写
- 战斗场景要紧张刺激
- 修炼场景要详细具体
- 历史场景要真实可信

### 5. 读者互动
- 关注读者反馈
- 及时调整方向
- 保持良好互动

## 注意事项

### 1. 历史准确性
- 重大历史事件要准确
- 社会环境要真实
- 人物行为要符合时代

### 2. 武术描写
- 招式要具体形象
- 动作要清晰流畅
- 效果要合理可信

### 3. 情感表达
- 家国情怀要真挚
- 人物情感要真实
- 情感变化要自然

### 4. 价值观
- 弘扬正能量
- 体现民族自强
- 展示文化自信
