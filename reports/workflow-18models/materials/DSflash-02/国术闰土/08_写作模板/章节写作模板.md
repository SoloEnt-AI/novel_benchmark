# ✍️ 章节写作模板

---

## 一、章节结构

每章建议控制在 **6500-7500字**，遵循以下结构：

### 🏗️ 标准结构

```
【开头·钩子】（200-500字）
  → 用一个镜头/对话/悬念开场，抓住读者注意力
  → 通常从角色视角切入，快速带入情境

【主体·推进】（5000-5500字）
  → 剧情推进：对话、战斗、修炼、伏笔
  → 至少包含1个【爽点】或【情绪高潮】
  → 适当穿插角色内心独白

【结尾·悬念】（300-500字）
  → 制造悬念或转折
  → 用"钩子"留白，让读者想点开下一章
  → 常用手法：意外发现、强敌现身、关键情报、身份揭露
```

---

## 二、写作原则

### ✅ 每章必有的

| 要素 | 说明 | 示例 |
|------|------|------|
| **镜头感** | 一个清晰的场景开头 | "月光下，瓜田里站着一个少年" |
| **节奏感** | 长短句交错，快慢结合 | 战斗用短句，心理用长句 |
| **爽点** | 至少一个让读者"爽到"的桥段 | 打脸、突破、装逼、反杀 |
| **钩子** | 章末悬念 | "他才发现，站在面前的不是人……" |
| **金句** | 一句让人记住的话 | "练武不是为了打架，是为了不挨打" |

### ❌ 需要避免的

- ❌ 大段背景说明不推进剧情
- ❌ 角色自言自语过多
- ❌ 战斗变成"报菜名"式的招式堆砌
- ❌ 过度描写与主线无关的日常

## 三、三种常用章型模板

### 🥊 战斗章

```
【开场】对手登场/挑战发出（500字）
  → 描写对手的气场和装备
  → 围观者的反应

【对峙】气势比拼（500字）
  → 双方眼神交锋
  → 读者情绪蓄力

【激战】战斗过程（3000-4000字）
  → 分三个阶段：
    ① 试探阶段：双方互相摸底
    ② 白热化：各自使出真本事
    ③ 决胜：主角找到突破口，一击制胜

【余波】战斗后的影响（1000字）
  → 对手/观众的反应
  → 主角的感悟
  → 引出新的悬念

【结尾钩子】（300字）
  → 新的敌人出现/更大阴谋浮出水面
```

### 🧘 修炼章

```
【开场】修炼动机（500字）
  → 受刺激/遇到瓶颈/得到了新功法

【过程】艰苦修炼（4000字）
  → 站桩/练拳/打坐/实战对练
  → 汗水、肌肉酸痛、坚持
  → 师父/同门的互动

【突破】阶段性成果（1000字）
  → 不是大突破，就是小进步
  → 但要让读者感到"没有白练"

【日常】穿插主线推进（1000字）
  → 其他角色的动向
  → 主线的暗线推进

【结尾钩子】（300字）
  → 危机来临/新的任务/意外发现
```

### 🕵️ 剧情章

```
【开场】新场景/新人物引入（500字）

【对话】关键信息交换（2000字）
  → A和B的对话透露重要线索
  → 可能涉及历史背景、势力格局

【冲突】意见分歧/立场碰撞（2000字）
  → 主角与同伴/长辈/对手的理念冲突
  → 为后续剧情做铺垫

【行动】主角做出决策（1500字）
  → 根据得到的信息采取行动
  → 展现主角的性格和成长

【结尾钩子】（500字）
  → 行动带来的意外结果
  → 为下一章制造悬念
```

## 四、爽点设计速查

| 爽点类型 | 写法 | 频率建议 |
|---------|------|---------|
| **打脸爽** | 看不起主角 → 被主角实力碾压 | 每2-3章一次 |
| **突破爽** | 卡瓶颈 → 奋力一搏 → 突破成功 | 每5-8章一次 |
| **复仇爽** | 被欺负 → 隐忍修炼 → 实力碾压回来 | 每卷1-2次 |
| **装逼爽** | 低调出场 → 展现实力 → 全场震惊 | 每3-5章一次 |
| **救国爽** | 国难当头 → 挺身而出 → 拯救同胞 | 关键剧情节点 |
| **传承爽** | 收徒→教武→弟子成长→青出于蓝 | 中后期 |

## 五、章节速查清单

写作前/修改时对照：

- [ ] 开头有钩子吗？
- [ ] 章内有至少一个爽点吗？
- [ ] 章末有悬念吗？
- [ ] 主角有成长/变化吗？
- [ ] 战斗描写有层次吗？（不是单纯报招式）
- [ ] 对话有信息量吗？
- [ ] 字数控制在6500-7500字范围内吗？
- [ ] 整体节奏有起有伏吗？
- [ ] 这一章对主线有推进吗？
- [ ] 读者看完会想看下一章吗？
