# 02 世界观与国术体系

> 无系统硬核国术文的命门文档。境界、练法、国术 vs 火器规则一经写进正文，尽量不崩。

---

## 一、时代与地理

### 1.1 时间锚点（暂定）

- **魂穿起点**：约 **1900 年前後**（义和团运动余波 / 庚子前后，社会撕裂感强，便于写洋人势力与民气）
- 可微调区间：1898–1905
- 原则：大事件作背景板，主角在可见的地方史与江湖支线上立功成名

### 1.2 地图递进

| 阶段 | 舞台 | 功能 |
|------|------|------|
| 卷一 | 绍兴乡野 / 鲁镇一带 | 立足、拜师、小打脸、明劲初成 |
| 卷二 | 绍兴县城 / 杭州 | 擂台、武馆、教会买办初交锋 |
| 卷三 | 上海租界与华界 | 十里洋场、国术破枪成名 |
| 卷四 | 京津 / 北方乱局 | 更大格局、军阀萌芽、暗劲大成 |
| 卷五 | 全国巡回 / 南洋等 | 国术论战、实业+武学 |
| 卷六 | 总决战舞台 + 归乡余韵 | 化劲/宗师、主题收束 |

### 1.3 势力板（简化）

1. **乡土层**：乡绅、族长、地痞、县衙胥吏、贫农雇工
2. **江湖层**：门派、镖局残脉、会党、草莽拳师
3. **洋人层**：教会、洋行、租界巡捕、退役军人/拳手、领事阴影
4. **买办层**：译员、买办、假洋人、“以洋自重”的新派恶徒
5. **时局层**：清廷地方官、革命党线索、新军/军阀萌芽（中后期）

## 二、国术力量阶梯（核心）

不以数字等级，而以**可感知质变**划分。读者应能通过描写分辨主角到了哪一层。

### 2.1 五境总表

| 境界 | 关键词 | 外在表现 | 大致剧情位置 |
|------|--------|----------|--------------|
| 一、强身 | 皮、肉、筋、骨、呼吸 | 耐打耐造，力大身捷，病少，能长时间苦练 | 开篇→卷一前中 |
| 二、明劲 | 整劲、形显、一击有声 | 拳风可闻，击中如槌，能将人掀飞；桩马稳如铸 | 卷一中后→卷二 |
| 三、暗劲 | 触手即发、冷劲、透劲 | 外表不大开大合，对手内腑/关节已伤；借力打力 | 卷三→卷四 |
| 四、化劲 | 引进落空、听劲、身知 | 近身几乎“粘”住对手，力大者反而跌出；预判机先 | 卷四末→卷五 |
| 五、拳入神明（宗师） | 知机、意在拳先、武德与武技合一 | 不神化飞天；而是判断、距离、人心、战场直觉臻绝 | 卷五末→卷六 |

### 2.2 各境修炼重点（写作素材）

**强身**
- 桩功、跑步、肩臂腰腿、翻筋、排打（适度）、睡眠与食补
- 前世记忆加成：间歇训练、呼吸法、伤病护理、蛋白质/营养常识（用时代物替代，如蛋、骨汤、鱼、豆）
- 反馈描写：睡得沉、劲往骨子里长、冬天不那么怕冷、刺猹/干活不喘

**明劲**
- 整劲：脚-膝-胯-腰-背-肩-肘-手一条线
- 试力、打沙袋（或米袋）、木人、推手入门
- 反馈：击中木柱嗡鸣、对手眼白翻起、自己拳头反震变小

**暗劲**
- 松沉、爆发藏在接触点之后
- 短打、靠身、肘膝、擒跌
- 反馈：对手“挨了像没挨，走两步内脏翻涌”；衣服不破人已伤

**化劲**
- 听劲、走劲、化打合一
- 反馈：四两拨千斤不再是口号；枪刺、刺刀在近身被带偏

**宗师**
- 不靠玄幻，靠：无数实战沉淀 + 对人与武器的理解 + 传火（教徒弟、立规矩）

### 2.3 成长节奏（100 万字）

- **小突破**：几乎每章或每几章都有（一个动作更顺、一场架打得更巧）
- **中突破**：约每 5–8 万字（击败某类对手、掌握某类劲/器械）
- **大境界质变**：约每 15–20 万字，放在卷末或卷中高潮后

## 三、主角国术路线（暂定）

> 可定为“杂学成家”，更符合无门派开挂、靠悟性整合的人设。

### 3.1 根基来源

1. **乡土底子**：跑、跳、甩杆、刺猹、识踪迹、忍饥耐寒（原身）
2. **引路人传授**：建议一位隐世/没落的实战派拳师（形意/心意/八卦/炮拳/本地连手等，选定一种为主）
3. **前世认知**：现代训练逻辑、对抗策略、解剖常识（转化为“怎么练更快、怎么少受伤”）
4. **实战偷师**：会党、镖师、军中武弁、甚至洋拳的架势——只学有用的，不跪着学

### 3.2 主修建议（写作时锁定一主多辅）

- **主**：形意/心意一路（刚猛整劲，好写热血，破甲破势感强）
- **辅**：本地摔跌、棍法/矛法（破枪过渡）、短兵
- **中后期**：融入更细的化劲、枪刺克制、群体战术

### 3.3 标志性意象（闰土符号转化）

| 原典意象 | 转化用法 |
|----------|----------|
| 月夜看瓜 | 开篇穿越、夜间感知、警戒力 |
| 项圈/银项圈 | 身世信物或护身记忆锚点 |
| 钢叉刺猹 | 器械启蒙、直线刺杀、胆气 |
| 雪地捕鸟 | 耐心、陷阱、观察力 |
| 海边检贝 | 可作童年闪回，衬托命运分叉 |

## 四、国术 vs 火器（硬规则）

### 4.1 总原则

**国术不能废枪，但能在特定条件下胜过持枪者。**  
胜的是“人、距离、时机、环境、器械与意志”，不是神话肉体。

### 4.2 可胜条件（正文反复可用）

1. **近距**：已经贴身，枪来不及举平/拉栓/开枪
2. **猝袭**：盲区、夜色、烟雾、人群、转角
3. **器械**：长杆、飞叉、刀、暗器干扰瞄准
4. **心理**：持枪者胆怯、傲慢、训练不足
5. **环境**：雨天受潮、狭窄弄堂、船舱、楼梯
6. **团队**：一人夺枪、一人制敌，或弓弩/土炮协同（中后期）

### 4.3 不可胜 / 必吃亏（保持紧张感）

1. 开阔地正面冲刺面对已瞄准的步枪/排枪
2. 机枪、火炮覆盖（个人武勇只可救局部，不可硬抗）
3. 远距离被多名训练有素的枪手点名
4. 重伤、饥饿、无掩体时的硬刚

### 4.4 描写禁忌

- ❌ 子弹手拍飞子弹  
- ❌ 肉身抗连发无损  
- ❌ 一掌震死穿军装的洋军队长并炸营  
- ✅ 可以：带伤胜、险胜、智胜、惨胜；胜后发烧吐血、筋骨损伤

## 五、练功资源与代价

### 5.1 资源

- 食：蛋、骨汤、鱼、豆、少量肉；后期药膳
- 场：瓜地、祠堂后院、破庙、武馆、船舱
- 器：沙袋、石锁、木人、铁砂（慎）、长枪杆
- 人：名师一语、对手压力、同门切磋
- 时：每日辰时/夜半固定功课（形成仪式感）

### 5.2 代价

- 骨膜炎式的疼、旧伤、发烧
- 钱与粮的压力（逼主角接护院、打擂、做苦力）
- 走火：只求快而崩劲、伤肩伤腰（用一次教训即可）
- 树敌：成名即成靶

## 六、战力对照（方便写对手）

| 层级 | 代表 | 约等于主角何时可稳胜/险胜 |
|------|------|---------------------------|
| 地痞流氓 | 3–5 人围殴 | 强身后期–明劲初 |
| 乡勇/衙役好手 | 单挑有章法 | 明劲 |
| 门派中坚 | 十年拳架子 | 明劲圆满–暗劲初 |
| 一流拳师 | 走镖/擂台成名 | 暗劲 |
| 洋拳手/巡捕高手 | 体能+格斗+枪械意识 | 暗劲后–化劲，多靠战术 |
| 武装小队 | 多人持枪 | 永远不能无脑冲，靠计与环境 |
| “象征性大敌” | 某洋行武装头目/武斗权威 | 卷末规格，可胜但惨 |

## 七、世界观写作注意事项

1. 方言点到为止，求神韵不求全文方言。
2. 租界、教会、洋行细节求“像”，不考据到拖节奏。
3. 每个新地图先给 **感官锚点**（气味、声音、路、吃的）。
4. 国术名词第一次出现要有画面，不要只扔术语。
