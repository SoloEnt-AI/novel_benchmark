# 主角卡：闰土（魂穿）

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 闰土（原名可按乡俗带姓，正文常用“闰土”） |
| 身份 | 绍兴乡间少年 → 国术传承者 → 武馆/民族气节象征 |
| 穿越方式 | **魂穿**（占据原身，融合部分原身记忆与情感） |
| 年龄（开篇） | 约 14–16 岁（少年体，便于长线成长；可按你喜好微调） |
| 外貌 | 紫色圆脸底子、头戴小毡帽意象可改写；穿越后眼神渐冷渐定，身子由瘦韧练成筋骨匀停 |
| 气质 | 外拙内韧，话少，动手快，护短 |

## 二、双重灵魂结构

### 2.1 原身·闰土

- **家庭**：父亲为底层雇工/忙月类角色（可戏剧化）；家境贫寒；有需要守护的亲人线（母亲/幼弟等，按大纲设）
- **技能底子**：看瓜、识兽踪、甩钢叉、跑路、忍饿、干粗活、对土地与天气的直觉
- **性格底色**：羞涩、懂事、对“老爷/迅哥儿”阶层有天然距离感——穿越后逐渐被“不跪”的灵魂改写，但乡土礼数仍在
- **创伤点**：被轻视、被夺走、被命运按在田垄上

### 2.2 穿越者（前世）

> 暂定方案（可改）：**现代体育生 / 业余传统武术爱好者 + 喜欢晚清史与战术纪录片的普通人**

**提供什么（金手指边界）：**
- ✅ 科学化训练思路（循序渐进、恢复、呼吸、核心稳定）
- ✅ 基本人体结构常识（哪里不能瞎练、击打效果）
- ✅ 对火器时代的敬畏与战术意识（不送死）
- ✅ 现代平等观、卫生观、组织观的萌芽
- ❌ 不提供：完整历史剧透开挂、化学造枪造药速成、金融收割全世界
- ❌ 不提供：系统、商城、突然天降神功

**性格注入：**
- 不服输、要脸、有底层同情心
- 对“跪洋人”极度厌恶
- 初期会因现代思维与时代碰撞出喜剧/冲突感，但整体偏热血正剧

### 2.3 融合原则

- 开篇 1–3 章完成“我是谁”的确认，不长期人格分裂戏
- 原身情感（对亲人、对土地）保留，作为护短动力
- 穿越者理性（怎么练、怎么打、怎么布局）主导成长

## 三、性格标签

| 标签 | 表现 |
|------|------|
| 硬 | 能扛疼、能吃苦、肯下桩 |
| 韧 | 输得起，隔夜就练，记教训 |
| 拙 | 不善官场话术，初期吃亏 |
| 准 | 盯目标极狠，一旦决定动手不拖 |
| 护短 | 家人、师父、同门、乡亲被欺会炸 |
| 要脸 | 不是虚荣，是“中国拳不能在我这儿丢人” |

**缺陷（必须保留，供冲突）：**
1. 初期识字有限、眼界窄  
2. 对士绅规则、洋场规矩不熟  
3. 护短易冲动（需师父/搭档拉一把）  
4. 成名后易被“个人英雄主义”诱惑——中期要学会带人、布局  

---

## 四、欲望阶梯（主线发动机）

1. **活下去**：伤病、饿、地痞、意外  
2. **改命养家**：钱、粮、房子、亲人尊严  
3. **拜师入道**：得到真东西，不是花架子  
4. **成名立馆**：有地方练、有人认、有话语权  
5. **打落洋人气焰**：从具体恶人到象征性权威  
6. **国术传火**：徒弟、规矩、让后来者不必跪着活  

每一卷至少满足/推进其中 1–2 阶，并露出下一阶的钩子。

## 五、能力成长轨迹（摘要）

| 阶段 | 能力侧重点 | 标志事件（示例） |
|------|------------|------------------|
| 开篇 | 原身底子+自觉练功 | 月夜危机中第一次“用对了力气” |
| 卷一 | 强身→明劲 | 乡里大打脸，救亲/护瓜/反霸 |
| 卷二 | 明劲稳固+器械 | 县城擂台，初遇洋枪/教会爪牙 |
| 卷三 | 暗劲+破枪战术 | 租界成名战 |
| 卷四 | 暗劲大成+带队 | 北方乱局中护民/护厂 |
| 卷五–六 | 化劲→宗师 | 打落时代级“洋权威”，立传火 |

详细境界见 `02_世界观与国术体系.md`。

## 六、人物关系（主角中心）

```
                    〔亲人〕
                       │
〔师父·引路人〕—— 闰土 ——〔搭档/同门〕
                       │
              〔镜像反派·假洋人〕
                       │
              〔洋人势力梯度敌人〕
```

- **师父**：给规矩、给真劲、给“武德与脊梁”  
- **搭档**：补短板（识字、洋文、商业、枪械知识）  
- **镜像反派**：同样年轻、甚至也练过拳，但选择认洋人做爹  
- **情感线（可选）**：一条主线即可，见配角文档  

---

## 七、语言与行为特征（方便写对话）

- 短句，少成语堆砌；急了会冒乡土比喻  
- 动手前常先看地势、看远近、看有没有枪  
- 赢了不废话，先看自己人有没有受伤  
- 对洋人/买办的蔑视语，不写脏到出戏，写到“硬气”为止  

**口头禅/反复动作（可选固定）：**
- 攥拳时拇指捏在食指侧（明劲习惯）  
- 战前用脚尖点地测深浅  
- “先活着，再说话。”

| 时期 | 我是谁 |
|------|--------|

| 前中 | 能打的乡野少年 |

**终点不是“天下第一”，而是：这片土地上的拳头，值得这个价钱。**

## 九、开篇人设三章检验

读完前三章，读者应能回答：

1. 他是谁？（魂穿的闰土）  
2. 他要干什么？（活下去、变强、别再被踩）  
3. 他凭什么？（肯练、会练、有胆）  
4. 为什么追更？（第一次打脸/危机钩子已抛出）
