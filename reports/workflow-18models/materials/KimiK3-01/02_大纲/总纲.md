## 卷一 月下少年（1889–96，绍兴）

**弧光**：接受闰土身份 → 守护小家 → 甲午之痛立大志。

| 章群 | 内容 |
|---|---|
| ch001–003 | **黄金三章**：瓜田刺猹（魂穿觉醒战）→"我是闰土"→村外来了个伤腿老兵 |
| ch004–015 | 死缠拜师赵破虏；桩功筑基；母病采药（现代知识首用）；竹器改良破金润泉压价；教训孙二赖打手（首战小爽） |
| ch016–025 | 1893大祭祀值年：进周家、初见迅哥儿、雪地捕鸟、月下讲猹；互赠信物（竹刻猹↔《剑南诗稿》）；冬，周家科场案发，主角护送当物挡羞辱；正月别离（原著哭别改写） |
| ch026–040 | 甲午：战报南来，赵破虏醉酒泣血（辽东旧创）；马关条约，城中看客；孙二赖勾洋行爪牙趁乱报复→师徒联手退敌（卷一武戏高潮）；宁波访内家拳残谱（"以静制动"伏笔） |
| ch041–050 | 周伯宜病逝线（寻药、当铺之辱暗中出手）；赵破虏起北返之念（埋卷二）；主角决意北上求艺；摘下银项圈留家（仪式）；卷尾钩子：深州枣林，一排三体式桩架，为首老者 |

**悲点**：甲午之败（国）；周家败落（家）。
**爽点**：刺猹、改良竹器打脸金润泉、桩功惊武举（县试场小爽）、退洋行爪牙。

## 卷二 华北风雨（1895–1900，深州/京津）

**弧光**：学艺成人 → 戊戌庚子两次"打不过历史" → 血火淬炼。

| 章群 | 内容 |
|---|---|
| ch051–065 | 深州拜李存义；三体式苦修三年（跳时写法）；郭云深一面之缘（"崩拳如射箭"）；明劲小成；与迅哥儿书信之一（南京水师学堂） |
| ch066–078 | 随镖走江湖；京城源顺镖局，王五登场；程廷华点拨走转；护镖战马匪=明劲大成之战（大爽） |
| ch079–090 | 戊戌：谭嗣同与王五夜话；政变；六君子菜市口；主角随王五收尸——"全知的无力"第一次拷打（他早知道会败）；赵破虏北返重逢 |
| ch091–102 | 义和团起：铁罗汉"神功"敛财；主角当众戳穿"刀枪不入"（祛魅爽点）；民教冲突的两面（恶霸教民vs无辜教民）；山雨欲来 |
| ch103–110 | **庚子总高潮**：天津老龙头血战（李存义单刀参战，据传说演绎）；赵破虏之死+遗训；主角重伤格杀冯·克劳斯（全书首次"拳胜枪"，惨烈）；暗劲萌芽；程廷华、王五殉国（收尸线）；卷尾钩子：辛丑前夜，天津废墟上传来一个名字——霍元甲 |

**悲点**：六君子、赵破虏、程廷华、王五。
**爽点**：护镖成名战、戳穿神功、格杀克劳斯。

## 卷三 津门拳锋（1901–08，天津/绍兴）

**弧光**：立足成名 → "拳打在人身上，要响在人心里"。

| 章群 | 内容 |
|---|---|
| ch111–125 | 辛丑之痛（"量中华之物力"）；押镖教拳立足；1901俄力士斯其凡洛夫事件——霍元甲登场（史实改编），主角助拳结交；张占魁同门切磋；暗劲小成 |
| ch126–140 | 黄包车夫命案→日租界小野道馆→**踢馆**（本卷明面高潮）；金润泉在租界重现被打脸（卷一伏笔收）；麻皮阿四伏法；道馆幕后浮现"监察官"影子（高柳线首次显形） |
| ch141–150 | 日俄战争在中国国土开打；难民与看客；主角暗护抗日志士出关；"幻灯片"先声（迅哥儿书信之二） |
| ch151–162 | 回乡：大通学堂、秋瑾、**谢蕴秋登场**；徐锡麟安庆事败→秋瑾轩亭口就义（救不及，本卷悲点）；谢蕴秋北上安置（武士会女教习伏笔） |
| ch163–170 | 沉淀：收徒、名动京津；李存义首倡"武士会"之议；卷尾钩子：上海来信——张园来了个英国力士，口出狂言 |

**悲点**：秋瑾。**爽点**：踢馆、打脸金润泉、慑退俄力士的余波。

## 卷四 精武之魂（1909–12，上海）

**弧光**：精武同袍 → 霍元甲之死 → 从"打洋人"升维"立精神"。

| 章群 | 内容 |
|---|---|
| ch171–182 | 张园奥皮音事件（史实框架：未战先怯）；农劲荪登场；谢蕴秋重逢定情；虹口浪人夜袭——**"叉剑和鸣"双打名场面** |
| ch183–200 | 1910精武体操会创立；日本柔道会挑战（传说演绎）→胜；霍元甲病、毒案疑云、**殁**（本卷悲点，死不救） |
| ch201–208 | 暗线追查：证据链→虹口道场→**暗劲毙秋野**（半虚构复仇，爽点）；幕后主使"高柳"浮出水面（大反派正名）；化劲门槛初触 |
| ch209–220 | 辛亥：武昌枪声；李存义天津创中华武士会；南北呼应；**绍兴重逢迅哥儿**（对照原著场景重写，泪+爽："闰土哥，你来了。"）；卷尾钩子：民国的旗升起来了，可路呢？ |

**悲点**：霍元甲。**爽点**：奥皮音慑退、胜柔道会、手刃秋野、重逢改写。

## 卷五 国士无双（1913–19，南北/北京）

**弧光**：宗师化劲 → 武之路与文之路相认。

| 章群 | 内容 |
|---|---|
| ch221–235 | 南北游历：访孙禄堂得太极听劲，三家合一之路；军阀乱局中的国术凋零；与谢蕴秋成婚；水生出生（1913） |
| ch236–250 | 1915二十一条；著书立说（呼应孙禄堂《形意拳学》）；高柳遣弟子登门"交流"（试探战，小爽）；与激进学生辩论"国术救国"（文戏） |
| ch251–262 | 新文化潮起：北京教育部，迅哥儿抄古碑的沉默（《呐喊·自序》素材）；**"铁屋子"夜谈**（核心文戏；主角的心魔峰值：不能剧透） |
| ch263–276 | **1918双高潮**：康泰尔中央公园设擂——王子平、韩慕侠正面破之（史实光环），主角断其幕后金主；**破化劲，决战高柳**（全书武戏顶点）；同年，《狂人日记》发表——夜读泪下："他的笔里，有我递的刀。" |
| ch277–280 | 五四前夜→五四：护学生；卷尾钩子：绍兴来信——迅哥儿要回乡接母 |

**悲点**：二十一条、国术凋零。**爽点**：康泰尔擂、决战高柳、《狂人日记》。

## 卷六 故乡（1919–21，绍兴）

**弧光**：放下与交棒 → 见证《故乡》→ "路"留给下一代。

| 章群 | 内容 |
|---|---|
| ch281–295 | 陪同迅哥儿回乡接母：乌篷船、荒村、老屋——**对照原著逐场改写**（这次船上有闰土哥）；杨二嫂的市侩、双喜阿发的世故（阶层对照）；老父章福庆；《药》刊出，主角认出"人血馒头"出自自己的信 |
| ch296–305 | 五四余波里的少年中国：水生站桩（六岁）；谢蕴秋办女学；韩慕侠彩蛋（南开来信的周姓学生）；主角悟"路" |
| ch306–314 | 1921李存义善终：侍疾送终，临终不传拳谱传一个"武"字；"国术馆"之种（续作钩子） |
| ch315–320 | **收束**：《故乡》发表；鲁迅书桌上摆着竹刻猹；月下瓜田重演——两个四十岁的男人并肩，"深蓝的天空中挂着一轮金黄的圆月"；终章点题："其实地上本没有路，走的人多了，也便成了路。"水生喊爹，主角回头："站着。" |

**悲点**：李存义（善终，哀而不伤）。**爽点**：全书主题总兑现。

## 写作纪律

- 每卷开写前：查 `01_设定/历史年表.md` 锁死时间窗；查 `04_台账` 确认伏笔状态。
- 爽点节奏：3章一小爽、10章一大爽；悲点后三章内必有暖场或反击，不沉溺。
- 史实人物死亡节点不可动；主角的胜利全部来自个人线。
