# 人物卡：迅哥儿（周树人）

> **定位**：灵魂配角，主题锚点。全书暗线——主角打碎的每一片"厚障壁"，
> 最终都由他的笔来见证。
> **红线**：不写崩。他可以被影响、被守护，但他必须长成那个写出《呐喊》的人。

## 史实骨架（不可动的节点）

| 年份 | 事件 |
|---|---|
| 1881 | 生于绍兴东昌坊新台门周家 |
| 1893 | 祖父周福清科场案发下狱，家道中落（原著大祭祀值年亦在此年前后） |
| 1896 | 父周伯宜病逝；四年出入当铺与药铺，"有谁从小康人家而坠入困顿的么" |
| 1898 | 入南京水师学堂（后改矿路学堂） |
| 1902 | 赴日，入东京弘文学院（嘉纳治五郎创办——**史实：鲁迅在此学过柔道**，彩蛋必用） |
| 1906 | 仙台"幻灯片事件"，弃医从文 |
| 1909 | 回国 |
| 1910 | 任教绍兴府中学堂 |
| 1912 | 入教育部，迁北京 |
| 1918 | 《狂人日记》发表，"鲁迅"笔名出世 |
| 1919.12 | 回绍兴接母迁京（《故乡》素材之行） |
| 1921 | 《故乡》写成（1月）、发表（5月，《新青年》九卷一号） |

## 与主角的关系线

- **称呼**：他叫主角"闰土哥"，主角叫他"迅哥儿"——**终生不变**。
  这是全书与原著最大的对照：原著里那声"老爷"，本书里永远不必出口。
- **1893初见**：大祭祀值年。原著场景全还原：雪地捕鸟、看管祭器、瓜田与猹——
  但这次，讲猹的人是**真在月下刺过猹**的人。临别互赠：竹刻猹 ↔ 手抄《剑南诗稿》。
- **1893–96周家大难**：主角以农家子+少年武人身份相助——护送当物、雪夜寻药、
  挡住讨债人的羞辱。**不改家败，只护尊严**（史实节点不可动，缝隙里见真情）。
- **1898–1909分离期·书信线**（每卷2–3封，作结构件）：
  - 主角的信：华北风雪、戊戌之血、庚子之火、拳民愚昧、人血馒头……
    **全是日后《呐喊》的矿藏。**
  - 迅哥儿的信：南京、东京、幻灯片。迷茫与抉择都写给远方的闰土哥。
- **1911绍兴重逢**：对照原著"中年重逢"场景重写——
  没有灰黄的脸和"老爷"，只有一句："闰土哥，你来了。"
- **1918《狂人日记》**：主角夜读样刊，认出"吃人"的细节来自自己的信——
  全书最隐秘、最高级的爽点：**他的笔里有我递的刀。**
- **1919–21同归故乡**：主角全程陪同。《故乡》诞生——但这一次，
  闰土哥的叉还在，腰是直的。

## 功能场景清单（写作时调用）

1. 初见名场面（卷一）
2. 当铺之辱与主角暗中出手（卷一暗线）
3. 书信蒙太奇（卷二至卷五，每卷2–3封）
4. 人血馒头见闻 →《药》的种子（卷二）
5. 重逢改写（卷四末，泪点+爽点）
6. 《狂人日记》样刊（卷五）
7. 回乡与《故乡》（卷六，全书收束）

## 塑造要点

- **少年**：好奇敏慧；家败催出早慧与冷峭。他不哭，他记。
- **青年**：沉默锋利，在"医身"与"医心"之间挣扎。主角的存在，
  让他亲眼看见一个"身体站直了"的国人样本——这比一百篇文章更有说服力。
- **他不是主角的附庸**：他的战场在纸上。两人是同一个民族的两条路——
  武之路与文之路，卷五相认，卷六合一，落回原著那句：
  "走的人多了，也便成了路。"

## 禁止事项

- 不得让他习武、不得让他变成爽文打手
- 不得让他提前"觉醒"而省略迷茫（迷茫是他成为鲁迅的路）
- 不得让主角向他剧透"你将来是文豪"——守护不是导演
