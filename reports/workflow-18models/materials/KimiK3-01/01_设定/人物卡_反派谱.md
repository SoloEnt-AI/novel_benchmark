# 人物卡：反派谱

> **总原则（红线）**：所有"打洋人"戏份挂载**具体恶行**——主角打的是作恶的个体
> 与侵略的机器，不是某个民族。每场冲突先立正当性，再给爽感。
> 梯度设计：恶人级别随卷升级，且**华人败类往往比洋人更可恨**（鲁迅式批判）。

## 长线大反派：高柳辰雄（虚构 · 贯穿卷二至卷五）

| 项 | 内容 |
|---|---|
| 身份 | 日本陆军省武术监察官，柔道、剑道双修；随军武道观察团首领 |
| 登场线 | 卷二：庚子年随联军入华北，冷眼镜记录中国武术（伏笔，主角不知其名）→ 卷三：日租界柔道馆的幕后主人 → 卷四：霍元甲毒案的总策划 → 卷五：1918年北京，全书武戏决战的对手 |
| 人物逻辑 | 不是脸谱化的疯子。他真心尊重武道，因此更认定"武道该由强者之邦执掌"——**他是"武"字被军国主义偷走的化身**。主角打死他，打的是这个"偷"字 |
| 败亡 | 1918年，败于破化劲的主角。临死一句点题（待写）：他到死都在问"中国人为什么还站得起来" |
| 红线备注 | 书内须明写：恨的是军国之刀，非日本之民（可安排一日本平民/反战者小角色作对照） |

|---|---|---|---|
| 一 | 教民恶霸·孙二赖（虚构） | 依仗教堂势力横行乡里，强占水田、打伤竹匠（威胁主角家计）——民教冲突的乡村缩影 | 少年主角以桩功+智计小胜；埋"洋人→教案→义和团"的远雷 |
| 一 | 洋行买办·金润泉（虚构） | 压价收购竹器、引洋钉洋货挤垮本地手工业（章福庆生计线） | 主角改良竹器破局（小爽）；此人卷三可在租界重现被打脸 |
| 二 | "大师兄"·铁罗汉（虚构） | 义和团坛口首领，借"神功"敛财、私杀教民妇孺、吞义民捐银——愚昧+贪腐的化身 | 主角当众戳穿其"刀枪不入"（祛魅戏）；死于庚子乱军，讽刺收场 |
| 二 | 联军军官·冯·克劳斯（虚构） | 德军少尉，拳击手出身，以射杀拳民为"狩猎游戏"；枪杀程廷华一线的关联者 | 庚子血战中被主角以重伤代价格杀——全书第一次"拳胜枪"（贴身咫尺，惨烈而非爽） |
| 三 | 柔道馆主·小野（虚构） | 天津日租界道场馆主，纵容弟子打死华人黄包车夫，官府不敢问 | 主角踢馆（明面上的高潮）；其背后牵出高柳（暗线升级） |
| 三 | 租界巡捕头目·麻皮阿四（虚构） | 华人，吃租界饭，比洋人更狠地欺压同胞——"做戏的虚无党"式人物 | 伏法于国人手中；鲁迅式批判的载体 |
| 四 | 奥皮音（史实改编） | 英国马戏力士，"东亚病夫"羞辱的具体化身（非大恶，是"面子之战"） | 史实框架：未战先怯/被慑退；不丑化，写足"力士也是吃血汗饭的" |
| 四 | 秋野（史实悬案改编） | 日本医生，霍元甲之死的传说元凶 | 主角暗线追查、手刃元凶（半虚构，注明演绎）——给读者一个交代，不给历史一个假案 |
| 五 | 康泰尔（史实传说改编） | 俄国流亡力士，北京摆擂连败武师，辱"支那无人" | 王子平/韩慕侠正面破之（史实光环），主角断其幕后黑手 |
| 五 | 高柳辰雄 | 见上 | 全书武戏顶点决战 |
| 六 | 无武力反派 | **"厚障壁"本身**：杨二嫂式的搬弄、官绅的盘剥、看客的麻木 | 文戏呈现；呼应《故乡》《药》《狂人日记》的批判——武已立，文来收 |

## 写作纪律

1. 每个反派出场时，在 `04_台账/伏笔台账.md` 登记其恶行证据与退场方式。
2. 反派可以强、可以狡，**不可蠢**——蠢反派拉低主角胜利的含金量。
3. 高柳线从卷二就要埋线（名字、徽记、目击），卷五收束，跨四卷的大伏笔。
