# 时代年表 · 清末民初历史与剧情对照

## 使用说明

- 主角**章运水（乳名闰土）**设定生于 **1879年**（原型章运水约生于1879年，比鲁迅长两岁）
- "剧情映射"为小说主线锚点；历史大事件尽量贴合史实，细节处允许架空演绎
- 铁律：**大事不虚，小事不拘**

## 关键史实备忘（写作时勿出硬伤）

- **王五之死**：1900年，死因众说纷纭（联军所害/德军枪杀），本书取"庚子乱中殉难"
- **奥皮音事件**：1909年，英国大力士奥皮音在上海阿波罗影院设擂挑衅，霍元甲应邀赴沪，奥皮音未赛而逃——史实本身已是爽文模板，可直接化用
- **霍元甲之死**：1910年9月，传被日本柔道会医生秋野下慢性毒，本书采"慢性毒"说并留悬念
- **精武体操学校**：1910年6月创办，陈其美、农劲荪等支持
- **周树人时间线**：1898南京水师学堂 → 1902赴日 → 1904仙台医专 → 1906弃医从文 → 1909回国 → 1918《狂人日记》 → 1921《故乡》
- **章运水（原型）**：家贫，约1934年去世——本书将彻底改写其命运，"闰土不再叫迅哥儿'老爷'"是全书主题的兑现点
- **章家关系**：父章福庆（竹匠，兼周家忙月），母章阮氏（曾为周家帮佣，即鲁迅笔下"长妈妈"的原型之一，可作彩蛋使用）
