# 《穿越闰土·国术征洋》核心设定总览

> **类型**：穿越 + 国术 + 清末民初 + 热血爽文 + 家国情怀
> **字数**：100 万字（精炼长篇）
> **结构**：三卷制，每卷 30-35 万字
> **连载**：存稿 20-30 万字启动

---

| 候选 | 风格 |
|------|------|
| 《闰土》 | 极简文艺，厚重大气 |
| 《国术闰土》 | 直观，类型辨识度高 |

## 二、核心设定一句话
> 21 世纪国术爱好者"陆沉"魂穿到鲁迅笔下的少年闰土身上，携带【国术推演系统】，在清末民初的乱世中一步步从沙地少年成长为一代国术宗师，在擂台上打洋人、在江湖中正武学、在国难中守中华。

---

## 三、世界观：清末民初（1900-1920）

### 时代切片
- **1910-1913（第一卷）**：辛亥革命前后，浙东沙地
  - 武馆凋敝，新式学堂兴起，老拳师隐于民间
  - 乡绅、买办、巡捕房三股势力盘根错节
  - 民间私斗成风，乡间擂台盛行
- **1913-1918（第二卷）**：民国初建，省城与上海
  - 武馆复苏，"国术救国"思潮涌动
  - 租界洋人挑衅，擂台外交白热化
  - 留洋归来者引入西洋拳击、柔术
- **1918-1920（第三卷）**：军阀混战，武道碰撞
  - 北方形意、八卦、太极三派鼎立
  - 东洋"杀人技"渗入，军部培养武士
  - 南北武林大会、"打洋擂台"成为时代符号

### 社会风貌
- 服饰：长袍马褂、对襟短打、瓜皮帽、布鞋草鞋
- 武器：朴刀、红缨枪、匕首、练功石锁、桩子
- 物价：1 银圆 ≈ 1 户 3 口月伙食；武师月入 3-5 银圆
- 地标：浙东沙地（虚构）、绍兴府、杭州武林门、上海外滩、北京前门

## 四、主角设定

### 陆沉（魂穿后身份：闰土）
| 维度 | 详情 |
|------|------|
| **真身** | 21 世纪国术爱好者，业余练形意 8 年，研究大量民国武术资料 |
| **穿越形态** | 灵魂替换，保留现代全部记忆，原作闰土少年时期的躯体 |
| **年龄** | 开篇 16 岁（原作"我"与闰土第一次见面的年纪） |
| **性格** | 沉稳、隐忍、有现代人的思辨；骨子里是"想改写闰土悲剧命"的执念 |
| **金手指** | 【国术推演系统】—— 详见下方 |
| **目标线** | ①改命（改写原作悲剧） ②强国（打洋人扬国威） ③明道（国术至高境界） |

### 主角与原作闰土的关系
- **躯壳**：闰土（章贵）的少年身体
- **灵魂**：陆沉（现代人）
- **本心**：用陆沉的现代知识+国术理论，让"闰土"这个名字不再被生活压垮
- **执念核**：原作最痛的那句"他站住了，脸上现出欢喜和凄凉的神情……"——这是他穿越的全部动力

## 五、金手指：【国术推演系统】

### 系统来源
> 陆沉魂穿瞬间，识海中浮现一块古铜色面板，署名"先秦方士所遗、历代宗师血祭而成"，自称"国术推演系统"。
> 系统绑定于神魂，无法被外人察觉。

### 五大属性面板

| 属性 | 含义 | 初始值（明劲前） |
|------|------|------------------|
| **根骨** | 筋骨皮膜资质，决定修炼速度上限 | 7/100（凡人偏上） |
| **悟性** | 招式理解、推演效率 | 9/100（高于常人，源自现代知识储备） |
| **气血** | 体能、内脏强度，决定持久战与抗打 | 6/100 |
| **暗伤** | 累积伤害，可被推演/疗伤手段化解 | 0/100 |
| **推演点** | 拆解、优化、融合招式的"经验值"货币 | 10（开局赠送） |

### 推演点获取途径
- **实战** +1~5 点/场（越级战斗奖励翻倍）
- **悟拳**（打坐/站桩时灵光一闪）+1~3 点
- **任务完成**（隐藏任务"扬我国术"） +10~50 点
- **教学**（教会他人且对方精进）+0.5~2 点
- **挨打**（主动挨打悟防守）+1~2 点

### 系统核心功能
1. **【招式拆解】**：消耗推演点，将对手的招式或师父教的动作拆解成"动作-发力-破绽"三维
2. **【发力优化】**：对自身已学招式进行微观调整，1 推演点=优化 1 处发力
3. **【百家融合】**：消耗大量推演点，可将两门以上招式融为一招
4. **【境界试炼】（隐藏）**：每个大境界的"破境关卡"提供模拟对手供挑战
5. **【扬我国术】（隐藏任务线）**：击败外籍拳师/破擂台纪录/正武林败类 触发

### 系统使用限制
- **不直接给力量**：系统只是"推演工具"，实力源于自身修炼
- **不告知未来**：历史走向对陆沉是"模糊预言"而非精确剧情
- **有代价**：高强度推演会损气血、生暗伤
- **师承为本**：系统无法替代师父喂招、实战挨打

### 系统的爽点设计
- **每战有成长**：哪怕是挨打，掉血也掉推演点
- **有"装备"感**：属性面板让读者有 RPG 升级爽感
- **有"教学"线**：主角传拳他人，自己也有收益
- **不喧宾夺主**：战斗场面仍以血肉感、招式感为主，系统只在"幕后"

## 七、力量平衡铁律
1. **越级必败**：明劲打暗劲不偷袭绝无胜算
2. **暗伤可见**：强压境界会留下暗伤，影响后续突破
3. **气血为根**：技巧再高，气血不足也撑不过三分钟
4. **流派相克**：形意破八卦、太极破形意、八极克摔跤（实战派逻辑）
5. **洋人有秘术**：英拳击、法踢拳、日柔术各有杀手锏，不可只靠属性碾压

## 八、卷章节奏

### 📕 第一卷【沙地立骨】 30-35 万字
**主舞台**：浙东沙地（虚构，参照绍兴）
**时间线**：1910-1913
**境界推进**：凡人 → 明劲巅峰
**核心爽点**：觉醒系统、拜师学艺、擂台初胜、结识迅哥儿
**卷末 BOSS**：清末武举人后裔·杜秀才（明劲巅峰 + 暗器）

### 📗 第二卷【擂台撼洋】 30-35 万字
**主舞台**：杭州、上海
**时间线**：1913-1918
**境界推进**：明劲巅峰 → 暗劲大成
**核心爽点**：武馆扬名、外滩旁打洋人、暗劲破境、家国冲突
**卷末 BOSS**：英国远东拳击冠军"铁拳马库斯"（暗劲巅峰 + 西洋拳击秘术）

### 📘 第三卷【宗师之路】 30-35 万字
**主舞台**：武当山、北京、上海
**时间线**：1918-1920
**境界推进**：暗劲大成 → 化劲初期（破境见神）
**核心爽点**：游历北方三派、融会贯通、与东洋"杀人技"生死战、与迅哥儿和解
**卷末 BOSS**：日本柔术+剑道双修大师"柳生一脉"传人（化劲门槛 + 武士刀法）
**结尾**：开宗立派 / 远赴南洋传拳

## 九、本作的核心命题

> **"国术不是花架子，是杀人技。"**
> **"闰土可以不止是闰土。"**
> **"一个人的拳头，撑不起一个民族；但一个民族有骨头，就不能没有拳头。"**

主角不是为了无敌而无敌，他的每一次越境、每一场打斗，最终指向的是：
- 改写自己（闰土）的悲剧命
- 证明中国武学不弱于洋人
- 寻找个人武道与家国命运之间的平衡

## 十、避坑铁律（写给自己看）

1. **前 3 章必出系统 + 第一场胜利**
2. **每境界至少 30 万字铺垫，不许飞升**
3. **单场打斗 800-2000 字，重在招式与心理**
4. **反派有动机、有厚度，不做工具人**
5. **迅哥儿戏份不超过 15%，不当主角**
6. **原作《故乡》元素点到为止，不强行复刻**
7. **每卷必有"看似打不过"的死局，主角赢在方法不靠属性**
8. **家国线不空洞，每一步都要落到具体的人**
