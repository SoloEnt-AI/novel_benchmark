# 《穿越闰土·国术征洋》国术考据清单

> 主角的武学体系：**形意为主、劈挂为辅、八卦为补**——走"内家三合"路线
> 兼顾各派代表招式描写，确保打斗场面有"招式感"而非"特效感"

---

## 一、主角主修：形意拳

### 1. 形意拳总论
- **源流**：传为岳武穆所创（争议），清末山西李洛能集大成
- **核心理念**："五行生克、十二形全"
- **风格**：硬打硬进、寸劲过寸、起如风、落如箭
- **主角定位**：取形意之"整劲""寸劲"，作为看家本领

### 2. 五行拳（形意根基）

| 拳名 | 五行 | 动作要领 | 主角运用场景 |
|------|------|----------|--------------|
| **劈拳** | 金 | 形似斧劈，从上往下，劲力通透 | 破防守、反架 |
| **钻拳** | 水 | 形似电钻，螺旋向上，专破硬功 | 打洋人硬桥 |
| **崩拳** | 木 | 形似箭发，直线寸劲，半步打人 | 招牌技，杀人技 |
| **炮拳** | 火 | 形似炮炸，崩弹炸力，刚烈无比 | 决胜技，卷一收官 |
| **横拳** | 土 | 中正安舒，化劲之基，蓄势待发 | 防守过渡、蓄力 |

**主角招牌组合**：
- **明劲阶段**："劈→钻→崩"连招
- **暗劲阶段**："崩→横→炮"连环（暗劲透脏）
- **化劲阶段**："五行合一"（融合技雏形）

### 3. 十二形（形意进阶）

| 形名 | 仿生 | 主角学会时点 |
|------|------|--------------|
| 龙形 | 搜骨 | 卷一中段 |
| 虎形 | 扑力 | 卷一中段 |
| 猴形 | 灵敏 | 卷一末 |
| 马形 | 蹄劲 | 卷二中段 |
| 鼍形（鳄） | 翻江 | 卷二中段 |
| 鸡形 | 抖翎 | 卷二中段 |
| 鹞形 | 钻林 | 卷二中段 |
| 燕形 | 抄水 | 卷二末 |
| 蛇形 | 拨草 | 卷三初 |
| 鹰形 | 捉拿 | 卷三中 |
| 熊形 | 膀靠 | 卷三中 |
| 鹰熊合演 | 阴阳 | 卷三末（破境化劲） |

### 4. 形意核心技法
- **三体式**（桩功）：所有形意功夫的根基
- **半步崩拳**：形意看家本领，主角"一寸长一寸强"的杀手锏
- **暗劲练法**：整劲之后求"透"，拳入脏腑
- **化劲练法**：打人如挂画，触人即飞

### 5. 形意·明劲→暗劲→化劲的标志
- **明劲**："起落翻钻未展伸"——力达外表
- **暗劲**："展伸合一气流行"——力透内里
- **化劲**："缩伸开合任自如"——力由心发

## 二、主角辅修：劈挂拳

### 1. 劈挂拳总论
- **源流**：清末河北沧州郭大发所传，"半步崩拳打天下"
- **核心理念**："长桥大马、连环紧扣"
- **风格**：放长击远、滚斫斩截、劲力冷弹
- **主角定位**：形意的"长桥"补充，专克贴身短打（如八极、泰拳）

### 2. 劈挂核心招式
- **劈挂掌**：放长击远，劲力通透
- **抄手起势**：劈挂起手，蓄力于肩
- **滚斫**：横扫千军，破贴身
- **斩截**：直劈如斧，沉肩坠肘
- **开山拳**：远程重击
- **大枪（劈挂大枪）**：陈四爷传给主角的临终绝学
- **十二把劲**：劈挂劲力总纲（冷、弹、脆、快、硬、沉、长、绵、巧、柔、猛、毒）

### 3. 形意+劈挂的相生
- **形意取近**：半步崩拳、贴身近战
- **劈挂取远**：长桥大马、远程重击
- **结合点**：陈四爷的"形劈合一"——明劲巅峰后可"形意半步+劈挂长桥"切换

---

## 三、主角补修：八卦掌

### 1. 八卦掌总论
- **源流**：清末董海川所创
- **核心理念**："走为上策、变中求胜"
- **风格**：身法走转、步法如风、掌法如幻
- **主角定位**：补足步伐和身法，让主角"打得到、打不着"

### 2. 八卦掌核心
- **趟泥步**：八卦之根，足下如趟泥
- **走圈**：绕圆走转，越走越快
- **八大掌**：单换掌、双换掌、顺势掌、背身掌、转身掌、磨身掌、翻身掌、回身掌
- **六十四掌**：八卦之变
- **核心**："脚踏八卦、掌打八方"

### 3. 八卦与形意的相辅
- **形意主"整"**：力从根起，一往无前
- **八卦主"变"**：身法灵动，避实击虚
- **暗合**：化劲之境，"形意整劲"配"八卦身法"，主"动静相生"

## 四、卷一对手门派

### 1. 通臂拳（杜秀才主修）
- **源流**：清末河北"祁家通臂"
- **风格**：放长击远、摔打合一、冷弹脆快
- **代表招式**：
  - **摔掌**：通臂看家本领
  - **通臂大劈**：远程开碑
  - **猿猴摘桃**：快手阴招
- **克制**：劈挂克通臂（同为长桥，劈挂更刚猛）

### 2. 八极拳（吴二主修）
- **源流**：清末河北孟村"吴家八极"
- **风格**：贴身短打、刚猛暴烈、寸劲入骨
- **代表招式**：
  - **铁山靠**：八极看家本领，肩靠打人
  - **六大开**：八极六大手
  - **小缠丝**：贴身缠斗
  - **顶心肘**：贴身肘击
- **特点**：八极"挨打十拳不如一靠"——是贴身最强的拳

### 3. 地方拳种（路人级反派用）
- **查拳**（鲁北）、**华拳**（山东）、**洪拳**（广东）、**蔡李佛**（广东）、**咏春**（闽粤）——用于丰富江湖生态

## 五、卷二对手：西洋拳

### 1. 英式拳击（马库斯主修）
- **源流**：18 世纪 Marquess of Queensberry 规则后成型
- **风格**：直摆勾三板斧、节奏明快、护头护肋
- **代表招式**：
  - **直拳（Jab）**：前手刺拳，探路骚扰
  - **摆拳（Cross）**：后手重击
  - **勾拳（Hook）**：近身重击
  - **大摆拳**：英式大摆，舍身一击
- **优势**：节奏快、护头严密、抗打强
- **劣势**：膝肘禁用，地面技空缺

### 2. 英式柔术（马库斯辅修）
- **源流**：英国"catch as catch can"（古典式摔角）
- **特点**：投技+寝技，无规则
- **代表招式**：
  - **抱单腿**：站立投技
  - **十字固**：寝技降服
- **剧情作用**：让马库斯"在地面战"也有威胁

### 3. 法式踢拳（皮埃尔主修）
- **源流**：19 世纪法国"萨瓦特"演变
- **风格**：腿法为主、拳腿结合
- **代表招式**：
  - **前蹬腿（Front Kick）**：法式看家
  - **侧踢**：破防守
  - **回旋踢**：高难度腿法
- **克制**：形意+八卦可破，腿法再快也快不过身法

---

## 六、卷三对手：东洋武术

### 1. 日本古流柔术（柳生源助主修）
- **源流**：战国时代"骨法"+"捕手"演变
- **核心理念**："以柔克刚、借力打力"
- **风格**：
  - **投技**：背负投、巴投、大外刈
  - **寝技**：关节技、绞技
  - **当身技**：打入要害（眼睛、喉咙、裆部）
- **特点**：以小博大的极致，讲究"四两拨千斤"

### 2. 古流剑道（柳生源助辅修）
- **源流**：中世日本"柳生新阴流"等古流
- **核心理念**："无刀取"——以剑入道
- **招式**：
  - **袈裟斩**：斜劈
  - **逆袈裟**：反向斜劈
  - **胴切**：横切躯干
  - **突き（突刺）**：直刺
- **实战法**：真剑胜负，一击必杀

### 3. 军部"杀人技"武士
- **特点**：不按流派招法，按"杀敌效率"训练
- **狠招**：撩阴、插眼、锁喉、反关节——不讲武德
- **剧情作用**：卷三后期反派群像，给主角"以一对多"的战斗

## 七、境界与招式的对应

| 境界 | 主角掌握程度 |
|------|--------------|
| **凡人** | 只会刺猹、挑柴、划船等野路子 |
| **明劲入门** | 学三体式、五行拳前三拳（劈、钻、崩） |
| **明劲小成** | 五行拳全、十二形前三形、劈挂基础掌 |
| **明劲巅峰** | 形意+劈挂杂学（陈四爷真传），可越级战明劲巅峰 |
| **暗劲入门** | 暗劲透劲，发力入脏腑 |
| **暗劲大成** | 形意暗劲+劈挂长桥融合，卷二卷末水平 |
| **化劲门槛** | 形意+八卦融合，"五行合一"雏形 |
| **化劲初期** | "鹰熊合演"+"八卦游身"——主角终卷境界 |

## 八、写作技法提示

### 1. 打斗描写三原则
- **镜头感**：远景（身形）→ 中景（招式）→ 近景（力道）
- **时间感**：让战斗有"慢镜头"（关键招式）和"快进"（连招）
- **疼痛感**：让读者感同身受——"痛觉描写"是民国国术的特色

### 2. 招式与境界的对应语言
- **明劲**："拳风破空"、"碎石如粉"
- **暗劲**："透体而过"、"内里崩裂"、"外无伤而内出血"
- **化劲**："触人即飞"、"打人如挂画"、"借力打力"
- **丹劲**："气血如汞"、"真气轰鸣"
- **罡劲**："打破虚空"、"筋骨齐鸣"

### 3. 民国国术的"质朴感"
- 不写"气功大师"的玄学——民国国术是"身体力学+实战经验"
- 写老拳师们的"三节四梢、五行六合"——术语化
- 写"整劲""寸劲""透劲"——具体化
- 写"打人如打鼓"——质感化

## 十、写作雷区（写给未来自己）

1. **不要把国术写成"气功"** ——民国国术是力学和实战，不是玄学
2. **不要把洋人写得太蠢** ——马库斯要有真本事，否则打赢了没爽感
3. **不要把招式写得太玄** ——"五行拳"是五种发力模式，不是五种魔法
4. **不要把境界写得太快** ——明→暗→化三境，每境至少 30 万字
5. **不要把师父写得太神** ——陈四爷是"明劲巅峰"，已经是他那代人的极限
6. **不要把"打洋人"写成爽文流水线** ——每场打斗要有"国术为何而生"的反思
