# 《闰土：国术宗师》世界观设定

## 一、时代背景

本书设定在清末民初（约1890年-1920年），这是中国历史上最动荡、最屈辱也最激荡的时期之一。

### 核心时代特征

- **列强环伺**：甲午战败、庚子国变，洋人在华享有治外法权，租界遍布各大城市
- **新旧交替**：科举废除、西学东渐，传统武馆与洋人俱乐部并存
- **民心思变**：革命党暗流涌动，义和团余波未平，各路势力角逐天下
- **国术黄金期**：这是中国武术最后的辉煌时代，各派宗师辈出，之后国术逐渐式微

### 社会风貌

- 乡间：宗族制度仍在，但已开始瓦解。地主乡绅把持地方，洋教堂势力渗透乡村
- 城镇：租界繁华与华界贫困形成鲜明对比。武馆林立，洋人开设拳击馆、柔道馆
- 江湖：武林门派仍存，但已受枪炮冲击。暗劲以上高手仍有极大影响力
- 官场：清廷摇摇欲坠，地方官员多为买办，对洋人卑躬屈膝

## 二、地理版图

### 主要地点

#### 1. 绍兴·闰土故乡（第一卷主场景）

- **原型**：浙江绍兴乡下，鲁迅故乡附近
- **地理特征**：水乡泽国，河道纵横，乌篷船穿梭。稻田连绵，远处有会稽山脉
- **社会结构**：以赵、钱等大姓宗族为核心，乡绅地主把持话语权
- **关键地标**：
  - 闰土家：海边沙地边的农户，种西瓜、捕鸟
  - 赵家大院：地方最大地主，勾结洋人
  - 海塘武馆：隐世老拳师开设的小武馆（主角拜师处）
  - 洋教堂：洋人传教士设立，实际是情报据点
  - 迅哥儿家：城中大户，与新学有渊源

#### 2. 绍兴城（第二卷主场景）

- **城市特征**：古城格局，河道穿城，乌篷船是主要交通工具
- **势力分布**：
  - 知府衙门：清廷地方政权，腐败无能
  - 各派武馆：形意、少林、南拳各有分馆
  - 洋人势力：英国领事馆、法国教堂、日本商社
  - 革命党暗线：光复会在此有秘密据点
- **关键地标**：
  - 百草园（迅哥儿家的后园，友情线重要场景）
  - 绍兴擂台：每年一度的武林盛会
  - 鉴湖女侠祠：秋瑾纪念地，革命党人暗中聚会处
  - 租界码头：洋货入口，也是走私军火的通道

#### 3. 上海滩（第三卷主场景）

- **城市特征**：远东第一大都市，十里洋场，纸醉金迷与底层苦难并存
- **势力分布**：
  - 租界巡捕房：洋人掌控的执法力量
  - 青帮/洪门：地下势力，亦正亦邪
  - 各国武馆/拳馆：西洋拳击馆、日本柔道场、俄国摔跤馆
  - 革命党总部：同盟会在上海有重要据点
  - 各路武林高手：来上海讨生活的各派拳师
- **关键地标**：
  - 精武体操会（霍元甲创办，可作为致敬元素）
  - 外滩擂台：洋人设擂，挑战中国武者
  - 城隍庙：传统势力聚集地
  - 四马路：繁华商业区，也是情报交汇处

#### 4. 天津卫（第四卷主场景）

- **城市特征**：北方重镇，九国租界，义和团运动的核心地带
- **势力分布**：
  - 袁世凯北洋势力：新军驻扎，实力最强
  - 义和团余部：被打散后转入地下
  - 八国驻军：各国军队及随军武者
  - 天津武林：形意拳大本营，郭云深一系传人
- **关键地标**：
  - 天津老城：传统武馆林立
  - 紫竹林租界：洋人势力核心
  - 大沽口炮台遗址：国耻纪念地
  - 天后宫：民间信仰中心，也是武林人士聚会处

#### 5. 京城（第五卷主场景）

- **城市特征**：帝都气象，新旧并存，城破之后的颓败与尊严
- **势力分布**：
  - 清廷残余/民国政府：政权更迭中的混乱
  - 京城武林：太极拳、八卦掌、形意拳三大内家拳根据地
  - 各国使馆区：洋人外交势力
  - 满清遗老遗少：保守势力
- **关键地标**：
  - 天桥：民间艺人、拳师卖艺之地
  - 各王府旧宅：隐世高手藏身之处
  - 京城擂台（天坛/地坛）：最高规格的武林盛会
  - 使馆区：洋人聚集，也是最终决战之地

- **帮会**：青帮、洪门、哥老会，亦正亦邪，有爱国者也有败类
- **乡绅地主**：地方势力，闰土原著中的压迫者，主角前期的直接对手

## 四、核心矛盾与冲突

### 主要矛盾线

1. **民族矛盾**（主线）：中国武者 vs 洋人武者，国术尊严之战
2. **阶级矛盾**（副线）：闰土（农民出身）vs 地主乡绅，打破命运枷锁
3. **武道矛盾**（成长线）：国术传承 vs 时代变革，如何在新旧交替中保存国术精华
4. **思想矛盾**（深度线）：传统 vs 现代，武术 vs 枪炮，个人 vs 国家

### 冲突升级路线

```
个人恩怨（打地主恶霸）
  → 地方冲突（对抗洋教堂势力）
    → 城市争霸（上海滩挑战洋人拳王）
      → 民族大义（抗击八国武者）
        → 国术之巅（京城论武，证明国术价值）
          → 终极对决（击败幕后黑手，扬我国威）
```

## 六、世界规则

### 基本规则

1. **武力上限**：丹劲高手可敌数十人，罡劲高手百人敌，但无法对抗成建制军队和枪炮
2. **国术地位**：明劲武者可开馆收徒，暗劲武者受各方势力拉拢，化劲以上是一方霸主
3. **洋人态度**：初期轻视中国武术，中期重视并打压，后期忌惮并试图收买/消灭
4. **社会规则**：武者有一定社会地位，但不能对抗官府和军队，需在规则内行事
5. **擂台规则**：传统擂台签生死状，洋人擂台有裁判但经常作弊

### 金手指设定

- **穿越优势**：
  - 现代人的知识视野（不是武力金手指，是思维方式的优势）
  - 知道历史走向，可提前布局
  - 闰土身体天赋极佳（从小劳作，筋骨强健，是练武的上好根骨）
  - 与鲁迅的友谊（原著中的迅哥儿），可获得思想启蒙和社会资源

- **限制**：
  - 没有系统、没有空间、没有外挂物品
  - 修炼速度比常人快，但不是开挂级别，靠的是科学训练方法+刻苦修炼
  - 现代知识有限，不是全知全能
