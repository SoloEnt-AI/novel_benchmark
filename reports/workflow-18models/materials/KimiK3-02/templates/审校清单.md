# 发布前审校清单

## 一、硬检查（每章必过）

- [ ] 字数2000-2500（黄金三章可略长）
- [ ] 开头3行有钩，结尾有钩
- [ ] 本章有且仅有一条主线任务，支线不喧宾夺主
- [ ] 章号、YAML头、故事日期与 `wiki/时间线台账` 一致
- [ ] 称呼一致：主角对外"章闰土"，亲人口语"闰土"；师兄弟排行不乱
- [ ] 无错别字（重点：的/地/得，在/再）

## 二、设定一致性

- [ ] 境界合理：主角当前境界能打赢的人/打不赢的人，对照《力量体系》枪械规则与同代标尺
- [ ] 历史日期对得上《晚清大事年表》（事件、年龄、节气）
- [ ] 地理动线符合《世界观与时间线》（他不可能一天从绍兴到北京）
- [ ] 金手指未越界：无系统提示音、无超前制造、顿悟次数未超配额（全书5-6次）
- [ ] 伏笔登记：新埋/回收均已写入 `wiki/伏笔登记表`

## 三、尺度红线（对照《主题与尺度》）

- [ ] 反派恶行具体化，无"洋人该死"式地图炮台词（除非是被主角当场驳斥的反面台词）
- [ ] 真实历史人物未被安排负面行为
- [ ] 死难场景（烈士、平民）写哀荣，不写血腥奇观
- [ ] 无影射现实内容
- [ ] 每场打戏有剧情功能（恩怨/境界/人物），非流水架

## 四、连载节奏（每5章复核一次）

- [ ] 近5章至少2个小爽点
- [ ] 近10章无连续压抑（重锤后已给回甘）
- [ ] 读者当前最大的"期待"是什么？（说得出=钩子有效；说不出=需要加钩）
- [ ] 存稿余量≥10章

## 五、卷末大复盘（每卷结束）

- [ ] 本卷承诺的大爽点、重锤是否兑现
- [ ] 三线（武道/家国/人情）是否都有推进
- [ ] 境界进度、时间线台账全量更新
- [ ] 下卷前3章细纲先行（卡文防火墙）
- [ ] 读者评论关键词扫一遍，记录"最被夸奖的点"和"最想弃书的点"，下卷微调
