# 人物卡：主角 章闰土（闰土）

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 姓名 | 章闰土（闰月生、五行缺土，故名。致敬原型章闰水） |
| 生卒 | 1878年（光绪四年）生 |
| 籍贯 | 绍兴府会稽县，海边沙地杜浦村 |
| 身份 | 瓜农/忙月之子 → 武人 → 一代宗师 |
| 标志 | 银项圈、小毡帽（少年）→ 白蜡大枪（成年） |

## 二、前世：陈骁

- 28岁，省武术队套路运动员退役，开过一家拳馆，倒闭；半生"练武无用论"的亲历者与不甘者
- 死法（第一章前情，点到即止）：拳馆失火，为抢出师父留的那杆大枪没跑出来——**器物执念穿越**，白蜡大枪意象的源头
- 知识储备：运动训练学、基础解剖力学、现代搏击实战体系、囫囵吞枣的晚清史（记得大事件，记不住日期细节）

## 三、性格

- **底色：韧。** 不是天才型狂傲，是"今天比昨天多站一炷香桩"的笨功夫人格——与闰土这个土地的意象完美贴合
- **表层：土味幽默。** 庄稼人的实在话+现代人的吐槽魂，承担全书笑点（例：管深蹲叫"扎蛤蟆功"，把蛋白质补充说成"吃蛋长劲"）
- **痛点：恨"老爷"二字。** 前世被房东、被甲方叫过无数声"老板"的打工人之魂，今生最听不得膝盖发软的话
- **暗面：不敢深想前世。** 怕想起现代的父母朋友——用练功麻痹，卷三某夜戏爆发一次（人物深度章，不写多）

## 四、动机弧（五段式）

1. **卷一：活下去，不受欺**——还债、护家、不再任人踩踏
2. **卷二：争口气**——擂台上把"东亚病夫"四个字打回去（个人雪耻层）
3. **卷三：报师恩、守同道**——武林是个"家"（师门层）
4. **卷四：救亡**——庚子血火中发现拳脚救不了国，至暗时刻（幻灭层）
5. **卷五六：铸魂**——"一个人能打十个，十万人挺直腰就是一国人"。从武者到师者（升华层）

> 对应"见自己（卷一二）→见天地（卷三四）→见众生（卷五六）"三层境。

## 五、金手指使用守则（防崩）

1. **现代训练科学**：可以加速成长、少走弯路、避免暗伤——但桩要一站一站熬，没有一夜变强
2. **力学/解剖学知识**：用于"点破窗户纸"的顿悟戏，每次只点一层，全书限用5-6次，次次有代价（练错、受伤、被师父骂"想太多"）
3. **历史记忆**：只记得大事件与年份量级，不知细节；卷四庚子后蝴蝶效应拉满，记忆作废
4. **绝不出现**：系统、兑换、储物空间、超越时代的制造（不造枪不炼钢——那是另一路书，守住国术流纯度）

## 六、武道路线

- **母拳**：形意（秦霜所授）+ 大枪（家学叉法→枪法的意象承接："从小叉猹的手，天生端得住枪"）
- **兼修**：八卦（程廷华点拨，补身法）、太极听劲（孙禄堂印证）
- **风格**：正面硬进+听劲化发的"刚柔双线"，区别于李书文纯刚、程廷华纯柔

## 七、标志性物件与意象

| 物件 | 意义 | 关键戏 |
|---|---|---|
| 银项圈 | 命不是神佛圈的 | 卷一爹要卖项圈还债他死活不肯（不是迷信，是孝）；卷四战场捡回一命后独白点题；终卷传给水生的孩子时意义完成升华 |
| 钢叉→白蜡大枪 | 从护瓜到护国 | 卷三王五赠枪："叉得住猹，就端得起枪" |
| 香炉烛台 | 原著悲剧意象 | 卷四怒斥拳民"刀枪不入"时引爆："我章闰土这辈子，不拜泥塑的菩萨！" |

## 八、口头禅

- （少年期）"五行缺土？我命里缺的是个说法。"
- （成年后）"站稳了。"——教拳时说得最多，终卷成为点题双关
- （怒极）"膝盖别软。"
