# 总纲主线

> 一句话总纲：闰土以国术为器，从改写个人宿命，到改写民族"东亚病夫"的宿命——拳镇山河，宗师不朽。

---

## 一、总纲：三段式结构

全书 100 万字，按主角的**格局拉升**分为三大段：

| 大段 | 卷别 | 核心命题 | 格格局 |
|---|---|---|---|
| **第一段：立身（改个人命）** | 第一卷 | 不认命，练国术，护亲惩恶 | 一个人、一家人 |
| **第二段：立名（改乡土/民族命）** | 第二、三、四卷 | 闯荡江湖，打脸洋人，名震天下 | 一乡人、一国人 |
| **第三段：立道（改国族命）** | 第五、六卷 | 开宗立派，国术大兴，登顶世界 | 天下人、后世 |

> 结构心法：主角的"拳"始终没变，变的是他这一拳打向的范围——从打倒一个恶霸，到打碎一个蔑称，到打出一个时代。这是格局逐层拉升的核心。

## 二、分卷总纲

### 第一卷·少年闰土·觉醒国术（约16万字）
- **境界**：凡人 → 明劲圆满
- **主线**：魂穿 → 前世觉醒 → 认清"闰土的命运" → 立志练武改命 → 拜师章三爷/自学 → 苦练明劲 → 惩治乡里恶霸金牙虎 → 护亲扬名乡野 → 立下御侮之志
- **卷末高潮**：金牙虎欺压至主角家人，主角明劲初成，一战打服金牙虎及其背后的地主恶势力，威震乡里；章三爷见其成材，临终托付，主角决意离乡闯荡。
- **核心爽点**：从被欺压的穷少年，到"少年高手"的逆袭；前世懂行碾压乡野粗浅拳脚。
- **情绪基调**：压抑中蓄力，结尾爆发——"我要的不只是打倒一个金牙虎，是不再跪着活。"

### 第二卷·离乡入世·拳镇江南（约18万字）
- **境界**：明劲圆满 → 暗劲
- **主线**：离乡南下闯荡 → 结识铁牛、苏婉等 → 与江南各路高手切磋融汇 → 卷入洋行买办欺压华人的事件 → 与马六为首的洋行打手势力冲突 → 进阶暗劲 → 打脸立威，扬名江南武林
- **卷末高潮**：马六仗洋人势欺压同胞（甚至伤及主角在意之人），主角暗劲初成，于市井/擂台血战马六一伙，扬名江南；初窥"洋人之患"全貌，为第三卷蓄势。
- **核心爽点**：悟性流碾压——切磋中观摩即学、一招反杀；从"乡野高手"到"江南名手"的进阶。
- **情绪基调**：江湖豪情中渐起家国之忧——"洋人的拳，比金牙虎狠多了。"

### 第三卷·津沪风云·力挫大力士（约20万字）
- **境界**：暗劲圆满 → 化劲门槛
- **主线**：北上津沪 → 见识更大的武林与时局 → 洋人大力士（伊万诺夫/奥皮音）摆擂辱华"东亚病夫"，连伤中国拳师 → 主角登台血战 → 名震天下 → 与精武会等同道结交，格局升至"为国"
- **卷末高潮（全书第一个大高潮）**：主角力挫大力士，举国震动——这一战打的不只是一个人，是"东亚病夫"四个字。万人空巷，主角名震天下。
- **核心爽点**：本书招牌爽点——"东亚病夫"的屈辱被铁拳击碎；拳眼看穿蛮力套路、以巧破力。
- **情绪基调**：从个人恩怨升至国族大义——"原来我这一拳，可以替这么多人出气。"

### 第四卷·列强环伺·国术立威（约18万字）
- **境界**：化劲
- **主线**：开馆授徒、强种强国 → 打破"传内不传外"旧规 → 洋人军事/特工势力介入，针对主角 → 主角以武护侨、护华工、护尊严 → 与列强武力全面对抗
- **卷末高潮**：破局一方洋人势力（如捣毁欺压华工的据点/击败其武力头目），护一方华人；主角"一方宗师"的地位确立。
- **核心爽点**：从"一个人强"到"带一群人强"——开馆授徒、桃李天下；以宗师之姿镇一方。
- **情绪基调**：责任渐重——"一个人强不够，得让中国人都硬起来。"

### 第五卷·宗师之路·天下有公（约18万字）
- **境界**：抱丹
- **主线**：万国竞武大会 → 远赴海外 → 以中国国术应万国武技（拳击、柔道、摔跤等）→ 一路披荆斩棘 → 登顶世界
- **卷末高潮**：国际擂台决赛，主角击败最强海外高手，登顶世界之巅，中国国术扬威全球。
- **核心爽点**：世界舞台的"以一国之术应万国之武"——国术 vs 世界格斗术的文化碰撞与碾压。
- **情绪基调**：扬眉吐气——"中国人，不是病夫，是宗师。"

### 第六卷·宗师不朽（结局卷·约10万字）
- **境界**：罡（巅峰）
- **主线**：武道绝巅 → 影响时代走向（国术大兴、强种强国）→ 回望来路 → 完成从"闰土"到"一代宗师"的终极蜕变
- **结局**：功成。主角立于巅峰，回望那个海塘边看瓜的穷少年，已成一代宗师——他改写的，不只是自己的命，是一个民族挺直脊梁的可能。
- **核心爽点**：圆满、升华、传承——国术薪火相传，宗师精神不朽。
- **情绪基调**：苍凉与豪迈交织——"少年时月下刺猹，此生刺的，是这吃人的世道。如今世道，到底被刺开了口子。"

## 三、贯穿全书的主线脉络

### 1. 武道线（明线）
凡人 → 明劲 → 暗劲 → 化劲 → 抱丹 → 罡。每一次境界突破，都是一卷的大爽点。

### 2. 格局线（暗线）
护己 → 护家 → 护乡 → 护国 → 护天下 → 留后世。主角的"拳"始终在打，但打的意义在不断升维。

### 3. 情感线
- **师徒情**（章三爷）——传承与托付。
- **兄弟情**（铁牛、迅哥儿）——市井与文武。
- **爱情**（苏婉）——以武相识，并肩而行。
- **家国情**——从个人到民族的情感升华。

### 4. 主题线（内核）
**"不认命"**——这是全书最大的主题。原著闰土认了命，穿越者偏不。从反抗贫穷的命运，到反抗屈辱的国运，贯穿始终。
