# 单章工作流与章节模板

## 一、单章生产流程（连载期标准动作）

1. **填卡**（10分钟）：照下方模板填好本章卡片
2. **初稿**（60-90分钟）：2200-2500字，一气呵成，不停下来改
3. **自查**（10分钟）：过《审校清单》
4. **入库**：存入 `chapters/第XXX章.md`，更新 `wiki/` 三个台账
5. **每5章一小结**：检查爽点密度与伏笔状态；每卷末大复盘

## 二、章节卡（写作前必填）

```
章节号：
本章日期（故事内）：          ← 与 wiki/时间线台账 对齐
POV/场景地：
出场人物：

【开头钩】（前3行必须抓人——悬念/冲突/反常/金句，四选一）：

【本章主线任务】（只许一件：推进恩怨/揭示信息/境界突破/情感推进）：

【冲突】（谁想要什么，被谁挡住）：

【爽点/燃点】（本章至少一个；若为铺垫章，写明"蓄力"并确认3章内有释放）：

【信息增量】（读者读完新知道了什么）：

【伏笔操作】（埋了哪条/收了哪条——登记进 wiki/伏笔登记表）：

【章尾钩子】（类型：危机/悬念/反转/新人物/金句）：

【三线检查】武道□ 家国□ 人情□（至少勾一条）
```

## 三、正文格式约定

- 文件命名：`chapters/第001章 月下钢叉.md`
- 每章正文前附 YAML 头：

```yaml
---
章节: 1
卷: 一
故事日期: 1889-03
境界: 未入门
登场: [章闰土, 章阿土, 章沈氏, 猹]
伏笔: [银项圈(埋)]
---
```

## 四、行文手感基准（对照样章《第001章》）

- 第三人称、过去时态、紧贴主角视角
- 短句为主，打戏单句不过30字；一段不过4行
- 每章至少1个"原著彩蛋"或"时代细节"（毡帽、茴香豆、黄包车、号外……），密度随缘，不硬塞
- 章内金句≤2句，多了贬值
- 心理独白用「」或直接叙述，全书写法统一
