# 国术参考资料（写作素材库）

> 用途：打斗描写、修炼描写、理论对话的素材底座。原则——**理法是真的，境界是编的**：
> 拳理、招式、练法尽量写实（读者里有真懂行的），境界划分是网文设定，自洽即可。

## 一、内家三拳（本书主角主修：形意+大枪）

### 形意拳（主角母拳）
- **桩功**：三体式（鸡腿、龙身、熊膀、虎抱头；前手似推山，后手似撕棉）
- **五行拳**：劈（金，如斧劈柴）、崩（木，如箭穿林）、钻（水，如浪翻卷）、炮（火，如炮炸膛）、横（土，如梁横架）
- **十二形**：龙、虎、猴、马、鼍、鸡、鹞、燕、蛇、骀、鹰、熊
- **核心讲究**：硬打硬进无遮拦；起如钢锉、落如钩竿；消息全凭后脚蹬
- **名言素材**："半步崩拳打天下"（郭云深）；"练拳不练功，到老一场空"

### 八卦掌
- 趟泥步、转圈换掌；单换掌为母；身法如游龙；程廷华一脉以柔化著称
- 打斗画面感强（绕身走转、以巧破力），适合写"以弱胜强"戏

### 太极拳
- 缠丝劲、听劲、引进落空；清末杨式已入京（杨露禅"杨无敌"传说在前）
- 孙禄堂晚年后融三拳创孙式太极——可作终卷伏笔

| 拳种 | 特点 | 适用角色 |

| 八极 | 贴身短打、顶心肘、刚猛暴烈，"文有太极安天下，武有八极定乾坤" | 李书文型猛人、军中教头 |
| 谭腿/戳脚 | 北腿代表，踢桩、连环腿 | 绿林配角 |

| 跤术（善扑营） | 满清宫廷摔跤 | 京城配角、满人高手（可作正面人物，体现"义不分满汉"） |

## 三、兵器

- **大枪**："枪乃百兵之王"，拳械一体（形意拳脱枪为拳）；抖大杆是最硬核的功力训练；主角标志性兵器：白蜡大枪，呼应少年那柄钢叉（**重要意象**：从叉猹的叉，到保家的枪）
- **单刀**：王五的刀，"单刀李"李存义
- **剑**：文人剑（谭嗣同赠剑桥段可用）

## 四、训练素材库（主角现代知识改良点）

| 传统练法 | 主角的现代改良（金手指出血点） |
|---|---|
| 站桩死熬 | 分组计时、心率意识、循序渐进周期化 |
| 硬功排打（挨揍练皮） | 改良为逐步负荷+营养恢复，避免暗伤 |
| 师父口传心授 | 用力学解释整劲（杠杆、重心线、地面反作用力），"一句话点醒梦中人"的爽点 |
| 只练拳不练体 | 引入跑步、跳绳、石锁（哑铃思维）、核心力量 |
| 实战靠喂招 | 护具对抗、条件实战、复盘制度 |
| 营养随意 | 蛋白质优先（鸡蛋牛肉豆子）、训练后补充——清末穷人家的执行难点也可成剧情 |

## 五、打斗描写三原则

1. **一招一式有因果**：力量从脚起、过腰胯、达拳锋；胜负手要有铺垫（前文埋的伤、地形、心理）。
2. **境界差异可视化**：明劲挨打是"撞"，暗劲挨打是"钉子钻进五脏"，化劲是"拳头落在棉花里对方已在你身后"。
3. **每场打戏承担剧情功能**：要么推进恩怨，要么揭示境界，要么塑造人物——不写"为了爽而打的流水架"。

## 六、推荐案头书（作者自修用）

- 《逝去的武林》李仲轩口述——民国形意门内生态，行话、规矩、人物感的最佳来源
- 《龙蛇演义》梦入神机——境界体系与打斗节奏的网文范本
- 《国术概论》等民国武术典籍影印本——理论词汇库
- 徐皓峰小说及访谈（《师父》《道士下山》）——武林"规矩"与冷峻笔调
