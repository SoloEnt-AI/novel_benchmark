# 晚清大事年表（1889-1912）· 剧情锚点版

> 用途：全书历史骨架。闰土约生于1878年（原著：1889年前后"十一二岁"）。
> 规则：大历史走向不改（甲午必败、辛丑必签、辛亥必成），主角改变的是个人与局部的命运；蝴蝶效应随篇幅递增，前世记忆可靠性递减。

## 卷一锚点：1889-1893（闰土11-15岁）

| 年份 | 历史事件 | 可化用剧情 |
|---|---|---|
| 1889 | 光绪亲政（大婚、亲政大典） | 穿越节点。乡野无感，只从县太爷加税摊派里体现"朝廷换了气象" |
| 1891 | 长江教案频发，民间排外情绪起 | 县城乡绅与教民冲突背景音，卷一末小高潮引子 |
| 1893 | 周福清科场行贿案下狱（鲁迅家道中落实事） | "章老爷家"败落，主角世界观冲击点 |

## 卷二锚点：1894-1895（16-17岁）

| 年份 | 历史事件 | 可化用剧情 |
|---|---|---|
| 1894.7 | 丰岛海战，甲午战争爆发 | 上海/杭州消息传来，朝野最初竟以为必胜 |
| 1894.9 | 平壤之败、黄海海战（邓世昌殉国） | 主角第一次在租界擂台上打洋人，民间狂热与前线惨败形成辛辣对照 |
| 1895.2 | 威海卫陷落，北洋水师全军覆没 | 举国如丧考妣 |
| 1895.4 | 《马关条约》：割台湾、赔银二亿两 | **卷二结尾爆点**：主角擂台连胜的"扬眉吐气"在割地赔款面前一文不值——第一次幻灭与立志 |
| 1895.5 | 公车上书 | 士子线引子（后续谭嗣同线伏笔） |

## 卷三锚点：1896-1898（18-20岁）

| 年份 | 历史事件 | 可化用剧情 |
|---|---|---|
| 1897.11 | 德国强占胶州湾，列强瓜分狂潮起 | 京津武林群情激愤，"国将不国"氛围 |
| 1898.6-9 | 戊戌变法103天；9.21政变，9.28六君子就义 | 王五-谭嗣同线：主角参与营救未果/护送遗属，"我自横刀向天笑"名场面，主角亲历时代悲壮 |
| 1898 | 义和拳起于山东冠县 | 卷三末钩子：拳民风声传入京津 |

## 卷四锚点：1899-1900（21-22岁）——全书第一大高潮

| 年份 | 历史事件 | 可化用剧情 |
|---|---|---|
| 1899 | 朱红灯起义，"扶清灭洋"旗号 | 主角对拳民"刀枪不入"的态度：同情其勇、痛其愚昧（香炉烛台伏笔在此引爆） |
| 1900.6 | 八国联军大沽口登陆；清廷宣战 | 天津战场：聂士成八里台战死（7.9），李存义老龙头车站夜袭俄军（真实武林事） |
| 1900.8 | 北京陷落，两宫西狩 | **程廷华之死**（真实：八卦宗师于崇文门外遇德军，中枪殉国，年52）；**王五之死**（源顺镖局，传说霍元甲为其收尸）——武林最黑暗一日，主角血战突围 |
| 1900 | 俄军入侵东北 | 可作支线/人物下落 |

## 卷五锚点：1901-1908（23-30岁）

| 年份 | 历史事件 | 可化用剧情 |
|---|---|---|
| 1901.9 | 《辛丑条约》：赔4.5亿两、使馆区驻兵、拆大沽炮台 | "东交民巷"成为主角心中刺；武林转暗线：保镖、锄奸、护侨 |
| 1901 | 霍元甲吓退俄国大力士斯其凡洛夫（天津，真实事） | 经典桥段复刻，主角参与或见证 |
| 1904-05 | 日俄战争在中国国土上开打 | 最大耻辱点："两个强盗在我家院子里打架"；日本武道势力随军渗透，主线大反派登场 |
| 1905 | 同盟会成立；废科举 | 革命党线接触；旧士子出路断绝的时代侧写 |
| 1908.11 | 光绪、慈禧相继崩 | 山雨欲来 |

## 卷六锚点：1909-1912（31-34岁）

| 年份 | 历史事件 | 可化用剧情 |
|---|---|---|
| 1909 | 霍元甲吓退英国大力士奥皮音（上海，真实事） | 精武线开启 |
| 1910 | 精武体操会成立；霍元甲暴卒（传为日人所害） | 主角接棒"精武"旗帜；与日本武道势力总清算伏笔 |
| 1911.10 | 武昌起义 | 武林人各择其路；水生一代上战场 |
| 1912.1-2 | 民国成立、清帝退位 | 终卷：终极对决（对主线大反派）+ 开馆授徒 + 《故乡》闭环结局 |
