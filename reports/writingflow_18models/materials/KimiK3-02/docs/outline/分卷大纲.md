# 分卷大纲（六卷）

---

## 卷一 绍兴少年（001-065章，~15万字）

**时间**：1889-1893（11-15岁）  **地点**：杜浦村→绍兴府城
**境界**：零基础→明劲小成  **历史**：光绪亲政背景、教案远音、1893周家败落

**主线**：穿越立足→家债危机→拜师秦霜→四年苦修→初显身手→离乡。

**关键情节链**：
1. 瓜田穿越（黄金三章，见细纲）
2. 家债浮出：欠赵老太爷印子钱，爹要卖银项圈→主角死活不肯，立誓"一年还清"（经济主线启动）
3. 遇师：雪夜/雨夜，主角识破落魄老镖师秦霜是高手（搬运粮袋的整劲细节），死缠拜师；秦霜三考（挑水、站桩、看心性）后收下
4. 四年修炼蒙太奇+三个成长节点戏：第一次整劲、第一次赢架（对村霸少年，收二弟水根为跟班）、装弶捕鸟改良（现代思维小爽点）
5. 乡土冲突升级：地保刘三逼债打人→主角出手（明劲初显，打十个青皮）→赵老太爷动用官府关系→秦霜出面摆平（亮出当年镖局辈分），但点破："此地容不下你了"——也为后续还乡埋情绪
6. 卷末：1893年，"章府"（迅哥儿家）科场案败落震动乡里；15岁的主角带水根离乡。临行秦霜赠言："出去看看，这世道比你想的大，也比你想的烂。"

**爽点**：刺猹名场面（趣味）→装弶改良（智爽）→初显身手打青皮（力爽）→秦霜出手（背景爽）
**卷末钩子**：离乡船上，听见客商说"上海滩洋人摆擂台，中国人没一个敢上"。

## 卷二 甲午风云（066-125章，~14万字）

**时间**：1893末-1895（15-17岁）  **地点**：杭州→上海
**境界**：明劲大成→暗劲入门  **历史**：甲午战争全程、马关条约

**主线**：沪上立足→码头帮派冲突→租界擂台成名→甲午战败的幻灭与立志。

**关键情节链**：
1. 杭州过渡（~8章）：码头扛包谋生，得罪沙蟹帮；沈青禾（药铺送药少女）初登场；主角以现代话术+拳头立足，小爽点连发
2. 上海篇：租界见闻冲击（"华人与狗"式屈辱场景写一笔，克制但扎心）；为生计进戏园当武行
3. 擂台主线：英国水手拳师霍克摆擂辱华，连败沪上拳师并口出狂言→主角先败后胜的两番战结构（一番战败北：明劲对西洋拳击的硬碰硬行不通；败后悟"以巧破力"+暗劲萌芽→二番战翻盘）——**卷二大爽点**
4. 暗劲突破契机：败北后受形意门前辈（过路人物，引出卷三人脉）一句话点拨+现代筋膜知识的顿悟戏
5. **卷末核弹**：擂台连胜、名动沪上的当口，《马关条约》消息传来——割台湾、赔二亿两。万人空巷的庆贺与此形成残忍对照。主角当夜撕了"东亚病夫雪耻"的报纸标题，独坐黄浦江边。第一次明白：擂台赢一百场，也赢不回一座台湾。

**爽点**：沙蟹帮冲突、戏园护场、两番战翻盘霍克
**卷末钩子**：北上！去看这国的病根。天津码头，一个叫霍元甲的脚行把式正在卸货。

## 卷三 京华武林（126-195章，~16万字）

**时间**：1896-1898（18-20岁）  **地点**：天津→北京
**境界**：暗劲小成→大成  **历史**：胶州湾事件、戊戌变法

**主线**：拜会京津名家、融入武林→戊戌风云亲历→**师父秦霜之死**。

**关键情节链**：
1. 天津：结识霍元甲（脚行搬货较力戏，不打不相识）；津门拳房生态
2. 北京：源顺镖局拜王五→被考校（暗劲测力戏）→王五赠白蜡大枪（**意象承接章：钢叉到大枪**）；访程廷华，被"走转"身法戏耍（主角第一次体会化劲碾压，立志）
3. 初会孙禄堂：少年天才第一次较艺，主角败——"输得心服口服"（立对照组）
4. 胶州湾事件（1897）：京津武林群情激愤；德国军官瓦格纳在津设擂（卷四仇敌埋线），主角因资历被按住未上，王五之弟子上场惨胜——埋"洋人玩不起就用枪"的伏笔
5. 戊戌变法线：王五-谭嗣同交游线带出变法风云；主角为镖局护"维新派人物"南逃（动作戏）；政变、六君子就义——主角混在人堆里看谭嗣同赴死，**全书文戏第一高峰**
6. **卷末重锤**：秦霜北上寻徒，恰逢教民恶霸勾结洋人欺压百姓，为师旧伤之躯出手，死于洋枪冷弹。主角赶到只接住师父那杆老枪。秦霜遗言："别哭。练拳的，死在站着，不算亏。"

**爽点**：拜会名家的连环较艺、护法南逃动作戏
**泪点**：谭嗣同赴死、秦霜之死（双连击，卷三情绪设计：先扬后抑）
**卷末钩子**：山东传来风声——"义和拳，扶清灭洋"。师父的枪，主角扛上了肩。

## 卷四 庚子国难（196-280章，~20万字）★全书第一大高潮

**时间**：1899-1900（21-22岁）  **地点**：山东→天津→北京→突围
**境界**：暗劲巅峰→**化劲（血火顿悟）**  **历史**：义和团、八国联军全程

**主线**：直面拳民之愚昧与悲壮→天津血战→北京城破、武林殉难→绝境突围与化劲。

**关键情节链**：
1. 山东见闻：拳民"刀枪不入"的把戏被主角当场拆穿→冲突→但他看到拳民眼里的东西后沉默了（**香炉烛台伏笔引爆章**："他们信的哪是符水，是没活路"）
2. 天津：李存义老龙头车站夜袭俄军（真实事件，主角参与）；聂士成八里台战死的战场侧面（写哀荣）
3. 北京：武林人集结（程廷华、王五、李书文、孙禄堂……国术全明星的最后一次同台，写足江湖气与家国情）
4. **程廷华之死**（真实事件改编）：化劲宗师孤身于磁器口遭遇德军排枪——主角亲眼目睹"觉险也躲不开排枪"，全书逻辑基石轰然落地
5. **王五之死**：源顺镖局最后一战，护镖局满门与街坊撤退
6. 主角化劲突破：巷战绝境，生死一线顿悟听劲——**但突破后的第一章，是他抱着师父的老枪跪在废墟里**：突破救不了北京。爽点与重锤同章对冲，本书标志性的情绪设计
7. 桃井结仇：日本军随军武道家桃井龙太郎围杀中国武人，与李书文对枪不分胜负、与主角首次照面（主角不敌，靠杰克·杜威——拒向平民开枪被军法处置的美国拳手——相助脱身）
8. 卷末：护送孤儿寡母西撤（青禾失散于乱军）；辛丑签约消息传来。主角在东交民巷的界碑外站了一夜。

**爽点**：夜袭老龙头、巷战化劲、与李书文并肩
**重锤**：程廷华、王五之死；化劲救不了国
**卷末钩子**：十年后。不，拳还在，人还在——这条命，还得打下去。

## 卷五 辛丑暗战（281-360章，~18万字）

**时间**：1901-1908（23-30岁）  **地点**：天津→上海→各地暗线
**境界**：化劲大成→**丹劲（卷末）**  **历史**：辛丑条约、日俄战争、同盟会

**主线**：从"明着打"转"暗着干"：保镖、锄奸、护侨→见证霍元甲吓退俄大力士→日俄战争的最大耻辱→转型办馆。

**关键情节链**：
1. 暗线开篇：主角成了"影子镖师"——护维新党人、锄汉奸买办（谍战式单元剧，3-4个单元，各5-8章，节奏快爽点密）
2. 1901年天津：霍元甲吓退俄国大力士斯其凡洛夫（真实事件复刻），主角在台下——**不写主角抢戏，写他"看着霍大哥的背影，明白了什么叫不战而屈人之兵"**（主角让位于真实历史，反而高级）
3. 青禾重逢：仁济医院护士身份；玛丽医生登场（西方科学给国术背书戏）
4. 日俄战争（1904-05）："两个强盗在我家院子里打架"——全书民族情绪最低点；桃井随军再现，与主角三次暗战（一败一平一胜的递进），丹劲门槛在最后一次暗战中摸到
5. 收徒水生：回乡一趟（中年闰土"原著形象"的惊鸿一瞥：族里同龄人的麻木模样，照镜子般的后怕），带回水生
6. 卷末：抱丹之夜——气血如汞、百病全消的仪式感章；同年，同盟会成立的消息与废科举的旧人哭相交织。主角决定：开馆。

**爽点**：锄奸单元剧、三次暗战递进、抱丹
**卷末钩子**：上海滩，一个英国人奥皮音正在登报：要在张园摆擂，"赌一赌中国人里有没有男人"。

## 卷六 辛亥惊雷（361-430章，~16万字）

**时间**：1909-1912+1919尾声（31-34岁→41岁）  **地点**：上海→武昌（侧写）→绍兴
**境界**：丹劲大成→罡劲门槛（触而未入）  **历史**：精武会、霍元甲之死、辛亥革命、清帝退位

**主线**：精武接棒→与日本武道势力总清算→辛亥洪流→终极对决→归乡闭环。

**关键情节链**：
1. 1909奥皮音事件（真实事件改编）：霍元甲吓退英力士，精武体操会1910年成立——主角全力辅佐（办馆理念碰撞戏：霍的"体育救国"与主角的"铸魂"殊途同归）
2. **霍元甲暴卒**（1910，传为日人所害）：主角查案线→证据指向桃井势力的"上海武道制霸计划"→总清算序幕
3. 辛亥（1911）：水根（新军）在武昌；水生在火线；武林人各择其路（写群像抉择：有从戎的、有护民的、有误投军阀的）
4. **终极对决**：桃井约战公开擂台（日方企图以武道胜利配合外交施压），丹劲对丹劲——全书武戏最高章。胜负手：主角以"听劲+大枪脱枪为拳"的二十年一体修为破桃井剑道；胜而不杀。桃井后被己方灭口（其"刀俎逻辑"自噬），主角为其收尸——武道家最后的体面
5. 时代终章：清帝退位。孙禄堂来访，第三次较艺，印证不较力——"天下第一手"之论落在"传薪"二字
6. **尾声·归乡**（1919）：见总纲结局正文。"兄弟"二字，银项圈一晃，月下刺猹的少年定格。末章："站稳了。"

**爽点**：精武扬名、终极擂台、辛亥热血
**泪点**：霍元甲之死、桃井之死（复杂泪点）、归乡
**全书落点**：不是打败谁，而是"孩子们站桩的院子"。
