# 爽点地图（全书节奏总控）

## 一、爽点类型库

| 类型 | 定义 | 本书代表场景 |
|---|---|---|
| 力爽 | 硬实力碾压 | 明劲初显打十青皮；丹劲抱丹 |
| 智爽 | 现代思维降维 | 装弶改良；用力学一句话点破拳理 |
| 打脸 | 势力眼当场反转 | 地保逼债反被打；赌拳庄看走眼 |
| 扬威 | 民族情绪爆点 | 两番战翻盘霍克；吓退大力士；终极擂台 |
| 以弱胜强 | 越境而战 | 暗劲对化劲程廷华（虽败犹荣式）；卷四对桃井不死 |
| 绝境突破 | 生死间破境 | 巷战化劲；暗战抱丹 |
| 群像燃 | 全明星集结 | 庚子北京武林同台；辛亥各择其路 |
| 泪燃 | 悲壮中的燃 | 谭嗣同赴死；程廷华王五殉国；霍元甲托孤 |

## 二、密度规则

- **每3-5章**：一个小爽点（打脸/小胜/顿悟）
- **每卷**：2-3个大爽点+1个情绪重锤（泪点/重击）
- **全书**：3个超高潮（北京血战/终极擂台/归乡）
- **禁止**：连续10章无爽点（重锤章后也须跟"回甘章"——比如程廷华死后，跟一章主角夜练枪法、街坊默默送灯的静默燃）

## 四、情绪曲线（全书）

```
爽/燃 ─  ╱╲    ╱╲      ╱╲
       ╱   ╲  ╱  ╲    ╱  ╲___      ______
      ╱     ╲╱    ╲  ╱       ╲____╱      ╲____ 缓慢爬升至光
     ╱             ╲╱   ←庚子谷底（卷四）
   卷一  卷二  卷三  卷四  卷五  卷六
  轻快  扬-锤 扬-锤  谷底  回升  高收
```
原则：大爽之后必跟重锤（防飘），重锤之后必给回甘（防弃书），谷底之后逐卷爬升，全书收在"亮"字上。
