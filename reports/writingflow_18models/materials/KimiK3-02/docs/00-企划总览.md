# 《国术：从闰土开始》企划总览

> 一句话卖点：**穿越成闰土，不求神、不喊老爷，用一双铁拳打出个朗朗乾坤。**

## 一、基本定位

| 项目 | 内容 |
|---|---|
| 类型 | 历史穿越 · 传统国术 · 热血爽文 |
| 篇幅 | 约100万字，400-450章，单章2000-2500字 |
| 时代 | 清末民初（1889-1912） |
| 主角 | 现代武人魂穿少年闰土 |
| 金手指 | 前世国术见识+现代训练科学+模糊历史记忆（无系统、无加点） |
| 力量体系 | 明劲→暗劲→化劲→丹劲→罡劲→见神不坏（纯肉身，无超凡） |

## 二、核心卖点

1. **国民级IP零门槛**：闰土是中文世界认知度最高的文学形象之一，"银项圈、刺猹、西瓜地"自带画面感与情怀，开篇即钩子。
2. **公版人物零风险**：鲁迅（1936年逝世）作品已过版权保护期，可自由改编。
3. **历史节奏表=天然爽点排期**：甲午、庚子、辛丑、辛亥，大事件自带冲突与高潮，大纲不必无中生有。
4. **反差感即主题**：原著闰土是被生活压垮、求神拜佛、喊"老爷"的悲剧人物；本书让同一人物挺直脊梁，"求人不如求己"。结尾与《故乡》原著形成闭环（见总纲结局设计），泪点与爽点合一。
5. **国术写实流**：苦练、站桩、擂台、战场，拳拳到肉；境界清晰，升级感强。

## 三、读者画像

- 男频历史/武侠/国术流读者，《龙蛇演义》《国士无双》受众
- 对"清末民国+抗击外侮"题材有情结的家国向读者
- 被"闰土"梗吸引进门的泛读者（需用黄金三章留住）

## 四、创作流程（六阶段）

1. **筹备期** → `docs/research/` 原著要点、晚清年表、国术资料、竞品分析
2. **设定期** → `docs/setting/` 时间线、力量体系、人物卡、主题与尺度
3. **大纲期** → `docs/outline/` 总纲、分卷大纲、爽点地图
4. **开头期** → `docs/outline/前30章细纲.md` + 黄金三章样章
5. **连载期** → `templates/` 章节模板、审校清单；开书前存稿20章+
6. **维护期** → `wiki/` 时间线台账、伏笔登记、境界进度，每卷末复盘

## 五、三条主线

- **武道线**：闰土从乡野少年到一代宗师的境界攀登
- **家国线**：甲午之痛→庚子之血→辛亥之光，个人命运嵌入救亡大时代
- **人情线**：家人、师父、武林同道、与"迅哥儿"跨越阶级的兄弟情（原著"厚障壁"的逆转）
