# 人物卡：群像

> 使用原则：真实历史名家**正面实名**（增厚重感与代入感）；反派一律虚构；负面行为绝不安在真实人物头上。

## 一、师门线

### 秦霜（师父，原创）——卷一灵魂人物
- 60岁，落魄镖师，形意门人（师承可虚接郭云深一支的旁支），一杆大枪曾"挑过捻军的营"
- 秘密：太平天国/捻军旧部遗属，隐姓埋名于绍兴；腿上有旧枪伤，境界从半步化劲跌到暗劲大成
- 性格：酒糟鼻子、嘴上嫌弃、心里滚烫；教徒弟的方式是"先挑三年水、站三年桩"
- 功能：传武、传规矩、传"武人骨气"；**卷三末为护百姓死于洋枪**——主角武道幻灭第一击，全书最大泪点之一
- 名言："练拳先练站，站的不是桩，是骨头。"

### 章水根（二弟） / 水生（后辈）
- 水根：小主角两岁，性子野，卷二随兄出门，走"镖师/军中线"——兄弟分歧线（水根后来觉得"练武不如扛枪"，投新军，辛亥呼应）
- 水生：后辈少年（按原著是闰土之子辈，本书调整为族侄），卷五六徒弟线主体，"不让这孩子再过我前世的苦日子"

## 三、反派阵营（全部虚构）

### 主线大反派：桃井龙太郎
- 日本镜心明智流剑道+柔术天才，"大陆武道制霸"计划执行者，背后是日本军部柔道会势力（影射玄洋社）
- **主角镜像设定**：同龄、同样天才、同样苦修——但他信"武为刀俎、弱肉强食"，主角信"武为铸魂"
- 轨迹：卷四随军来华（庚子）→ 参与围杀中国武人（与主角结死仇）→ 卷五多次暗战 → 卷六终极对决，丹劲对丹劲
- 终局处理建议：堂堂正正败于擂台，死于自己信奉的"刀俎逻辑"（被自己人灭口/切腹），不写虐杀，留武道家最后体面——格调所在

### 对照组洋人（正面/复杂，必须有）
- **莫理循**（真实人物，泰晤士报驻华记者）：旁观者视角记录主角事迹，"洋人的笔替中国人说话"——国际舆论线
- **萨镇冰式人物或虚构拳手**杰克·杜威：美国水手拳击手，擂台输给主角后惺惺相惜，教主角西洋拳击的发力（技术交流线），庚子时拒绝向平民开枪被军法处置——"义不分中外"的主题载体
- 虚构女医生/护士玛丽（仁济医院）：救治线、西方科学视角看国术（"你们的站桩，是非常科学的静力训练"——借她口给国术背书）

## 四、家人与乡土线

- **父·章阿土**：老实、迷信、疼儿子。卷一银项圈戏、卷四千里寻子戏（泪点）
- **母·章沈氏**：沉默的坚韧，全家情感锚点
- **杨二嫂**：年轻时的豆腐西施，泼辣鲜活，市井戏调味剂（原著彩蛋）
- **迅哥儿（周树人）**：章府少爷，比主角小三岁。少年玩伴线（雪地捕鸟等原著桥段翻新）；卷三绍兴重逢（他已显文名志向）；终卷1919年前后归乡重逢——**"兄弟"二字收尾全书**。戏份控制：全书出场≤10章，重在质量
- **谭嗣同**：卷三特别出场，王五线，"去留肝胆两昆仑"——全书文戏最高峰之一
