# 力量体系：国术六境

> 原则：理法写实、境界自洽、**上限锁死**。全书无超凡，最高战力也躲不过排枪——这是本书与玄幻流的根本区别，也是主题的地基。

## 一、六境总览

| 境界 | 一句话定义 | 战力直观 | 全书进度 |
|---|---|---|---|
| 明劲 | 筋骨之力练成一整块，发劲刚猛暴烈 | 壮汉十人近不得身，一拳断砖 | 卷一 |
| 暗劲 | 内劲初生，劲力可"透"，伤人脏腑于无形 | 打人如挂画；掌上按一下，人没事、五脏已伤 | 卷二、三 |
| 化劲 | 全身无处不弹簧，听劲化发，四两拨千斤 | 蝇虫不能落、一羽不能加；十个暗劲围不上身 | 卷四、五 |
| 丹劲 | 气血抱丹，体能质变，精力弥漫 | 寒暑不侵、力逾千斤、三日不眠战力不减 | 卷五末、六 |
| 罡劲 | 内气勃发近乎"外放"，已非人力范畴 | 三尺之内劲风伤人（传说级描写，克制使用） | 终卷摸门槛 |
| 见神不坏 | 打破虚空、可以见神；至诚之道，前知祸福 | 武道神话，本书不实证，只作传说与留白 | 不达成 |

## 二、分境详解

### 明劲
- **特征**：整劲。脚蹬地、腰胯转、力达四梢，全身劲拧成一股
- **修炼**：站桩（三体式）+五行拳单操+抖大杆；筋骨齐鸣、虎豹雷音为明劲大成标志
- **突破标志**：随手一动皆有"爆炸力"，硬打硬进
- **主角用时**：卷一（4年打基础，穿越者优势在"方法对+肯死练"，不走速成邪路）

### 暗劲
- **特征**：刚柔转换，劲力内敛；明劲伤皮肉，暗劲伤脏腑
- **修炼**：由刚入柔，拳里掺"水意"；主角以现代解剖学理解"内劲"（筋膜链、核心传导），领悟快于同辈——**金手指在武道上的主要体现**
- **突破标志**：棉里裹铁；按胸断肋而皮肤无伤
- **主角用时**：卷二入门、卷三大成（约20-25岁，天才级速度，有孙禄堂做对照组）

### 化劲
- **特征**：听劲。皮肤即耳目，触着知来意；借力、化力、发力一念之间
- **突破标志**：与人搭手，对方如坠云雾、处处落空
- **主角突破契机**：卷四庚子血战，生死之间顿悟（绝境突破，爽点设计）
- **重要设定**：化劲宗师能"觉险"——对杀意有直觉，但**只能避暗箭、避不开排枪**。程廷华之死立此规则。

### 丹劲
- **特征**：抱丹。气血凝聚如汞，敛入骨、爆于瞬；体能层面的质变（恢复、耐力、抗打全面跃升）
- **设定边界**：仍是一日三餐会饿、中弹会死的人。丹劲大宗师=人类体能天花板
- **主角用时**：卷五末至卷六（约32岁）

### 罡劲 / 见神不坏
- 罡劲：终卷对决中主角一触即收的体验式描写（"仿佛摸到了那层窗户纸"），**不实证**，留给读者想象与可能的续作
- 见神不坏：只存在于郭云深辈的传说与孙禄堂的口中，作为武道"北极星"存在

## 三、枪械对照表（战斗设计的硬规则）

| 场景 | 武者胜算 | 写法 |
|---|---|---|
| 街巷、室内、夜间、对单枪 | 暗劲以上占优 | 主角主场，可爽 |
| 开阔地对排枪/机枪 | 任何境界皆死 | 庚子战场的绝望感来源 |
| 擂台 | 纯武道规则 | 民族情绪爽点主场 |
| 刺杀/保镖 | 暗劲化劲高光 | 卷五暗线主玩法 |

**铁律**：主角永远不"肉身接子弹"。他能赢的是距离、时机、地形与人——这才是传统国术流的真实感与高级感。
