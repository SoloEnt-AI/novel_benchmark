# 主题内核与内容尺度

## 一、主题三层递进

1. **个人层：站直了**——闰土不做木偶人。穷人家的孩子，先要有不跪的膝盖。
2. **民族层：争口气**——"东亚病夫"四个字，用拳头一个一个打回去。但要写透：擂台赢得再漂亮，挡不住马关的割地赔款——**个人之勇救不了国**。
3. **文明层：铸国魂**——武道的终点不是杀敌，是"强种强国"：让一代中国孩子吃得上饭、站得直腰、眼里有光。从"打洋人"到"教国人"，是主角也是全书的成人礼。

> 一句话主题：**神佛救不了中国人，拳脚也救不了，能救的只有一个"强"字——身强、志强、国强。**

## 二、与《故乡》的互文（本书的"魂"）

| 《故乡》 | 本书 | 作用 |
|---|---|---|
| 闰土求香炉烛台 | 闰土怒斥"刀枪不入"，一生不拜泥塑 | 麻木→觉醒 |
| 一声"老爷"，厚障壁 | 终生不喊老爷；终卷一声"兄弟" | 阶级隔膜→人格平等 |
| 水生重复父辈命运 | 水生习武读书，上辛亥战场 | 代际循环→代际突围 |
| "他们应该有新的生活" | 终卷开馆授徒，孩子们站桩的剪影 | 鲁迅的希望，本书来接棒 |

**终卷尾声设计（全书文眼，提前锁定）**：1919年后某年冬，已成名作家的"迅哥儿"回绍兴搬家，码头上，脊背笔直的老者迎上来，一声"兄弟"。两人对坐喝酒，迅哥儿说要把他写进书里——"写我什么？""写一个月下刺猹的少年。"老者大笑，颈上银项圈晃了一下。全书终。

## 三、内容尺度红线（平台安全+格调）

### 必须做到
1. **反派具体化**：打的是"侵略者、恶霸、买办、汉奸"，不是"洋人"这个笼统概念。每卷至少有一个具体恶行交代动机（强占田地、毒打华工、擂台辱华、屠杀手无寸铁者）。
2. **设置对照洋人**：每卷至少一个正面或复杂的西洋/日本角色（莫理循、杰克、玛丽、有武德的对手）——"我们恨的是豺狼，不是肤色"。
3. **尊重真实烈士**：程廷华、王五、聂士成、邓世昌等死难场景庄重处理，不戏谑、不消费。
4. **义和团书写**：不美化愚昧（符水刀枪不入的悲剧要写透），不丑化动机（他们是不甘的庄稼人——**他们是"没有遇到秦霜的闰土们"**，这个处理让全书悲悯底色与鲁迅同源）。
5. **胜之有道**：擂台胜强敌靠技与智，不靠阴招下毒虐杀；对日本反派也给武道家体面。

### 不能碰
- 现代民族仇恨的地图炮式表述（借角色之口喊"杀光x国人"之类）——主角要亲手打断说这话的人，这就是立场戏
- 改变重大史实结果（如让中国打赢甲午/庚子）——锁死，无力感是本书的燃料
- 真实历史人物的污名化改编
- 过度血腥酷刑细节；民族伤疤（旅顺、庚子屠戮）写哀荣不写奇观
- 影射现实的任何隐喻

## 四、爽点与悲悯的配比

- 爽点负责"爽"：擂台、打脸、以弱胜强——大胆写、写透
- 悲悯负责"重"：败战、死别、无力——克制写、写准
- 配比经验值：每卷爽:重 ≈ 7:3；卷四庚子例外，5:5，全书情绪最低谷，随后逐卷回升至结局的光亮
