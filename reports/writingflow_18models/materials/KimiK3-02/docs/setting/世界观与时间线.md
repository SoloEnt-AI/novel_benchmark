# 世界观与时间线

## 一、世界设定

- **真实历史低武世界**：1889-1912年的中国，无任何超凡元素。武道是纯肉身技艺的极致，最高境界"见神不坏"也只存在于传说中（可作开放性传说处理，不实证）。
- **核心规则：武道与枪炮的关系**（全书立意的物理基础）
  - 明劲好手：十人敌，但怕乱枪
  - 暗劲好手：短距可避单一冷枪，街巷战之王
  - 化劲宗师：秋风未动蝉先觉，能预判杀手敌意，但战场上排枪炮火下人人平等
  - **这条规则不可打破**。程廷华（化劲宗师）庚子年死于乱枪——全书最重的逻辑基石与主题基石：肉身有涯，武道的意义不在杀敌，在铸魂。
- **历史改写规则**：大事件走向锁定（甲午败、辛丑签、辛亥成）。主角可救具体的人、赢具体的架、改局部的命，但改不了国运——无力感是中期剧情的发动机，也是结局升华的跳板。前世记忆随蝴蝶效应递减可靠性，卷四后基本归零（主角必须真正"活在当下"）。


## 四、三条主线交织规则

- **武道线**给节奏（升级、打戏、擂台）
- **家国线**给重量（历史节点、民族情绪）
- **人情线**给温度（家人、师父、水生、迅哥儿）
- 单章至少在线其一，单卷必须三线都有推进；大高潮三章必须三线汇流（例：卷四北京血战=武道突破+家国至暗+师友死别）。

## 五、闰土家世设定（本书私设，基于原著推演）

- 父：章阿土（"老闰头"），章家忙月，老实巴交，原著那位"在神佛面前许愿"的父亲——迷信但疼儿子，父子线核心
- 母：章沈氏，浆洗缝补补贴家用
- 弟妹：二弟章水根（后随兄习武，水生线预演）、小妹
- 家底：两亩薄田+瓜田帮工，欠着"赵老太爷"（本地士绅，卷一反派）的印子钱——卷一经济压力来源
- 与"章老爷家"（即原著"我"家，本书称"鲁镇周家"的化写为"章府"）的帮工关系：迅哥儿线入口
