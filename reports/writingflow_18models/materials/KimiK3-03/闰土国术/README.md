# 《闰土：从刺猹开始练国术》项目总览

## 项目信息
- **体量**：100万字 / 8卷 / 约400章（单章约2500字）
- **类型**：清末民初 · 国术流 · 魂穿 · 热血爽文
- **一句话卖点**：现代人魂穿少年闰土，从西瓜地刺猹开始练国术，打穿甲午、庚子、辛亥，成就一代国术宗师。

## 目录结构

```
00-企划/       立项书、力量体系、时代年表、拳术资料库
01-人物/       主角卡、配角卡、反派群像
02-大纲/       总纲、分卷大纲、各卷章纲
03-正文/       按卷分文件夹，逐章 .md（文件名：第001章-章名.md）
04-连载管理/   章节登记表、伏笔追踪表、时间线对照表
```

## 六阶段写作流程

1. **阶段0 立项**：书名/简介/标签/对标 → `00-企划/01-立项书.md` ✅
2. **阶段1 设定集**：力量体系、时代年表 → `00-企划/` ✅（拳术资料库随人物卡阶段补齐）
3. **阶段2 人物卡**：主角、周树人、师父、反派群像 → `01-人物/` ✅
4. **阶段3 大纲**：总纲（含8卷细纲）→ `02-大纲/总纲.md` ✅；卷一逐章章纲（待总纲确认后写）
5. **阶段4 黄金三章**：开篇试写（月夜刺猹切入，3章内亮穿越+国术双钩子）→ `03-正文/卷一/`（待写）

6. **阶段5 连载循环**：写作 → 每5章复盘 → 更新 `04-连载管理/` 三张表，保证100万字不崩

## 连载管理三张表（阶段5启用）

- **章节登记表**：章节号 / 章名 / 字数 / 主要事件 / 出场人物 / 埋设伏笔
- **伏笔追踪表**：伏笔内容 / 埋设章节 / 计划回收章节 / 状态
- **时间线对照表**：剧情时间 / 历史事件 / 主角年龄 / 境界进度
