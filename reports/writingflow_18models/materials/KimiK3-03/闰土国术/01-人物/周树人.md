# 人物卡 · 周树人（文线化身）

> **尺度红线**：鲁迅形象必须正面——不黑化、不矮化、不娱乐化；不开金手指、不改其历史选择、不让他"跟主角学武"。他只是被命运善待了一点点的那个周树人。

## 定位

- 主角发小，全书**"文线"化身**：武线主角用拳头打洋人，文线树人用笔唤醒国人——一文一武，双线救国
- 情怀担当：承包全书所有《故乡》原著意象（西瓜地、银圈、雪地捕鸟、贝壳、猹）

## 时间线锚点

- 1881年生，比主角小两岁（符合原著"闰土比我大两三岁"）
- **1893年**：周家大祭值年，12岁的树人与14岁的运水相识——少年情谊全部按原著兑现
- 此后走史实路线：1898南京水师学堂 → 1902赴日 → 1904仙台医专 → 1906弃医从文 → 1909回国 → 1918《狂人日记》 → 1921《故乡》

## 双线交汇设计（每两卷至少一次）

| 卷 | 交汇点 |
|---|---|
| 一 | 大祭值年相识、雪地捕鸟、月下瓜田听猹（少年情谊奠基） |
| 二 | 周家败落，主角暗中帮扶（打退逼债恶奴、赠野参——爽点+情谊，野参是伏笔） |
| 三 | 树人赴南京求学，渡口送别；约定"你练你的拳，我读我的书" |
| 五 | 仙台通信：树人信中述"幻灯片事件"前的心境，主角回信只八字——"笔比枪重，你好生写" |
| 六 | 树人回国，上海重逢，观主角擂台，热血沸腾（其文里第一次出现"一个练拳的朋友"彩蛋） |
| 八 | 1918读《狂人日记》；**1921读《故乡》——全书泪点核爆** |

## 名场面：1921年冬，北京（卷八预写要点）

- 树人把新发表的《故乡》递给主角。书里，中年闰土恭敬地喊了一声"老爷"。
- 现实中，两位老友对坐把盏。主角放下报纸，笑道："这一世，我没有喊，你也没有应。"
- 树人沉默良久："我写的不是你，是没了你的那个世道。"
- **功能**：点题——主角改的不只是自己的命，是一个意象的命。

## 写作要点

- 树人戏份少而精，每次出场必是情怀或主题重锤，不做日常工具人
- 对话风格：少年时灵动好奇（追着问"猹是什么"反过来被逗），成年后寡言锋利
- 永不点破"你是穿越者"——全书无人知晓主角来历，包括树人
