# 黄金三章细纲（ch001–003 逐拍）

> 验收标准：
> 1. 第一章前500字内必须出现**猹与钢叉**；三章内完成：穿越确认／身份确认／立志雏形／遇师钩子。
> 2. 每章一个情绪峰值、一个章末钩子；钩子必须具体（一句话说得清）。
> 3. 禁出现"系统/面板/属性"；现代梗只进内心吐槽且克制；绍兴方言词每章≤3处。
> 4. 原著意象回环：瓜田三原色（深蓝/金黄/碧绿）、"啦啦的响了"、"胯下窜"——必须全用，但不许整段抄原文，全部化用。

---

## ch001 月下瓜田（3000字 · 觉醒战）

**剧情功能**：黄金开篇——名场面+魂穿+第一战。
**本章目标**：读者300字内被画面抓住，1500字内喊"卧槽真是闰土"，章末必点下一章。

| 拍 | 内容 |
|---|---|
| 1 起（200字） | 火场。烟。热浪。坠落——前世之死只给**三句**，不给解释。"再睁眼，是月亮。" |
| 2 混乱（400字） | 八岁的手。冻疮。颈上凉——摸到一个银圈。瓜田。潮声。记忆碎片涌进来：爹剖竹的背影、娘在神龛前磕头、还有……猹。 |
| 3 猹来（500字） | "啦啦的响了"。瓜秧晃。一头老猹，獾一般大，毛皮油滑。身体先于脑子动了——手边正有一柄三股胡叉。（内心吐槽一句：这剧情我熟。） |
| 4 对峙（600字） | 八岁身对野兽，正解只有一个：等它扑。成年人的战术：踩瓜、引诱、侧身。**他知道它会"反从胯下窜"**——他读过这个故事！meta战栗：原来书里写的都是真的。 |
| 5 刺猹（700字） | 还原+升级：猹倒向他奔来、贴胯下窜——他早半拍拧腰，回马一叉。叉尖入肉的震颤从虎口传到心里。老猹挣命，他死不松手，被拖出三步，爪子在左肩犁开血口。猹不动了。月亮还挂着。 |
| 6 独白（400字） | 情绪峰值：前世练了一辈子"不能打"的传武，这一世第一叉，刺的是《故乡》里的猹。"这一叉……"他对着满手血笑出了声，又疼出了泪。 |
| 7 钩子（200字） | 村里灯笼乱晃，狗吠，人声越来越近，有人在喊——"闰土——！"他浑身一激灵。闰土？**我是闰土？** |

**自查**：穿越方式一句话带过不解释；猹=野兽非精怪（传统国术，无超凡）；伤势记账（左肩，卷末留疤）。

## ch002 我是闰土（3000字 · 身份确认）

**剧情功能**：身份确认+世界观信息差陈列（读者爽点）。
**本章目标**：交代1889/绍兴/章闰水；让读者看到"他知道甲午要来"的巨大张力。

| 拍 | 内容 |
|---|---|
| 1 起（300字） | 高烧。昏迷里两世记忆对撞：火场警报声/娘哭喊声；杠铃片/竹扁担；最后定格：水缸里一张紫色圆脸。 |
| 2 醒来（500字） | 床边的爹——章福庆，怀里还抱着那头死猹，又惊又疼又掩不住的骄傲。娘在神龛前还愿。他哑着嗓子问出年月：光绪十五年。心算：1889。**甲午，还有五年。** |
| 3 名动乡里（600字） | 小爽点：八岁娃月下独刺老猹精，全村轰动。乡邻围观、猹皮上墙、双喜阿发崇拜的眼神。主角虚弱地应付，心里在列清单：周树人八岁，在绍兴城里读私塾；郭云深还活着；李存义正当盛年；霍元甲二十一……（读者：这盘棋太大了） |
| 4 照脸（400字） | 水缸照脸：紫色圆脸，小毡帽，颈上明晃晃的银项圈——和课本里一模一样。他伸手碰了碰水面。情绪点："这一世，这张脸不会再有那种灰黄。" |
| 5 立志雏形（700字） | 夜里躺着算账：五年后甲午、十一年后庚子……他救不了历史（前世记忆全是雾，只剩大势），但能救身边的人，能练一身真东西，能在该在的地方站着。**"站着"二字首次浮现**（赵破虏口头禅的远伏笔，此处只作主角心声）。 |
| 6 钩子（500字） | 爹说猹皮明日拿去城里卖，顺路给周家送竹器——周家！主角心跳漏拍。爹又絮叨：村口茶亭这几日坐着个外乡老兵，伤了一条腿，白日黑夜地盯着咱们村看……"听说啊，是冲着你刺猹的事来的。" |

**自查**：信息差陈列用"心算清单"形式，节奏快；不出现"鲁迅"二字（全书统一用"迅哥儿/周树人"，留敬意与悬念）；爹娘形象=原著质感（神佛、疼儿）。

## ch003 竹匠的儿子（3000字 · 双线立志+遇师钩子）

**剧情功能**：家计线+武道线双启动；赵破虏登场。
**本章目标**：让读者信"这个家值得守护"，并对伤腿老兵产生强烈好奇。

| 拍 | 内容 |
|---|---|
| 1 起（400字） | 清晨剖竹。篾刀破竹的脆响，竹黄的青气。主角学着剖——手笨，被爹笑。（伏笔：竹艺，日后竹刻猹的手艺来源） |
| 2 金润泉（600字） | 洋行收竹器的金润泉登场：洋呢褂、文明棍，压价三成，话里带刀——"洋钉洋器满街是，你们这手工活，卖一年少一年喽。"爹陪着笑，手背上的筋在跳。主角看在眼里（内心吐槽：买办，百年前就这么气人）。 |
| 3 两条路（500字） | 主角心里定下两条路：持家——改良竹器（他见过后世的竹器工艺）；练武——去找那个老兵。**这一世不做看客。** |
| 4 土地庙（700字） | 伤退老兵赵破虏：破袄、酒葫芦、一条直不了的右腿。坐姿被主角一眼看穿——那是桩架，行伍里打出来的真功夫。老兵也在验他："听说你叉死过猹？站一炷香我看看。"主角提膝沉胯一沉——老兵眼皮一跳。 |
| 5 先抑（400字） | 老兵却不收："练武没出路。这是枪炮的年月，拳脚是死物。"转身进庙，关门。（为甲午之痛蓄势：他比谁都信这话，因为他验过。） |
| 6 钩子（400字） | 当夜。老兵推开庙门——月光底下，那个八岁的农家子还站在门外，桩架不散，已经站了整整一夜。露水打湿了小毡帽，颈上银项圈泛着光。赵破虏盯着看了很久，骂了一句脏话，侧身让开了门。 |

**自查**：金润泉恶行具体（压价+断生计）；老兵"先抑"符合其甲午创伤逻辑；站桩细节专业（提膝沉胯、尾闾中正）；章末画面感+收徒悬念双钩。

---

## 三章整体节奏核对

- 每章情绪峰值：ch001刺猹瞬间 / ch002"甲午还有五年" / ch003月下站桩
- 每章末钩子：喊名（我是谁）→ 周家+老兵（双线）→ 开门（收徒）
- 三章共埋伏笔：银项圈、竹艺、猹皮（入城由头）、赵破虏甲午创、"站着"
- 爽感配方：名场面情怀杀 + 信息差（他知道未来）+ 小人物尊严（爹的笑）+ 狠劲（站一夜）
