# 码字与存稿计划

## 产能假设

| 项 | 标准 |
|---|---|
| 章均 | 3000字（±500） |
| 日更目标 | 2章（6000字）；最低保1章 |
| 存稿红线 | 开书前存稿≥30章（卷一一半以上）；连载期存稿不得低于10章 |
| 卷间缓冲 | 每卷写完停更1–2天（用存稿填），完成卷收尾checklist再开新卷 |

## 单章产出循环（每章四步）

1. **细纲**：复制 `02_大纲/细纲模板.md`，填节拍与钩子（15–30分钟）
2. **初稿**：一口气写完，不回头改（1.5–2小时）
3. **自查**：过细纲模板末的四项一致性（年表/状态/人卡/红线）
4. **润色**：口语顺一遍；删水词；确认章末钩子落地（30分钟）

## 连载节奏

- **开书**：黄金三章一次放完；首周日更3章冲新书榜
- **日常**：日更2章；每10章（一大爽点章）安排在周末高峰
- **卷高潮章**：提前预告+当天加更1章
- **悲点章**（宗师之死）：当天只更1章，给读者情绪留白，书评区接龙悼词式运营

## 黄金三章打磨验收（动笔前复读）

1. ch001前500字见猹见叉；三章完成穿越/身份/立志/遇师四确认
2. 每章一个情绪峰值+一个具体钩子
3. 无系统面板字样；方言词每章≤3处；现代梗仅内心吐槽
4. 写完朗读一遍：短句占比七成以上，打戏段落不许有超过40字的长句
