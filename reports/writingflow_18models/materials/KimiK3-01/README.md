# 《闰土国术》（暂定名）创作项目

> 现代人魂穿少年闰土，练传统国术，打作恶的洋人，护一生的迅哥儿——
> 亲手打碎那层"可悲的厚障壁"。

## 写作流程（七阶段）

1. ✅ **定位确认**：100万字 / 无系统传统国术 / 魂穿 / 热血爽文 / 清末民初
2. **项目搭建**：本文件 + 全部目录模板
3. **设定层**：核心设定 → 历史年表 → 国术体系 → 人物卡×5 → 地理风物
4. **大纲层**：总纲（六卷骨架+爽点分布）→ 卷一详纲 → 前30章细纲
5. **黄金三章打磨**：开局逐字打磨，达标后再量产
6. **正文量产循环**：每章四步——细纲 → 初稿 → 自查（爽点/章末钩子/一致性）→ 润色
7. **运营发布**：书名简介3套备选；建议存稿30–50章开更

## 创作红线（任何章节不得违反）

1. **"打洋人"只打作恶个体**（洋兵暴徒、流氓拳手、侵略者、汉奸买办），不搞无差别排外——这是过审线，也是鲁迅精神的底线：他批判的是麻木，不是仇恨。
2. **史实宗师之死不改**：程廷华(1900)、王五(1900)、霍元甲(1910)、李存义(1921)。悲剧是主角的燃料，爽点放在主角自己挣来的胜利上。
3. **迅哥儿不写崩**：他可以被影响、被守护，但他必须长成那个写出《呐喊》的人。
4. **义和团写两面**：悲壮与愚昧并存。主角亲历其热血，也戳穿"刀枪不入"的骗局——这是全书武道观与启蒙观的交汇点。
