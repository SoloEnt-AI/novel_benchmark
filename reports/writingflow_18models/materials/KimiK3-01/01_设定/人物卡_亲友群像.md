# 人物卡：亲友群像

## 章家（主角家）

| 人物 | 设定 | 剧情功能 |
|---|---|---|
| **章福庆**（父） | 竹匠，老实手巧，常去城里周家做"忙月"；在神佛前许愿给儿子打了银项圈（原著原设定） | 生计线主体：洋钉洋货冲击手工业，压在他肩上；对儿子习武从"愁"到"荣"；卷六老人看孙儿站桩，圆满镜头 |
| **章杨氏**（母，虚构） | 温柔坚韧的农妇，信神佛 | 与父亲"神佛保佑"形成对照：儿子选择"自己挣命"；卷一咳疾小线（主角采药、改善营养——现代知识的第一次落地） |
| **水生**（子） | 约1913年生。原著中闰土第五子"水生"，黄瘦、颈上无银圈——本书中他健康结实，六岁就跟爹站桩 | 卷六交棒对象；"下一代的路"的具象 |

## 周家（迅哥儿家）

| 人物 | 设定 | 剧情功能 |
|---|---|---|
| **鲁瑞**（母） | 慈祥通达，待主角如子侄。原著中正是她说"你们先前不是哥弟称呼么？还是照旧：迅哥儿" | 两家情谊的锚；1919年接母迁京（《故乡》之行）的主角 |
| **周伯宜**（父） | 秀才，久病，1896年病逝 | 家败线；主角寻药、护当铺尊严的由头（不改其死） |
| **周福清**（祖父） | 翰林，1893年科场案发下狱 | 家败线源头（史实背景板，不正面出场） |
| **周作人 / 周建人**（弟） | 1885 / 1888年生 | 童年群戏；周作人线留作远期彩蛋（不展开） |
| **阿长（长妈妈）** | 周家保姆，朴拙善良，给迅哥儿买来绘图《山海经》（《阿长与山海经》） | 周家场景的暖色；主角识得她也是"下人里的好人"——阶层主题的日常化 |
| **宏儿** | 迅哥儿之侄 | 卷六：与水生玩耍——原著结尾"他们应该有新的生活"的兑现镜头 |

## 杜浦村与绍兴

| 人物 | 设定 | 剧情功能 |
|---|---|---|
| **双喜 / 阿发** | 村中少年，主角发小（致敬《社戏》人名的彩蛋） | 卷一童年群戏（社戏、偷罗汉豆可化用）；卷六再见时的阶层对照 |
| **杨二嫂（豆腐西施）** | 原著人物，市侩尖刻 | 卷六出场：厚障壁的市侩化身；主角既不惯着也不踩扁——写"可怜之人"的分寸 |

## 谢蕴秋（女主 · 弱感情线）

| 项 | 内容 |
|---|---|
| 籍贯 | 上虞，书香破落户 |
| 身份 | 绍兴大通学堂体操/剑术教员，秋瑾的学生；家传"越女剑"（半真半假，她自己都存疑——好梗） |
| 登场 | 卷三（1907年，主角26岁）：主角回乡暗护大通学堂，相识于危难 |
| 线 | 秋瑾就义后学堂瓦解 → 主角安置其北上传艺（武士会女教习）→ 卷四定情 → 卷五成婚 → 卷六携水生归乡 |
| 定位 | **弱感情线**：并肩战友式，不黏不抢戏；她的存在本身即主题（放足、读书、仗剑的新女性） |
| 写法禁忌 | 不写花瓶、不写拖油瓶、不为虐而虐；她的剑与主角的叉可有一段"叉剑和鸣"的双打名场面 |

## 革命线群像（史实，点到为止）

| 人物 | 出场 | 用法 |
|---|---|---|
| **秋瑾** | 卷三，大通学堂 | 凛凛女侠数面之缘；1907就义不可改——主角"救不及"是卷三悲点，谢蕴秋线的火种 |
| **徐锡麟 / 陶成章** | 卷三，转述与远景 | 光复会背景；同乡之烈 |
| **蔡元培** | 卷六提及 | 北大、五四、国立北京大学的背景板 |
