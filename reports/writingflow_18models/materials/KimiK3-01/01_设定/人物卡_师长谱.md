# 人物卡：师长与同道谱

> 用法：主角的每一段武学跃升都必须挂在具体的人身上。
> 虚构人物可以随意；史实人物只能在他们公认形象的边界内行动，**死期不改**。

## 赵破虏（虚构 · 启蒙师父）★全书第一泪点人物

| 项 | 内容 |
|---|---|
| 生卒 | 1836–1900，直隶人 |
| 出身 | 北洋武毅军哨官，戳脚、翻子拳好手 |
| 关键经历 | 甲午（1894–95）随军在辽东血战，右腿伤残；亲眼见功夫在排枪前成排倒下——"刀枪不入"四个字，他是用全哨弟兄的命验过的 |
| 流落 | 战后一路南逃，1890年流落到绍兴，被八岁的闰土（魂穿者）认出桩架功底，死缠拜师 |
| 所授 | 桩功筑基、戳脚、翻子；以及比拳更重的东西——对"真"与"假"的洁癖 |
| 性格 | 粗鲁、好酒、外冷内热；骂人可以，骗人不行 |
| 结局 | 1898年闻北方拳乱，执意北返；1900年没于天津乱军（主角赶到时只来得及听遗训） |
| 遗训（全书武道总纲） | "刀枪不入是假的。可'不敢打'才是真的病。拳练不到枪炮上，就练到人心里去——练到他们不敢再叫咱病夫。" |

**写作要点**：他教的不是名门正拳，是活命的东西和一口真气。他的死是主角
卷二血战的私人理由，也是全书"祛魅"主题的化身。**"站着"这句口头禅，源自他。**

## 李存义（史实 · 正师）

| 项 | 内容 |
|---|---|
| 生卒 | 1847–1921，河北深州人 |
| 拳种 | 形意（刘奇兰、郭云深正传），兼通八卦；"单刀李" |
| 史实要点 | 庚子年（1900）天津老龙头车站之役，传其率弟子持刀抗击联军；1911年于天津创中华武士会 |
| 书中职能 | 主角卷二拜入的正师：给名门正架、给江湖地位、给"武人也有家国"的样板 |
| 性格 | 厚重寡言，护犊子，有大局观；信"拳品即人品" |
| 结局 | 1921年善终（卷六，主角侍疾送终；临终传的不是拳谱，是一个"武"字） |

**写作要点**：他与赵破虏是"江湖"与"庙堂（武人之国）"的两极，
主角在两人之间完成武道人格。

## 宗师列传（短时出场，各自高光）

| 人物 | 生卒 | 出场 | 高光与写法 |
|---|---|---|---|

## 写作纪律

1. 史实宗师出场前，先查 `01_设定/历史年表.md` 确认其生卒与行踪窗口。
2. 他们对主角的态度=对"后浪"的态度：可以欣赏、可以考较、可以传艺，
   **不可谄媚、不可围着主角转**——宗师有宗师的分量。
3. 每一位的死亡/退场，都必须换回主角的一次认知升级（写入 `04_台账/伏笔台账.md`）。
