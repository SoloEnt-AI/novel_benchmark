# 历史年表：1881–1921（史实 ↔ 剧情映射）

> 用法：写任何章节前先查本表。史实事件是"墙"（不可改），剧情是"缝"（主角在缝隙中作为）。
> 主角的历史记忆模糊，读者比主角知道得多——用信息差做张力。

| 年份 | 史实 | 剧情映射 |
|---|---|---|
| 1881 | 9月25日，周树人生于绍兴东昌坊新台门。本项目设定：同年闰土（章闰水）生于杜浦村 | 主角与迅哥儿同龄——"仿佛年纪"的原著依据 |
| 1889 | 光绪十五年 | **卷一开篇**：8岁主角魂穿，瓜田刺猹觉醒 |
| 1893 | 周家大祭祀值年（原著事件底本）；冬，祖父周福清科场案发下狱，周家败落 | 初见迅哥儿（雪地捕鸟/看祭器/讲猹）；主角相助周家，结死交 |
| 1894–95 | 甲午战争；1895.4.17《马关条约》 | 启蒙师父（北洋老兵）之痛；主角立誓，卷一高潮 |
| 1896 | 周伯宜（鲁迅父）病逝 | 主角帮寻医、护当铺尊严；迅哥儿线暗涌 |
| 1898 | 戊戌变法（6–9月）；政变，谭嗣同等六君子就义；周树人入南京水师学堂 | **卷二**：主角在京，王五/源顺镖局线 |
| 1899–1900 | 义和团起；1900.6联军侵华，7月天津陷落（老龙头车站血战，传李存义持刀参战），8月北京陷落；程廷华殉国（被联军枪击）；王五殉国 | 卷二总高潮：全书第一大悲点；主角血战悟暗劲萌芽 |
| 1901 | 9.7《辛丑条约》；"量中华之物力，结与国之欢心"；天津俄力士斯其凡洛夫挑衅，霍元甲应战，俄人临阵退缩 | 卷三开局：主角结识霍元甲；租界时代开始 |
| 1902 | 周树人赴日，入东京弘文学院（嘉纳治五郎创办；鲁迅曾在此学柔道） | 书信线贯穿；日本武道反派线开启 |
| 1904–05 | 日俄战争，战场在中国东北 | 卷三："国土上的他国战争"，麻木与血性的对照 |
| 1905 | 废科举；同盟会成立；秋瑾加入光复会 | 时代齿轮；绍兴革命线铺垫 |
| 1906 | 仙台"幻灯片事件"，周树人弃医从文 | 迅哥儿线关键转折（书信/转述呈现） |
| 1907 | 7.6徐锡麟安庆起义失败殉难；7.15秋瑾就义于绍兴轩亭口，绝笔"秋风秋雨愁煞人" | 卷三悲点：主角回乡护大通学堂，救不及 |
| 1909 | 英国力士奥皮音上海设擂挑衅，霍元甲应邀赴沪，奥皮音未战先怯；周树人回国 | **卷四**开局 |
| 1910 | 精武体操会成立于上海（农劲荪等发起，霍元甲主教习）；9.14霍元甲去世（传被日本医生秋野以慢性药毒害）；周树人任教绍兴府中学堂 | 卷四主体：精武、擂台、毒案追查 |
| 1911 | 10.10武昌起义；李存义在天津创中华武士会 | 卷四收束；主角与中年迅哥儿重逢（对照原著"故乡重逢"，但没有那声"老爷"） |
| 1912 | 民国成立；周树人入教育部，随部迁北京 | 过渡；国术界新旧交替 |
| 1915 | 日本提"二十一条"（1月），5月签约；9月《青年杂志》创刊（后改名《新青年》）；孙禄堂出版《形意拳学》 | **卷五**：国术著书立说线 + 新文化线交汇 |
| 1918 | 俄国力士康泰尔在北京设擂，连败武师后被挫败（王子平、韩慕侠相关，传说多版本）；5月《狂人日记》发表，"鲁迅"笔名出世 | 卷五双高潮：擂台战 + 迅哥儿觉醒 |
| 1919 | 5.4五四运动；12月，鲁迅回绍兴接母亲迁京（《故乡》素材之行） | **卷六**开局：主角全程陪同——改写"回乡" |
| 1921 | 1月《故乡》写成，5月发表于《新青年》第九卷第一号；李存义去世 | 全书收束：这一次，闰土哥与迅哥儿并肩看月 |

## 史实弹性说明

- **不可动**：战争胜负、条约、就义/死亡节点、发表年份。这些是"天"。
- **可改编**：民间传说类（老龙头之战李存义参战、康泰尔擂细节、霍元甲毒案）——
  本身多版本，给主角留参与空间。改编时注明"据传说演绎"。
- **可虚构**：主角及其师承、具体战斗、与史实人物的私人交往——但不得让史实人物
  做出违背其公认形象的事。
