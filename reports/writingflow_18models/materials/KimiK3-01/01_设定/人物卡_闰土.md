# 人物卡：闰土（主角）

## 基本信息

| 项 | 内容 |
|---|---|
| 姓名 | 章闰水，小名闰土（闰月生，五行缺土——原著原设定） |
| 生年 | 1881（与周树人同龄，"仿佛年纪"的原著依据） |
| 籍贯 | 绍兴城外杜浦村 |
| 家世 | 父章福庆（竹匠，常去城里周家做"忙月"）；母章杨氏（虚构）；家贫 |
| 身份流变 | 农家子 → 学徒武人 → 镖师/拳师 → 精武同袍 → 一代宗师 → 著书授徒 |

## 前世

沈铁，2020年代民间国术馆教练，三十年苦练，有真东西——
却活在"传武不能打"被全网群嘲的时代，没有证明的战场。救火救人牺牲。

**心结即本书引擎**：这一世，战场遍地都是。
他不要当什么天下第一，他要替传武、也替这个民族，把"东亚病夫"四个字打回去。

## 性格

- **表**：农家子的憨厚实诚，话少，先礼后兵，重承诺
- **里**：成年灵魂的清醒、狠劲、冷幽默（内心吐槽=网文爽感调节器）
- **对敌**：不出手则已，出手不留隐患；但绝不滥杀——打的是"作恶"，不是"人种"
- **对友**：护短。尤其对迅哥儿——"这一世，我看谁敢让他弯腰。"

## 成长弧（六卷）

| 卷 | 弧光 |
|---|---|
| 一 | 接受闰土身份 → 守护小家 → 甲午之痛立大志 |
| 二 | 学艺成人 → 戊戌庚子两次"打不过历史" → 血火淬炼，暗劲萌芽 |
| 三 | 津门立足成名 → 明白"拳打在人身上，要响在人心里" |
| 四 | 精武同袍 → 霍元甲之死 → 从"打洋人"升维到"立精神" |
| 五 | 宗师化劲 → 与迅哥儿双线汇合：武之路与文之路相认 |
| 六 | 放下与交棒 → 见证《故乡》→ "路"留给下一代 |

## 心魔与弱点（张力来源）

1. **全知的无力**：知道灾难要来，细节全是雾，救不了想救的人——卷二重点拷打。
2. **"偷走鲁迅"的负罪感**：我改变了他的人生，他还会成为鲁迅吗？——卷五《狂人日记》亲手解答。
3. **身体代价**：卷一的孩童体能限制；卷四起旧伤累积（真实系，胜利要还利息）。
4. **兵器执念**：钢叉是标志也是局限——卷三起叉法与大枪互补，"手里的叉，心里的枪"。

## 形象演变

8岁：紫色圆脸、小毡帽、银项圈（原著原样）→ 12岁：精瘦黝黑，满手茧 →
19岁：庚子血战后左眉一道疤 → 30岁：布衫布鞋貌不惊人，站如松 →
40岁：鬓角微霜，桩功人的笔直，叉不离身。

## 语言习惯

- 绍兴土话底色；内心独白偶尔蹦现代词（吐槽调节）
- 口头禅：**"站着。"**——桩功的"站"，做人的"站"。卷六最后一章回环。

## 写作注意

- 主角的"现代知识"只用在训练与见识，**不搞发明、不搞工业流**——这是国术文，不是种田文。
- 打洋人戏份每场必须挂载"具体恶行"，正当性先于爽感。
- 他可以输（对历史），不可以怂（对恶人）。
