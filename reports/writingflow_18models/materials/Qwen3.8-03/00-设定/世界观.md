# 世界观设定

> 时代背景：清末民初（1895-1925），中国最屈辱也最热血的三十年。
> 核心矛盾：国术（中华武道）vs 洋人（列强武力），个人命运 vs 国家命运。

---

## 一、时代大背景

### 1895年（故事起点）
- 甲午战争惨败，北洋水师全军覆没
- 《马关条约》签订，割让台湾、赔款两亿两白银
- 举国震惊，"天朝上国"迷梦彻底破碎
- 民间尚武之风暗涌，"强国强种"思潮萌芽

### 1898-1900年
- 戊戌变法失败，谭嗣同等六君子就义
- 义和团运动兴起，"扶清灭洋"
- 八国联军侵华，北京沦陷，庚子国变

### 1901-1911年
- 《辛丑条约》签订，四亿五千万两赔款
- 清廷新政，废科举，练新军
- 革命党暗流涌动，孙中山、黄兴等人奔走革命
- 日俄战争（1904-1905），在中国东北打，清廷"中立"

### 1911-1919年
- 辛亥革命，清帝退位，民国建立
- 军阀混战，袁世凯称帝，张勋复辟
- 一战爆发，中国参战
- 巴黎和会外交失败，五四运动

### 1919-1925年（故事终点）
- 军阀割据达到顶峰
- 国术开始被重新重视（中央国术馆1928年成立的前奏）
- 列强仍在，但中国人民开始觉醒

## 二、地理格局

### 主要活动区域

| 区域 | 特点 | 故事作用 |
|------|------|----------|
| **浙江绍兴（故乡）** | 水乡小镇，鲁迅故乡，闰土老家 | 卷一主场景，穿越落地 |
| **上海（十里洋场）** | 租界林立，华洋杂处，鱼龙混杂 | 中期主场景，打洋人擂台 |
| **天津（武林重镇）** | 北方武术中心，霍元甲故乡，义和团发源地 | 卷二卷三主场景 |
| **北京（帝都）** | 大内高手、王府武师、八旗子弟 | 卷三卷四场景 |
| **东北（关外）** | 日俄势力交错，马匪横行 | 卷三支线 |
| **广州/佛山（南拳圣地）** | 咏春、洪拳、蔡李佛 | 卷四支线 |
| **海外（日本/欧洲）** | 最终扬威之地 | 卷五高潮 |

### 绍兴·故乡设定（卷一核心）

- **地点原型**：鲁迅《故乡》中的"鲁镇"，实为绍兴东浦/安昌一带
- **闰土家**：海边农村，父亲是"忙月"（给地主家做短工），家贫
- **周家（鲁迅家）**：当地士绅，鲁迅（周树人）此时约14岁，少年闰土约13岁
- **周边环境**：海边有盐田、沙地（种西瓜），有集市、码头
- **矛盾来源**：
  - 地方恶霸（地主、盐商）欺压百姓
  - 洋人传教士在镇上建教堂，仗势欺人
  - 官府腐败，与洋人勾结

## 三、社会阶层

| 阶层 | 代表 | 与主角关系 |
|------|------|-----------|
| **列强洋人** | 各国领事、商人、军人、传教士 | 主要对手 |
| **清廷/官府** | 地方官、衙役、新军 | 前期压迫者，后期部分转为盟友 |
| **士绅地主** | 周家（鲁迅家）、地方乡绅 | 复杂关系（鲁迅是友，地主是敌） |
| **武林人士** | 各门派拳师、镖师、江湖人 | 师父、盟友、对手 |
| **底层百姓** | 农民、工人、小贩 | 主角出身，保护对象 |
| **革命党** | 孙中山系、光复会、同盟会 | 中后期盟友 |
| **义和团** | 拳民、大师兄 | 卷二重要势力，悲剧性 |

## 四、核心世界观规则

1. **国术真实存在但隐于民间**：不是人人都会武功，真正的高手藏在民间、镖局、军队中。普通百姓只知道"练家子"的传说。

2. **洋人靠枪炮，不靠武功**：列强的真正威胁是坚船利炮，不是个人武力。但洋人中也有高手（军人、冒险家、武道家），他们是主角"打脸"的直接对象。

3. **国术不能对抗军队**：这是铁律。再高的武功也挡不住排枪齐射。主角的定位不是"一个人打败一支军队"，而是"在个人对决中为国争光"+"在特殊任务中发挥奇效"。

4. **时代在变**：从冷兵器到热兵器的过渡期。国术的没落是历史趋势，但主角要证明"国术的精神不灭"。

5. **穷文富武**：练武需要大量资源（食物、药物、时间），这是主角前期的核心困境。

---

## 五、氛围基调

- **前期（卷一卷二）**：压抑中孕育希望。国弱民穷，洋人横行，主角从底层崛起。
- **中期（卷三卷四）**：热血与悲壮并存。个人武力再强也挡不住时代洪流，但每一次胜利都点燃希望。
- **后期（卷五）**：扬眉吐气。国术宗师扬威海外，"中国人不是东亚病夫"。
