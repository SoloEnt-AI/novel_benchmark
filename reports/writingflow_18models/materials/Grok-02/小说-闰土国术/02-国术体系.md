# 国术力量体系

> 原则：传统质感、可验证、可对拼、服务爽文。不修仙、不面板、不飞天。

## 一、总纲：武之四梁

主角成长看四条轴，缺一不可：

| 轴 | 含义 | 读者感知 |
|----|------|----------|
| **劲** | 明劲→暗劲→化劲，发力与抗打 | 打得动、打得穿、接得住 |
| **架** | 身法、步法、器械、阵势 | 打得到、走得脱、带得了人 |
| **胆** | 临枪、临众、临死的心智 | 敢上、不崩、能指挥 |
| **识** | 战术、训练法、识人、布局 | 越打越会打，越带越强 |

金手指主要加成 **识**（科学训练与推演），并小幅加速 **劲** 的体悟。

## 二、个人境界（对外可称“武阶”，对内按劲划分）

### 1. 练架（入门）
- **表现**：站桩、基本拳架、跌扑滚翻、体能
- **战力**：收拾地痞一人；两三人合围仍险
- **标志事件**：首次当众打倒乡霸爪牙
- **主角开局**：魂穿后凭借现代格斗底子 + 原身少年筋骨，迅速越过纯新手

### 2. 明劲（拳师）
- **表现**：力从脚起、腰马合一，拳风可闻，击打有穿透感
- **战力**：稳胜普通武馆教习之下；可破单刀单枪的生疏对手
- **标志**：一寸劲打出内伤/短促倒地；能教人基本架

### 3. 暗劲（整劲）
- **表现**：节节贯穿，接触即发，外表不大开大合
- **战力**：近身爆杀；可在枪刺第一刺前切入；巷战、船头、堂屋优势极大
- **标志**：搭手即崩；能破“花架子名师”

### 4. 化劲（懂劲）
- **表现**：听劲、借力、引进落空；多人围攻中游刃
- **战力**：以弱胜强的名场面担当；可做护卫总教头
- **标志**：空手入白刃（有条件）、四两拨千斤的公开演示

### 5. 炼神 / 武胆（宗师门槛）
- **表现**：气势压场、预判杀机、乱战不迷；稍触即知 aggro 与破绽
- **战力**：镇场；带领小队完成“不可能的近战任务”
- **标志**：枪口下不乱，一呼百应

### 6. 宗师 / 武圣（卷五）
- **表现**：开派立派、兵武合一、训练体系可复制
- **战力**：个人已非唯一答案；其传人与法门改变局部战局
- **标志**：国术从“奇技”变为“可列装的战力模块”

**注意**：境界名称在正文中宜由配角传颂、门内口耳相传，避免主角自报“我已化劲”。

## 三、功法与传承路线（主角主修）

### 原点：沙地杂学 + 现代底子
- 捕鱼、刺猹、摔跤、棍棒、农活中的实用劲
- 现代：拳击/摔柔常识、力量训练、呼吸与恢复

### 卷一核心：《破暗十二桩》+ 本地拳
- 来源：落魄老镖师 / 隐居伤残教头（人物卡详见）
- 内容：桩功、步法、钻拳、肘靠、短兵
- 作用：建立“真传”身份，区别于街头野路子

### 卷二扩展：形意/八卦/南拳等择一融合
- 不搞百科全书式收集；**一条主脉 + 两门辅证**
- 主脉建议：**形意（打）** 或 **长拳短打结合**
- 辅：轻身步法、器械（刀、棍、枪——尤重枪，为破刺刀与对接新军）

### 中后期：兵武合一
- 刺刀术、驳壳枪掏近战、盾牌/桌椅掩体、夜袭绳索
- 国术教范：把劲力训练写成可给大兵练的操典（爽点+格局）

## 四、金手指细则

### A. 现代认知（常驻）
- 训练周期：强度/恢复/伤病管理 → 同样三个月，别人出徒他出师
- 营养：在贫困条件下仍知如何用有限食物提高恢复（黄豆、内脏、蛋等）
- 对抗策略：预判西洋拳、刺刀术、警棍、军体拳的弱点
- 组织：会画训练表、会分层教学、会搞对抗考核

### B. 武学推演（战斗中短暂）
- **触发**：生死压强、极度专注、重复拆招之后
- **体感**：数息内“世界变慢”，看清发力链与步法死角
- **代价**：脑力/体力透支；不可连开；推演不等于身体跟得上（需练到位才能打出）
- **成长**：同一招第二次推演收益递减，逼主角真练真打

### 禁止出现
- 系统商城、签到、抽奖
- 内力外放、隔空伤人
- 无条件的子弹时间

## 五、国术 vs 热武器（圆逻辑，保爽点）

### 国术优势区
- 距离：三步内、转角、船舱、轿内、夜巷
- 状态：突袭、刺客、护卫、捉拿、乱战白刃
- 对象：单兵、小队、依赖单发/慢速装填的旧式情境
- 心理：杀气、震慑、近身恐惧（洋人同样怕贴身）

### 国术劣势区
- 开阔地排队枪、机枪阵地、舰炮、严密壕沟
- **破法**：不硬刚 → 改地形、改时间、改人数结构、改任务目标
  - 目标从“歼灭军团”改为“斩首、夺旗、救俘、破胆、夺械”
  - 用民团+地形+内应+国术尖刀班

### 名场面公式
1. 对方亮枪， debuff 全场
2. 主角逼近/诱敌/借物
3. 贴身爆发（暗劲/短兵）
4. 枪哑或人倒
5. 舆论：“国术也能打洋人”

## 六、战力阶梯（反派与舞台匹配）

| 阶段 | 对手类型 | 对应主角大致层次 |
|------|----------|------------------|
| 开篇 | 地痞、乡霸家丁 | 练架→明劲 |
| 卷一末 | 教会打手、退职武弁 | 明劲稳、暗劲初 |
| 卷二 | 武馆名家、镖师、擂台客 | 暗劲 |
| 卷三 | 西捕拳师、洋行护卫、枪手 | 暗劲→化劲 |
| 卷四 | 军官、特务、多人战术围杀 | 化劲+武胆+组织 |
| 卷五 | 理念+武力双BOSS、最终阵列 | 宗师级+体系胜 |

## 七、传授与开派（长期目标）

**三级教学体系（中后期亮点）：**
1. **强身层**：乡民、学生、女眷——桩步、摔跌、胆量
2. **护身层**：商队、护院、巡丁——短打、棍刀、二人配合
3. **战身层**：尖刀、卫队、刺客反制——暗劲、枪刺对接、夜战

开派名号备选：
- 沙地门
- 闰土武馆 → 镇海武馆
- 振华拳社
- 国术“强身会/技击营”（民初风）

## 八、正文呈现技巧

1. **用结果展示境界**，少贴标签。
2. 打戏结构：压迫 → 换位 → 一招可叫出的名（如“崩拳钻入”）→ 余波（吐血、断牙、全场静）。
3. 每卷至少一次“公开赛/比武/当众破枪”的舆论战。
4. 训练戏要短、要有指标（比如“三十日能抗十合”），服务期待感。
