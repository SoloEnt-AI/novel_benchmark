# 主角设定：闰水生（闰土）

## 一、基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 闰水生（小名闰土） |
| **年龄** | 穿越时18岁（1912年） |
| **籍贯** | 浙江绍兴 |
| **身份** | 农民之子 → 武馆学徒 → 国术宗师 |
| **外貌** | 身材魁梧，面容坚毅，双目有神 |

## 二、穿越设定

### 1. 穿越前
- **身份**：现代国术爱好者、历史系大学生
- **特长**：精通形意拳、了解民国历史
- **性格**：热血正义、不甘平庸

### 2. 穿越后
- **时间点**：1912年，民国刚建立
- **身份**：绍兴农民闰土，家境贫寒
- **金手指**：
  - 现代人的见识和思维
  - 对形意拳的理解（理论）
  - 知道历史走向
  - 身体素质优秀（闰土原本就是农村少年，体力好）

## 三、性格特点

### 1. 核心性格
- **热血正义**：见不得同胞受欺负
- **隐忍坚韧**：前期低调发育，不轻易暴露实力
- **民族自尊**：对洋人欺压深恶痛绝
- **尊师重道**：对师父忠心耿耿

### 2. 成长变化
| 阶段 | 性格特点 |
|------|----------|
| 第一卷 | 隐忍低调，暗中修炼 |
| 第二卷 | 初露锋芒，嫉恶如仇 |
| 第三卷 | 自信张扬，名震一方 |
| 第四卷 | 沉稳大气，宗师风范 |
| 第五卷 | 超然物外，一代宗师 |

## 四、武学路线

### 1. 修炼进度
| 时间 | 境界 | 武学 | 战力 |
|------|------|------|------|
| 1912年 | 无 | 无 | 普通人 |
| 1912年底 | 明劲初期 | 形意五行拳 | 可敌5人 |
| 1913年 | 明劲中期 | 形意拳熟练 | 可敌10人 |
| 1914年 | 明劲→暗劲 | 形意十二形 | 可敌30人 |
| 1915年 | 暗劲 | 形意+太极 | 可敌50人 |
| 1916年 | 暗劲→化劲 | 三派融合 | 可敌百人 |
| 1917年 | 化劲 | 自创武学 | 可敌数百人 |
| 1918年 | 化劲→罡劲 | 大成 | 可敌千人 |
| 1919年 | 罡劲 | 宗师 | 当世顶尖 |
| 1920年 | 罡劲→丹道 | 传说 | 一代宗师 |

### 2. 招牌武技
- **形意·崩拳**：一击必杀，势不可挡
- **形意·炮拳**：刚猛爆裂，开山裂石
- **太极·揽雀尾**：化劲巅峰，四两拨千斤
- **八卦·游身掌**：身法如龙，群战无敌
- **绝招·五行归一**：五拳合一，威力无穷

## 五、人物关系

### 1. 师父
- **形意师父**：李洛能传人，隐居绍兴
- **太极师父**：杨氏太极传人，上海精武会
- **八卦师父**：程派八卦掌高手，天津

### 2. 兄弟
- **阿Q**：同村好友，性格乐观（参考鲁迅）
- **王二**：码头工人，力大无穷
- **张三**：书生出身，精通医术

### 3. 红颜
- **秀姑**：青梅竹马，温柔贤惠
- **林婉儿**：上海富家女，进步青年
- **小野樱子**：日本女子，武馆学徒（后期）

### 4. 敌人
- **前期**：赵太爷（乡绅）、恶霸李四
- **中期**：洋人拳师、买办陈老板
- **后期**：日本武士、外国格斗冠军

## 七、人物弧光

### 起点
- 贫苦农民，被人看不起
- 穿越者，有现代人的优越感

### 转折
- 拜师学艺，发现武术的博大精深
- 目睹洋人欺压，激发民族意识

### 高潮
- 擂台击败洋人，扬我国威
- 创立武馆，传授国术

### 终点
- 一代宗师，受人敬仰
- 国术推广，民族自强
