# 反派与对手梯度

> 打洋人要**分层**。每一层对手解决一种蔑视、一种压迫，并逼主角升一级能力/眼界。  
> 原则：具体恶人可恨可打；不写成漫画式全体脸谱，但爽文允许夸张。

---

## 一、对手总梯度

| 层级 | 类型 | 代表冲突 | 主角应对 |
|------|------|----------|----------|
| L1 | 乡里恶 | 抢、辱、占田、砸场 | 拳脚+胆气 |
| L2 | 士绅爪牙 | “泥腿子也配” | 明劲+规矩内打脸 |
| L3 | 教会/买办狗腿 | 仗洋自重 | 智取+首次见枪 |
| L4 | 租界巡捕/洋拳手 | 武力与制度双压制 | 暗劲+破枪战术 |
| L5 | 洋行武装/利益集团 | 资源与组织 | 带队+布局 |
| L6 | 象征性大敌 | “中国拳不行”的活广告 | 化劲/宗师之战 |

## 二、卷一主要反派

### 2.1 地头蛇·刘疤（暂定）

| 项目 | 内容 |
|------|------|
| 身份 | 乡绅豢养的管事/赌棍头 |
| 恶行 | 欺行霸市、调戏民女、抢瓜占地、踩人尊严 |
| 战力 | 有几下子，带一群打手 |
| 功能 | 开篇仇恨与第一次公开打脸 |
| 结局 | 被主角当众废武/逐出，余党引出县城线 |

### 2.2 乡绅·钱贡生（暂定）

| 项目 | 内容 |
|------|------|
| 身份 | 地方士绅，嘴上仁义 |
| 恶行 | 合法外衣下的剥削；勾结县衙 |
| 功能 | 教主角“拳头之外还有规矩与笔” |
| 结局 | 卷一不必死，可败可逃，留到卷二用官面手段反扑 |

## 三、镜像反派·假洋人（长线）

### 3.1 赵子洋（暂定名，可改）

| 项目 | 内容 |
|------|------|
| 年龄 | 与主角相仿或略长 |
| 身份 | 买办家少爷 / 教会义学出来的“新青年” |
| 表象 | 西服、洋话、文明棍，鄙视国术与乡土 |
| 真实 | 内心自卑，靠踩同胞换洋主子的一点颜色 |
| 能力 | 会一点洋拳/刺刀术，有枪有人有钱 |
| 与主角 | **镜像**：都想“出人头地”；一个用脊梁，一个用膝盖 |
| 长线 | 卷二露头 → 卷三租界对决 → 中后期可反复作为“汉奸式”障碍 |
| 高潮用法 | 当众跪与不跪的对照；或其最终被洋主子抛弃 |

**一句对立：**  
闰土：中国拳贵在不跪。  
赵子洋：不跪的都是穷鬼。

## 四、洋人对手（具象化，避免空洞）

### 4.1 神父/牧师身边的“拳头”（卷二）

- 不一定是神职本人；可以是护院、译员、恶仆
- 冲突：强买田地、包庇爪牙、打着信仰欺人
- 注意：批判的是**仗势欺人**，不把信仰本身写成魔教

### 4.2 租界巡捕头·“铁腕”汤姆/马丁（暂定，卷三）

| 项目 | 内容 |
|------|------|
| 身份 | 租界巡捕房武斗骨干，或退役军人 |
| 特点 | 身高体重、格斗训练、枪械熟练、懂规则霸凌 |
| 功能 | 第一次真正的“国术 vs 现代暴力体系”
| 胜法 | 窄巷、雨夜、近身、器械、团队配合；惨胜 |

### 4.3 洋行武斗顾问·布莱克（暂定，卷四–五）

- 更高一层：会组织武装、懂中国江湖、专门研究怎么打中国拳师
- 可成为“破国术理论”的反派侧代言人
- 最终被主角用更高明的拳理+战术当场打脸

### 4.4 象征性大敌（卷五–六）

- 不必是国家元首；可以是：
  - 某国在华武斗俱乐部冠军 + 军火商背景
  - 或“万国竞技”场上的权威裁判/拳王
- 一战定主题：不是中国人不能打，是中国人被按着打太久了

## 五、制度型反派（无具体人脸时）

有时敌人是规矩本身：

- 租界治外法权  
- 县衙“洋人案子不能办”  
- 报馆被控、武馆被封  
- 合同陷阱、债务陷阱  

**写法**：给制度一张“执行者的脸”，主角打执行者，同时用智囊线撬制度缝隙。

## 六、反派写作清单

每个重要反派出场前写清：

1. 他凭什么欺人？（拳/枪/钱/权/洋身份）  
2. 他看不上主角哪一点？（穷、土、黄皮肤、国术）  
3. 他倒台时读者爽在哪？（身份反转/当众受辱/被其主子弃）  
4. 他逼出了主角什么成长？  
5. 死或逃？是否留尾巴？
