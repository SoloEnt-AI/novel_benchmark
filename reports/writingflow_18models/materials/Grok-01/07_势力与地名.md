# 07 势力与地名

> 随正文扩展。地名可虚实结合：绍兴、杭州、上海用实；村镇、武馆、洋行可用化名。

---

## 一、卷一地图：乡野

| 地点 | 功能 | 感官锚点 |
|------|------|----------|
| 瓜地 / 沙地 | 开篇、夜战、练功 | 月、露、藤、虫鸣 |
| 闰土家 | 温情与压力 | 灶烟、破席、粥香 |
| 村口 | 信息、欺压、测量钉 | 老树、土路、告示 |
| 祠堂 | 公议、大打脸 | 牌位、香、烛 |
| 破庙 / 后山 | 师父隐居、试炼 | 尘土、拆招声、冷灶 |
| 集市 / 庙会 | 人潮、冲突高潮 | 吆喝、糖人、锣鼓 |
| 河埠头 | 出入、运货 | 船桨、水气 |

**地方势力**
- 钱贡生宅与佃户网
- 刘疤赌棚/打手
- 族长（中立偏保守）
- 县衙触角（地保）

## 二、卷二地图：县城

| 地点 | 功能 |
|------|------|
| 城门洞 | 入城仪式感 |
| 武馆街 | 挑战、门派眼色 |
| 县衙前 | 有理说不清 |
| 码头 | 破枪战、货与人 |
| 教堂/教会医院外 | 洋势力初显（写外围） |
| 沈文澜寓所/书店 | 智囊、识字 |
| 小拳场/租屋武棚 | 主角立足点 |

**势力**
- 城中武馆联盟（排斥野路子）
- 钱贡生城中亲戚/师爷
- 教会周边护院与译员
- 赵子洋买办家庭

## 三、卷三地图：上海

| 地点 | 功能 |
|------|------|
| 十六铺 / 码头 | 到达冲击 |
| 华界弄堂 | 生活、窄巷战 |
| 租界马路 | 灯火、规则羞辱 |
| 巡捕房外围 | 制度压力 |
| 民族厂房 | 护厂戏 |
| 报馆 | 舆论战 |
| 武馆联合总坛 | 江湖政治 |

**势力**
- 租界巡捕房
- 洋行（某某洋行）
- 会党（灰色盟友）
- 报馆与读者舆论
- 民族资本家
