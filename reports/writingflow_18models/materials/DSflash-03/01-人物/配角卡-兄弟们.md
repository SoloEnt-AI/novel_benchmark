# 配角卡 —— 兄弟团

---

## 一、水生（发小）

| 项目 | 内容 |
|------|------|
| **身份** | 同村玩伴，闰土的铁杆跟班 |
| **年龄** | 与闰土同龄 |
| **性格** | 憨厚老实、嗓门大、胆子小但讲义气 |
| **外貌** | 黑壮结实，圆脸大眼 |
| **武学潜力** | 一般，但吃苦耐劳，后期可达暗劲初入 |
| **作用** | 衬托闰土的成长，提供情感锚点（代表"故乡"） |

**角色故事：**
水生是原著中闰土的弟弟辈角色。在这个故事里，他是闰土最忠实的伙伴。闰土练武时他在旁边递水擦汗，闰土打架时他壮着胆子帮忙。他代表着闰土"曾经的那个世界"，提醒主角不忘初心。

**经典互动：**
- "闰土哥，你真要跟那人打？他好壮啊……"
- "怕什么？有我在，谁也动不了你。"

---

## 二、林武（大师兄）

| 项目 | 内容 |
|------|------|
| **身份** | 陈铁山门下大弟子，闰土的师兄 |
| **年龄** | 约28岁（初见时） |
| **性格** | 豪爽仗义、有点莽撞、重情重义 |
| **外貌** | 虎背熊腰，国字脸，络腮胡 |
| **武学境界** | 明劲圆满（后突破至暗劲初入） |
| **作用** | 前期为闰土挡风遮雨，后成为闰土的左膀右臂 |

**角色故事：**
林武是师父陈铁山收的第一个徒弟，跟随师父已经十年。他资质一般但极为刻苦，是典型的"笨鸟先飞"。初见闰土时看不起这个瘦弱的小师弟，但被闰土的悟性折服，从此对闰土服服帖帖。

**经典互动：**
- "小师弟，你这招我练了三年才学会，你三天就……你是不是人？"
- "以后有人欺负你，报我的名字——算了，还是报你自己的吧，你比我有出息。"

## 三、配角团定位总结

| 角色 | 定位 | 情感功能 | 剧情功能 |
|------|------|----------|----------|
| **水生** | 发小/兄弟 | 代表故乡与初心 | 见证闰土的崛起 |
| **林武** | 师兄/战友 | 热血兄弟情 | 并肩作战的伙伴 |
| **后续可加** | 江湖豪杰 | 志同道合 | 拓展势力版图 |
