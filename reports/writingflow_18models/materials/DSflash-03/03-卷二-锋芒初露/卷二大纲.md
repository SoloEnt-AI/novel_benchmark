# 第二卷「锋芒初露」—— 分卷细纲

---

## 一、卷信息

| 项目 | 内容 |
|------|------|
| **卷名** | 锋芒初露 |
| **字数** | 约20万字（50-60章） |
| **时间跨度** | 1894年 — 1898年 |
| **主要场景** | 上海（主打）、天津 |
| **主角境界** | 暗劲初入 → 暗劲圆满 |
| **核心主题** | 闯荡·蜕变 |

---

## 二、本卷核心爽点

1. **乡下少年进城**：从没见过世面的闰土进入上海十里洋场，各种反差
2. **暗劲质变**：从明劲到暗劲的跨越，实力飞跃
3. **打擂台**：在上海武术界立威
4. **初遇宿敌**：伊藤龙之介首次登场
5. **感情线开篇**：沈清荷登场

---

## 三、分章细纲概要（章节目录草稿）

| 章节范围 | 核心事件 | 爽点设计 |
|----------|----------|----------|
| **第1-5章** | 三人组来到上海。被租界的繁华震撼，也被洋人的嚣张刺激。盘缠被偷，流落街头。闰土第一次见到"华人与狗不得入内"的牌子。 | **反差+屈辱**：建立奋斗动机 |
| **第6-10章** | 为生计所迫，闰土在码头打零工。遇到码头恶霸欺压工人，闰土出手教训。被当地武馆馆主看中，邀请做教习。 | **初露锋芒**：被动装逼 |
| **第11-15章** | 入驻武馆，开始接触上海武术界。发现上海武术界的复杂：门派之争、洋人势力、地头蛇。**暗劲初入**突破。 | **世界观扩展** |
| **第16-20章** | 顾明远登场。顾明远被码头恶霸欺负，闰土救他。两人结交，顾明远给闰土带来新知识。**沈清荷**第一次出现（路过/旁观）。 | **智囊+感情线开启** |
| **第21-25章** | 武馆之间的摩擦。有武馆投靠洋人，打压本地武馆。闰土代表本馆出战，连胜三场。名声鹊起。 | **连续打脸** |
| **第26-30章** | **伊藤龙之介首次登场**。日本武士来上海交流（实为示威），击败多家武馆馆主。闰土与其交手，苦战平局。 | **宿敌登场** |
| **第31-35章** | 养伤+反思。顾明远帮闰土分析局势。沈清荷因学堂的事与闰土有更多交集。**暗劲小成**。 | **休整期** |
| **第36-40章** | 租界发生洋人打死黄包车夫事件。洋人被判无罪，引发民愤。闰土决定为死者讨公道。 | **民族矛盾爆发** |
| **第41-45章** | 闰土设擂挑战洋人拳师（**约翰·史密斯**）。英国海军拳击冠军在租界摆擂。闰土与其大战。 | **本卷高潮战斗** |
| **第46-50章** | 艰难战胜约翰·史密斯。闰土一战成名，但也引来了更多洋人的仇视。租界势力开始打压他。 | **树大招风** |
| **第51-55章** | 各方势力施压。武馆被砸、顾明远被打伤。闰土意识到在上海光靠拳头不够。 | **低谷** |
| **第56-60章** | 闰土决定去天津寻找更多机会。告别沈清荷（"等我回来"）。三人组前往天津。**暗劲圆满**。卷末。 | **新的征程** |
