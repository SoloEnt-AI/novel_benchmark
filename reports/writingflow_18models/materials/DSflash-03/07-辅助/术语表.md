# 国术术语表

---

## 一、境界类

| 术语 | 含义 |
|------|------|
| **明劲** | 国术入门，筋骨之力，刚猛霸道，一拳一脚下有风声 |
| **暗劲** | 内劲外放，劲力穿透表面直达内部，伤人无形 |
| **化劲** | 周身一体，全身无处不可发力，借力打力，四两拨千斤 |
| **抱丹** | 气血归元如金丹一粒，体力耐力爆发力质变 |
| **见神不坏** | 国术至高境界，打破人体极限，一举一动合于天地 |
| **整劲** | 全身力量整合成一体的发力方式 |
| **透劲** | 力量穿透表面直达内部的技巧 |
| **听劲** | 通过触觉感知对方力量和意图的能力 |
| **寸劲** | 极短距离内的爆发力，暗劲的基础 |

## 二、训练类

| 术语 | 含义 |
|------|------|
| **站桩** | 国术基本功，通过静态姿势打熬下盘、感受重心和气血 |
| **浑圆桩** | 最常见的站桩姿势，双手环抱于胸前 |
| **三体式** | 形意拳的基本桩功 |
| **单式操练** | 反复练习单一招式（冲拳、劈掌等），形成肌肉记忆 |
| **排打功** | 硬功训练，用器械拍打身体增强抗击打能力 |
| **推手** | 太极拳训练方法，两人在对抗中感受对方力量走向 |
| **走架** | 练习套路的通称 |

## 三、拳种/流派

| 术语 | 含义 |
|------|------|
| **洪拳** | 南方拳术，刚猛霸道，龙虎蛇豹鹤五形 |
| **太祖长拳** | 传自宋太祖的拳法，大开大合 |
| **形意拳** | 五行拳（劈崩钻炮横）+ 十二形，刚柔并济 |
| **太极拳** | 以柔克刚，借力打力 |
| **八卦掌** | 步法灵活，掌法多变 |
| **八极拳** | 刚猛暴烈，"文有太极安天下，武有八极定乾坤" |
| **通背拳** | 放长击远，以柔克刚 |
| **翻子拳** | 快如翻浪，连续攻击 |

## 四、招式类

| 术语 | 含义 |
|------|------|
| **崩拳** | 形意五行拳之一，直拳发力，短促凶猛 |
| **劈掌** | 由上往下的劈击，如刀劈斧砍 |
| **钻拳** | 斜向上的攻击，如毒蛇出洞 |
| **炮拳** | 爆发力最强的拳法之一 |
| **横拳** | 横向发力，破坏对手重心 |
| **缠手** | 以柔克刚的防守反制手法 |
| **靠** | 用肩膀或身体撞击对手 |
| **肘** | 近距离用肘攻击 |
| **膝** | 近距离用膝攻击 |

## 五、其他

| 术语 | 含义 |
|------|------|
| **丹田** | 人体核心，脐下三寸，气血汇聚之地 |
| **气** | 人体内的能量，国术中将气与力结合 |
| **筋膜** | 包裹肌肉的结缔组织，练武到深处可锻炼筋膜发力 |
| **骨膜** | 骨骼表面的膜，明劲锤炼可使骨密度增加 |
| **淬骨** | 通过系统训练增强骨骼强度 |
| **易筋** | 通过系统训练增强筋膜韧性和力量 |
