# 重要配角档案

> 本文档收录主角阵营的核心配角，每位配角有自己的故事弧光。

## 一、师父线

### 陈四海（启蒙师父）
| 项目 | 内容 |
|---|---|
| 身份 | 云游老拳师，形意拳传人 |
| 年龄 | 70 余岁 |
| 境界 | 化劲（隐世高手） |
| 性格 | 豁达、豪爽、深藏不露 |
| 外貌 | 鹤发童颜、身形清瘦、目光如电 |
| 口头禅 | "拳打千遍，其义自见" |
| 故事 | 早年为清廷武举人，因看不惯官场黑暗而隐姓埋名游走江湖 |
| 与主角关系 | 师徒如父子，倾囊相授 |
| 退场时机 | 卷一末尾或卷二初期（战死或归隐） |

> 设计目的：提供前期战力天花板 + 主角情感寄托

## 四、师友线（卷二扩展）

### 周树人（鲁迅原型）
| 项目 | 内容 |
|---|---|
| 身份 | 闰土发小，绍兴周家少爷 |
| 年龄 | 与闰土相仿（开篇约 30 岁，回忆时更早） |

| 设定处理 | 文中以"周先生"称呼，可作为引出闰土身世的引子 |

## 八、配角设计原则

1. **每个配角都要有自己故事**，不能只是工具人
2. **配角也要成长**，不能永远是配角陪衬
3. **必要时让配角退场**，生死无常才真实
4. **避免脸谱化**：即便是反派也要有血有肉
5. **女性角色独立**：不是花瓶，有自己的理想与意志
