# 黄金三章详细细纲

网文的前三章决定了读者的留存率。必须做到：**第一章出危机与金手指，第二章亮肌肉/初尝甜头，第三章打脸立威。**

## 第一章：少年闰土，天道酬勤
*   **核心事件**：主角穿越，接受现实，面临生死/生存危机，激活面板。
*   **场景**：江南绍兴，海边的沙地/西瓜地（月夜）。
*   **剧情发展**：
    1.  **开场切入**：前世散打冠军主角在一阵剧痛中醒来，发现自己手里攥着一柄锈迹斑斑的钢叉，眼前是一只正在逃窜的“猹”。脑海中记忆融合，他震惊地发现自己竟成了鲁迅笔下那个戴着银项圈的苦命少年——闰土。
    2.  **生存危机**：目前的家境极其贫寒，父亲积劳成疾，家里还要缴纳地主赵太爷的高昂地租。如果交不上，自家的几亩薄田就要被收走，全家都要饿死。
    3.  **金手指出现**：主角挥舞了一下钢叉，脑海中浮现出【天道酬勤】面板：
        `[技能]：基础叉法（未入门） 1/100`
        `[状态]：营养不良，暗伤隐患（修复中）`
    4.  **第一章结尾（钩子）**：主角咬紧牙关，利用前世的散打腰马合一的发力技巧，在月夜下开始疯狂练习刺叉。面板熟练度飞速跳动，他感受到身体里涌现出一股微弱但真实的力量。此时，远处传来赵家狗腿子下乡催租的狗吠和嚣张的叫骂声……

## 第二章：腰马合一，狗腿上门
*   **核心事件**：主角初步练成基础武学，冲突正式爆发。
*   **场景**：闰土家破旧的院子。
*   **剧情发展**：
    1.  **练功升级**：经过一夜的苦练，主角的面板提示：`[技能]：基础叉法（入门） 100/100 -> 进阶为【杀伐枪术-刺击】`。主角感受到双臂力量暴涨，前世的格斗意识与这具年轻躯体完美融合。
    2.  **恶人上门**：天亮后，赵太爷手下的狗腿子头目“吴黑狗”（练过几天三脚猫功夫，平时欺男霸女）带着几个人踹开闰土家的院门。
    3.  **压迫与反抗**：吴黑狗嚣张跋扈，看中了闰土家唯一用来抵债的银项圈，不仅要抢走项圈，还一脚将闰土病重的父亲踹倒在地，骂他们是“贱骨头”。
    4.  **第二章结尾（钩子）**：看着倒在血泊中的父亲，主角眼中的杀意再也压抑不住。前世在八角笼里那种凶兽般的气息轰然爆发。他缓缓抄起了墙角那柄带着血槽的钢叉，冷冷地盯着吴黑狗：“你刚才，是用哪只脚踹的我爹？”

## 第三章：钢叉破空，初露锋芒！
*   **核心事件**：第一场高潮打斗，打倒恶霸，收获爽感，确立主角的狠辣人设。
*   **场景**：闰土家院子。
*   **剧情发展**：
    1.  **雷霆出手**：吴黑狗见一个十三四岁的少年敢顶嘴，大怒扑来。主角不退反进，脊椎如大龙弹起，发出一声轻微的脆响（初步摸到明劲门槛的特征）。
    2.  **降维打击**：用现代散打的步伐避开吴黑狗的王八拳，手中钢叉如毒蛇吐信，精准、狠辣、毫无多余动作。一招“进步突刺”，叉尖直接挑穿了吴黑狗的大腿肌肉，将其狠狠钉在院子的土墙上！
    3.  **震慑全场**：其他几个狗腿子吓傻了，谁也没见过平时老实巴交的“闰土”竟然下死手。主角拔出带血的钢叉，眼神冰冷地扫视众人，吓得狗腿子们连滚带爬逃出院子。
    4.  **章末余波/下文铺垫**：主角给父亲包扎伤口，看着带血的钢叉，心中明白：打了赵家的狗，赵太爷绝不会善罢甘休。他必须在赵家报复之前变得更强。同时，村长急匆匆跑来，带来了一个消息：“周家的大少爷（迅哥儿）明天要回乡祭祖了……”引出下文的重磅人物。
