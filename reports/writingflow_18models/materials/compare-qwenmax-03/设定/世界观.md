# 《闰土：国术宗师》世界观设定

## 一、时代背景

### 时间线：1890年 - 1920年

| 年份 | 历史事件 | 故事节点 |
|------|----------|----------|
| 1890 | 光绪十六年 | 主角穿越，少年闰土（12岁） |
| 1894 | 甲午中日战争 | 主角初成，目睹国耻 |
| 1895 | 马关条约签订 | 民族危机加深 |
| 1898 | 戊戌变法 | 主角在上海崭露头角 |
| 1899 | 义和团运动 | 武林动荡 |
| 1900 | 八国联军侵华 | 主角与洋人高手首次大规模冲突 |
| 1901 | 辛丑条约 | 主角实业起步 |
| 1905 | 废除科举 | 主角商业帝国初成 |
| 1911 | 辛亥革命 | 主角暗中支持革命 |
| 1912 | 民国成立 | 主角成为一方巨擘 |
| 1914 | 一战爆发 | 主角趁机扩张实业 |
| 1919 | 五四运动 | 主角名震全国 |
| 1920 | 军阀混战 | 主角走出国门，扬威海外 |

### 社会环境

#### 政治格局
- **清政府**：腐朽没落，对外软弱，对内压榨
- **列强势力**：英、法、德、日、俄等国瓜分利益
- **租界**：洋人的法外之地，主角前期的主要对手
- **革命党**：同盟会等组织暗中活动
- **军阀**：辛亥革命后各地割据

#### 经济环境
- **洋行垄断**：外商控制主要贸易
- **民族工业**：艰难起步，备受打压
- **农村破产**：百姓流离失所
- **买办阶层**：依附洋人的汉奸商人

#### 武林生态
- **传统门派**：少林、武当、形意、八卦、太极等
- **民间武馆**：遍布城乡，但多为花架子
- **洋人武馆**：租界内的西洋拳击、日本柔道馆
- **镖局**：逐渐没落，被洋人的铁路取代

## 二、地理设定

### 主要场景

#### 1. 绍兴（故乡）- 第一卷
- **鲁镇**：主角出生地，鲁迅《故乡》原型
- **赵府**：当地大地主，主角初期对手
- **海边沙地**：闰土家种西瓜的地方，练武场
- **城隍庙**：江湖人聚集地

#### 2. 上海滩 - 第二卷
- **租界**：洋人地盘，主角扬名之地
- **十六铺码头**：帮会地盘，主角收服势力
- **南京路**：商业中心，主角实业总部
- **精武门**：霍元甲创办的武馆

#### 3. 全国各地 - 第三卷
- **天津**：北方武林重镇
- **广州**：南方革命基地
- **武当山**：内家拳圣地
- **少林寺**：外家拳祖庭

#### 4. 海外 - 第五卷
- **日本东京**：挑战日本武道
- **美国旧金山**：唐人街华人势力
- **英国伦敦**：挑战西洋拳击
- **俄国圣彼得堡**：对抗俄国大力士

---

## 三、核心矛盾

### 主线矛盾
1. **民族矛盾**：中华民族 vs 列强侵略者
2. **武林矛盾**：传统国术 vs 西洋格斗/日本武道
3. **阶级矛盾**：底层百姓 vs 封建地主/买办商人
4. **个人矛盾**：主角的现代人思想 vs 旧时代束缚

### 爽点来源
1. **国术碾压**：用中国功夫打败洋人格斗术
2. **商业逆袭**：用现代知识碾压旧时代商人
3. **身份反差**：农民闰土的出身 vs 宗师巨擘的成就
4. **民族自豪**：扬我国威，让列强低头

## 四、特殊设定

### 银项圈的秘密
原著中闰土戴的银项圈，在本书中设定为：
- **来历**：祖上传下的神秘物件
- **功能**：内藏上古国术传承，是开启主角金手指的钥匙
- **秘密**：项圈内藏有一套完整的内家拳功法，以及一份藏宝图

### 鲁迅的角色
- 原著中的"迅哥儿"（少年鲁迅）是闰土的青梅竹马
- 本书中设定为主角的好友，后期成为思想启蒙的盟友
- 鲁迅弃医从文，主角弃农从武，两人殊途同归

## 五、时代细节

### 货币体系
- 1两白银 ≈ 现代300元人民币
- 1块大洋（银元）≈ 0.7两白银
- 普通工人月薪：2-5块大洋
- 主角初期家产：几亩薄田，约值20两白银

### 物价参考
- 一碗面：2文钱
- 一斤米：5文钱
- 一间普通房屋：50-100两白银
- 租界洋房：1000两以上

### 交通方式
- 农村：步行、牛车、轿子
- 城市：黄包车、马车
- 长途：轮船、火车（后期）
