# 《闰土：国术宗师》女主设定

## 一、女主角：沈清韵

### 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 沈清韵 |
| **身份** | 绍兴沈家大小姐（后成为闰氏实业副总） |
| **年龄** | 比主角小2岁（10岁出场） |
| **出场** | 第一卷中期 |
| **特点** | 聪慧过人、商业天赋、温婉坚韧 |

### 外貌描写

```
眉如远山含黛，眸似秋水盈盈。
肌肤胜雪，唇若点樱。
一身淡蓝色旗袍，举手投足间带着江南女子的温婉。
但那双眼睛里，却藏着不输男子的坚定与智慧。
```

### 性格设定
- **聪慧过人**：过目不忘，精通算学
- **商业天赋**：对数字敏感，有经商头脑
- **温婉坚韧**：外表柔弱，内心坚强
- **独立自强**：不愿依附男人，想自己闯出一片天

### 人物弧光
1. **初期**：闺阁小姐，对外界充满好奇
2. **中期**：跟随主角学习商业，成为得力助手
3. **后期**：独当一面的女企业家，闰氏实业的灵魂人物

### 与主角关系发展
| 阶段 | 关系 | 事件 |
|------|------|------|
| 初遇 | 好奇 | 主角救了被恶霸欺负的她 |
| 相知 | 欣赏 | 发现主角的才华和抱负 |
| 相恋 | 深情 | 共同经历生死考验 |
| 相守 | 伴侣 | 成为主角的贤内助和事业伙伴 |

---

## 二、女配角：柳如烟

### 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 柳如烟 |
| **身份** | 上海滩百乐门头牌歌女（实为革命党卧底） |
| **年龄** | 与主角同龄 |
| **出场** | 第二卷 |
| **特点** | 美艳动人、身手不凡、身份神秘 |

### 外貌描写

```
一袭红色旗袍，勾勒出曼妙的身姿。
浓妆淡抹，风情万种。
眼波流转间，能让无数男人为之倾倒。
但若是细看，便能发现那笑容背后的冷冽。
```

### 性格设定
- **美艳动人**：外表是上海滩最耀眼的女人
- **身手不凡**：暗劲级高手，擅长暗杀
- **身份神秘**：革命党卧底，收集情报
- **重情重义**：对革命事业忠心耿耿

### 与主角关系
- **初期**：利用主角完成任务
- **中期**：被主角的人格魅力吸引
- **后期**：成为主角的战友，暗恋主角但不表白

---

## 三、女配角：山田樱子

### 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 山田樱子 |
| **身份** | 日本武道世家之女（后叛出家族） |
| **年龄** | 比主角小3岁 |
| **出场** | 第三卷 |
| **特点** | 武艺高强、性格刚烈、敢爱敢恨 |

### 外貌描写

```
一身白色武道服，英姿飒爽。
面容清秀，却带着日本女子少有的英气。
腰间别着一柄短刀，眼神锐利如鹰。
当她看向主角时，那眼神中既有敌意，也有难以掩饰的倾慕。
```

### 性格设定
- **武艺高强**：化劲级高手，精通日本武道
- **性格刚烈**：宁折不弯，敢作敢当
- **敢爱敢恨**：一旦爱上，便不顾一切
- **叛出家族**：因爱上主角而与家族决裂

### 与主角关系
- **初期**：作为对手挑战主角
- **中期**：被主角击败后心生爱慕
- **后期**：叛出家族，跟随主角

---

## 四、感情线设计

### 主感情线：沈清韵
- **定位**：正妻，灵魂伴侣
- **戏份**：贯穿全书
- **发展**：青梅竹马式，细水长流

### 副感情线：柳如烟
- **定位**：红颜知己，战友
- **戏份**：第二、三卷为主
- **发展**：单恋，成全主角和沈清韵

### 副感情线：山田樱子
- **定位**：侧室（后期）
- **戏份**：第三、四卷为主
- **发展**：从敌人到爱人

---

## 五、感情戏爽点设计

### 1. 英雄救美
- 主角救沈清韵于危难
- 主角救柳如烟于险境
- 主角击败山田樱子后手下留情

### 2. 美人倾心
- 沈清韵被主角才华吸引
- 柳如烟暗恋主角
- 山田樱子叛出家族追随

### 3. 吃醋争风
- 两位女配的良性竞争
- 主角的左右为难
- 沈清韵的大度包容

### 4. 并肩作战
- 沈清韵在商场为主角分忧
- 柳如烟在暗处为主角收集情报
- 山田樱子在明处为主角扫清障碍

---

## 六、感情戏描写要点

### 沈清韵（温婉深情）
```
她轻轻靠在主角肩上，柔声道：
"闰土哥，不管前路多难，我都会陪你走下去。"
主角握住她的手，心中一片温暖。
```

### 柳如烟（暧昧含蓄）
```
她站在灯下，红唇微启：
"闰土先生，奴家有一事相求……"
主角淡淡一笑："柳小姐但说无妨。"
她眼波流转："求先生……平安。"
```

### 山田樱子（刚烈直接）
```
她单膝跪地，将短刀双手奉上：
"闰土君，我败了。按照日本武道的规矩，我这条命是你的。"
主角伸手将她扶起："我不要你的命，我要你的心。"
她脸颊绯红，却倔强地不肯低头。
```
