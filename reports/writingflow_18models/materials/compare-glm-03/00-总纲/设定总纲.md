# 《穿越闰土：国术宗师》设定总纲

## 一句话简介

现代国术爱好者穿越为鲁迅笔下的少年闰土，从月下瓜田起步，练国术、打洋人，在军阀混战、列强欺压的民国初年，一步步拳镇洋场，成就国术宗师。

## 核心设定

| 项目 | 设定 |
|------|------|
| **类型** | 历史·国术·穿越·热血 |
| **篇幅** | 约 100 万字，5 卷 |
| **时代** | 民国初年（1910s-1920s），军阀混战 + 列强租界欺压 |
| **力量体系** | 渐进流国术：前期写实（明劲·暗劲·化劲）→ 后期超凡（丹劲·罡劲） |
| **舞台** | 绍兴乡下 → 上海滩 → 全国 |
| **核心矛盾** | 国弱民贱、洋人横行；以拳立身，以拳卫国 |
| **情感内核** | 闰土原作中"少年英雄→成年麻木"的悲剧宿命，是穿越者要打破的——"这一世，闰土不低头" |

## 基调

热血 + 民族尊严 + 拳理质感。

- 前期（卷一至卷三）：偏写实硬核，拳拳到肉，有门派传承考据感，拳理可推敲。
- 后期（卷四至卷五）：渐入超凡，气血冲霄、罡气破弹，爽感层层递进。
- 全程贯穿：民族气节、师门情义、江湖道义。

## 金手指

**传承手札 + 内视感悟（双线金手指）**

1. **传承手札**：瓜地异变中偶得古武传承手札——一位抗洋义和团老拳师的毕生手记。提供功法来源，并埋下"前辈打洋人未竟之志"的情感主线，天然连接"打洋人"的核心目标。
2. **内视感悟**：穿越带来"内视"能力，能清晰感知自身气血筋骨运行，修炼国术事半功倍、悟性逆天。提供外挂但不破坏写实感——功夫仍要一拳一拳练，只是悟得更快、练得更准。

后期突破超凡（化劲→丹劲）时，手札中隐藏的"以血养劲、罡气化形"秘法成为关键转折。

## 全书卷次一览（100 万字 / 5 卷）

| 卷次 | 卷名 | 境界 | 字数 | 核心事件 |
|------|------|------|------|---------|
| 第一卷 | 月下瓜田起刀兵 | 明劲 | ~15 万 | 穿越获传承，乡下练拳，击退恶霸，立志进城 |
| 第二卷 | 十里洋场试拳锋 | 暗劲 | ~20 万 | 上海闯荡，擂台扬名，初遇洋人欺辱 |
| 第三卷 | 租界风云拳镇洋 | 暗劲→化劲 | ~25 万 | 打洋人主线展开，登擂血战，化劲突破，碎"东亚病夫"牌匾 |
| 第四卷 | 血海深仇丹劲生 | 化劲→丹劲 | ~20 万 | 军阀博弈，日寇阴谋，至亲蒙难，破境超凡 |
| 第五卷 | 罡气横空镇八荒 | 丹劲→罡劲 | ~20 万 | 国难当头，罡劲大成，拳镇八方，护一方百姓 |

**关键转折点**：化劲→丹劲（由实入虚的分水岭）设在第三卷末/第四卷初，约全书 60% 进度处。

## 爽点节奏

- 单章 2000-3000 字，网文标准节奏。
- 每 3-5 章一个小爽点（打脸/扬名/突破）。
- 每卷一个大高潮（境界突破 + 强敌陨落 + 格局升级）。
- 反派梯度：乡间恶霸 → 同行拳师 → 租界洋拳师 → 俄国大力士/日本高手 → 洋人军方/黑龙会宗师。
