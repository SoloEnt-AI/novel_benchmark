# 《闰土拳》— 长篇国术爽文小说项目

> **题材**：清末民初·传统国术·魂穿爽文
> **预计篇幅**：100万字（约280-320章，每章3000-4000字）
> **核心卖点**：鲁迅笔下的闰土重生觉醒，以国术打碎奴性，从绍兴乡村一路打到紫禁城、打到东瀛、打遍东西洋，终成一代宗师。
