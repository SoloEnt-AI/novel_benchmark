# 角色卡

## 一、主角：闰土（章闰水 / 魂穿者陈铮）

### 基础信息

| 项目 | 内容 |
|------|------|
| **本名** | 章闰水（肉身原名）/ 陈铮（穿越前灵魂） |
| **年龄** | 12岁（第一卷开局）→ 38岁（第五卷终局） |
| **外貌** | 紫色的圆脸，头戴小毡帽，颈套银项圈（少年期）；国字脸，目光如电，身形精悍（成年期） |
| **出身** | 浙江绍兴农村，贫苦农民家庭 |

### 穿越前身份

- 姓名：陈铮
- 年龄：28岁
- 职业：自由搏击教练，自幼习练八极拳、形意拳
- 背景：因意外事故身故，魂穿到少年闰土身上
- 性格：热血、坚韧、有正义感，练武时极为专注

### 性格特征

| 维度 | 描述 |
|------|------|
| **核心性格** | 坚韧不服输，有热血但不鲁莽 |
| **成长变化** | 少年时偏冲动 → 成年后沉稳内敛 → 宗师时外柔内刚 |
| **信念** | "人活一口气"，这口气既是个人的尊严，也是民族的脊梁 |
| **软肋** | 对亲人感情极深，见不得弱者受欺 |

### 战斗风格

- **风格**：八极拳的刚猛 + 形意拳的简洁 + 太极拳的圆融
- **标志动作**：铁山靠、崩拳
- **战斗哲学**："能一肘解决的，绝不用第二拳"

### 人物弧光

```
第一阶段（第一卷）
  从"适应穿越、拜师学艺"到"第一次为了保护他人而战"
  关键转变：认出洋人对同胞的欺凌，激发出战意

第二阶段（第二卷）
  从"个人强身"到"为国术正名"
  关键转变：在天津擂台击败英国拳手，打出名号

第三阶段（第三卷）
  从"个人英雄"到"家国情怀"
  关键转变：目睹八国联军暴行，决心以武救国

第四阶段（第四卷）
  从"武者"到"宗师"
  关键转变：融合各家之长，自创拳法，开宗立派

第五阶段（第五卷）
  从"打洋人"到"为民族而战"
  关键转变：认识到一个民族的自强不能只靠拳头
```

## 二、师父：铁臂翁（虚构人物）

### 基础信息

| 项目 | 内容 |
|------|------|
| **本名** | 周铁山 |
| **年龄** | 60余岁（第一卷出场时） |
| **外貌** | 身形干瘦但目光极亮，双手布满老茧，双臂比常人粗壮一圈 |
| **出身** | 原太平天国翼王石达开的亲兵，天京事变后流落民间 |

### 武学

- **主修**：八极拳（已至化劲中期）
- **招牌绝技**："铁臂连环靠"——连续三次铁山靠，一次比一次重
- **教拳理念**："练拳先练人，招式可以学，胆气得自己养"

### 性格

- 外表冷漠严厉，实则护短
- 话少，但每句都在点子上
- 内心深处对国家民族的命运极为痛心

### 剧情作用

- 第一卷引领主角入门
- 在主角出山前赠言："到了外面，记住你是华夏人"
- 第二卷中期在八国联军之乱中为掩护村民牺牲——成为主角彻底觉醒的催化剂

## 三、重要NPC：周树人（鲁迅）

### 基础信息

| 项目 | 内容 |
|------|------|
| **年龄** | 比闰土大几岁，出场时十余岁 |
| **身份** | 绍兴大户人家子弟，后成为文坛巨匠 |
| **与闰土关系** | 少年朋友，一生知己 |

### 在本作中的定位

- **思想引路人**：在主角只懂得用拳头解决问题时，鲁迅提供"笔"的视角
- **精神映照**：一个用笔救国，一个用拳救国，殊途同归
- **重要情节**：
  - 第一卷：少年时的交游，闰土教鲁迅爬树、刺猹，鲁迅教闰土识字、讲外面的世界
  - 第三卷：在日本留学时的重逢，鲁迅的弃医从文对主角产生冲击
  - 第五卷：五四运动中再次相遇，一文一武，共同为民族呐喊

### 性格特征

- 少年时活泼好奇，与后来的冷峻形成对比
- 思想深刻，看问题一针见血
- 与闰土的对话往往成为主角成长的"顿悟点"

## 七、角色核心台词

**闰土**：
- "我不是什么大侠，我就是个种地的，但谁要骑在我华夏人脖子上，我让他尝尝什么叫铁拳。"
- "功夫从来不是为了打架，是为了让不敢打架的人敢站起来。"
- "银项圈是我妈给我套的，保平安。现在我自己的拳头，就是我的银项圈。"

**铁臂翁**：
- "练拳三年，打人只需一下。你练的不是拳，是胆。"
- "这世道，有枪的怕不要命的，不要命的怕有功夫的。"

**鲁迅**（对闰土）：
- "我以笔为刀，你以拳为剑。咱们兄弟俩，各走一路，但去的是同一个地方。"

## 八、角色创作原则

1. **所有角色服务于主题**：每一个角色都在回答"什么是民族尊严"这个问题
2. **反派不脸谱化**：洋人反派也应有其"合理性"，但最终被主角以实力和信念击败
3. **成长线清晰**：每个重要角色在故事中都有变化
4. **对话有辨识度**：通过语言风格区分角色
