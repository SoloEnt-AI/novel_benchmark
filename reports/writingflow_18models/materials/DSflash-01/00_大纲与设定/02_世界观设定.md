# 世界观设定

## 时代背景

### 时间跨度

- **开始**：1893年（清光绪十九年）
- **结束**：1919年（民国八年，五四运动）
- **核心时间段**：约26年

### 关键历史节点（融入剧情）

| 时间 | 历史事件 | 对剧情的影响 |
|------|----------|-------------|
| 1894年 | 甲午战争 | 刺激主角决心练武强国 |
| 1898年 | 戊戌变法 | 主角接触维新思想 |
| 1900年 | 义和团运动、八国联军 | 主角正式入世参战 |
| 1901年 | 《辛丑条约》 | 主角看清列强本质，确立信念 |
| 1905年 | 同盟会成立 | 与革命党接触 |
| 1911年 | 辛亥革命 | 时代大潮下的选择 |
| 1915年 | 二十一条、新文化运动 | 思想觉醒，与鲁迅重逢 |
| 1919年 | 五四运动 | 最终高潮，新旧时代的交接 |

## 地理舞台

### 核心区域

| 地点 | 重要性 | 剧情作用 |
|------|--------|----------|
| **绍兴（浙江）** | 主角故乡 | 第一卷主场，学艺、初战 |
| **天津** | 北方武学重镇 | 与各路高手交锋 |
| **上海** | 洋人租界聚集地 | 擂台战、与列强正面冲突 |
| **北京** | 政治中心 | 参与历史大事件 |
| **东北** | 日俄势力角逐 | 后期战场 |

## 势力设定

### 华夏本土势力

| 势力 | 态度 | 与主角关系 |
|------|------|-----------|
| **清廷** | 腐败无能，洋人走狗 | 前期对立 |
| **义和团** | 排外但盲目，有真功夫者 | 亦敌亦友，短暂合作 |
| **革命党** | 救国图强，开明进步 | 后期盟友 |
| **各地武馆** | 守旧传承，门户之见 | 从竞争到认可 |
| **底层百姓** | 受压迫，渴望英雄 | 主角的保护对象 |

### 洋人势力

| 势力 | 代表 | 威胁等级 |
|------|------|----------|
| **英国** | 拳击手、商人、驻军 | 前期主要对手 |
| **法国** | 传教士、租界势力 | 中期对手 |
| **日本** | 武士、间谍、浪人 | 后期最强对手 |
| **德国** | 军事教官、力士 | 穿插对手 |
| **八国联军** | 联合军事力量 | 第二卷终极冲突 |

## 社会风貌

### 阶层状况

```
皇帝/皇族 → 洋人（实际特权阶层）
    ↓
官僚/买办（洋人代理）
    ↓
地主/乡绅
    ↓
商人/手工业者
    ↓
农民/苦力（闰土的出身阶层）
```

### 文化氛围

- 西方文化冲击：教堂、西式建筑、洋货涌入
- 传统文化坚守：武馆、私塾、宗族
- 新旧交替：剪辫子、放足、新式学堂

## 武学世界观

### 国术在这个世界的定位

- **真实存在**：国术高手确实存在，但数量极少
- **传承隐秘**：真功夫多在民间隐世传承，不轻易示人
- **衰落之兆**：火器兴起，国术走向衰落——这正是主角要改变的趋势
- **国之瑰宝**：在洋人面前，国术是最后的文化尊严防线

### 武者的社会地位

- 民间尊重，但官方轻视
- 洋人畏惧又鄙视——畏惧功夫的威力，鄙视"东亚病夫"的标签
- 主角的目标：用拳头让洋人从鄙视变为敬畏
