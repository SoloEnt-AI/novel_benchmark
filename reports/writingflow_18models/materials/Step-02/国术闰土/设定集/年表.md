# 《国术闰土》年表（1905-1927年）

## 小说情节与历史事件对照

### 1905年（光绪三十一年）——第一卷·觉醒
| 时间 | 历史事件 | 小说情节 |
|------|----------|----------|
| 1月 | 日俄战争结束，日本胜 | 日本势力渗透东北，为后文日本反派埋线 |
| 6月 | 清末废除科举制度 | 农村读书人出路断绝，闰土父亲希望儿子学武 |
| 9月 | 五大臣出洋考察宪政 | 官府腐败加剧，教会勾结官府欺压百姓 |
| 秋 | 义和团余波未平 | 村里老人讲述义和团故事，闰土萌生反抗意识 |
| 冬 | **主角穿越** | 现代形意拳宗师魂穿为17岁闰土 |
| 冬 | 绍兴严冬，大雪封门 | 母亲病重，闰土为母求医，初遇游方郎中（形意拳隐士） |
| 冬-春 | 闰土拜师学形意拳 | 每日凌晨站桩，打五行拳，基础打好 |

|------|----------|----------|

## 四、家族/门派传承时间轴

```

  └─ 戴龙邦（清初）

```
