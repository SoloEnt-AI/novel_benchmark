# 一句话卖点与核心设定

## 书名备选
- 主用：《魂穿闰土》
- 备选：《闰土扛鼎》《国术：从闰土开始》《粗人》《从乡土打到租界》

## 一句话卖点
魂穿闰土，以传统国术明暗化劲为刃，从绍兴乡土一路打到租界洋场，专治欺压百姓的豪绅与洋人。

## 作品定位
| 项 | 内容 |
|----|------|
| 体量 | 约 100 万字 |
| 类型 | 魂穿 + 传统国术 + 清末民初 + 热血爽文 |
| 视角 | 第三人称主视角（偏闰土） |
| 节奏 | 快，小高潮密，压抑不过三章 |
| 文风 | 略带乡土质感，动作干净，情绪热，少灌水 |

## 核心设定（默认方案，可改）

### 1. 穿越方式
- **魂穿**：现代格斗爱好者 / 体育生魂（有基础身体认知，非全能科学家）
- **承接身体**：少年闰土（约 16–18 岁，尚在「银项圈记忆」与「中年苦相」之间，筋骨未废，可练拳）
- **记忆**：保留闰土原身记忆与乡土人脉，叠加现代人的尊严感、卫生观、战术意识

### 2. 金手指（默认 B+A 混合）
- **主**：一部残篇《混元桩劲谱》（托名古拳师手抄，实为本地硬门+形意崩拳思路），分九层，练一层开一层注解
- **辅**：现代人对「发力、呼吸、训练周期、营养、对抗」的科学直觉 → 表现为「悟性逆天」
- **不做**：聊天系统、商城、无敌光环；保持年代感

### 3. 主题
- 表层：升级打脸、护短、打洋人
- 里层：被命运按在地上的人，用拳头和骨气把自己拔起来
- 口号级主题：**人穷志不能短，国弱拳不能软**

### 4. 主线驱动
乡里活路被断 → 习武自保 → 踩乡绅教民 → 撞上洋人爪牙与治外法权 → 成名于武林码头 → 租界夺气 → 国术成为一面旗

### 5. 感情线（默认）
- **一条正经线**：后期再浓，前期点到为止
- 人选倾向：县城药铺女 / 武馆师妹型（能治伤、通消息、不花瓶）
- 不写后宫，不让感情线盖过打脸与家国

### 6. 开书第一枪（默认）
- 先写乡土：粮租、孩子受辱、原本身份的窝囊
- **第 1 章内**完成穿越清醒 + 第一次「忍不了」
- **第 3–5 章**第一次用拳头改小局
- **第 10 章前后**扯上教民/洋人影子

### 7. 读者承诺（每卷都要兑现）
1. 国术有谱，不是喊口号
2. 打脸有观众，有身份落差
3. 洋人能杀，但有代价、有反噬
4. 乡土子弟有血有肉，不是背景板

## 禁区与尺度
- 不美化列强；反派可精明，不可写成「文明导师」
- 暴力热血可写，避免无意义虐杀成瘾
- 历史大事件作舞台，不考据绑架；关键年份在时间线文档中统一
