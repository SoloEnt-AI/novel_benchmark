# 11 - 写作流程与日更计划

## 一、日更流程

### 每日写作流程（日更2章，约6000-7000字）

```
┌─────────────────────────────────────────────┐
│  写作前准备（30分钟）                         │
│  ├── 回顾昨日写的2章，检查衔接                │
│  ├── 查看今日细纲，明确2章的核心内容           │
│  └── 确认人物状态、时间线、伏笔进度            │
├─────────────────────────────────────────────┤
│  第1章初稿（90分钟）                          │
│  ├── 快速写完，不纠结细节                     │
│  ├── 保持节奏感，一口气写完                   │
│  └── 目标：3000-3500字                       │
├─────────────────────────────────────────────┤
│  休息（15分钟）                               │
├─────────────────────────────────────────────┤
│  第2章初稿（90分钟）                          │
│  ├── 同上                                    │
│  └── 目标：3000-3500字                       │
├─────────────────────────────────────────────┤
│  修改润色（60分钟）                           │
│  ├── 通读2章，检查逻辑漏洞                   │
│  ├── 润色战斗描写、对话                       │
│  ├── 检查爽点是否到位                         │
│  └── 确认结尾钩子是否有效                     │
├─────────────────────────────────────────────┤
│  记录与规划（30分钟）                         │
│  ├── 更新进度表（写了哪些章、到哪里了）        │
│  ├── 记录伏笔使用情况                         │
│  └── 预览明天的细纲内容                       │
└─────────────────────────────────────────────┘
```

**总用时：约5小时/天**

## 二、写作前自检清单

### 每章开写前检查
- [ ] 本章的核心事件是什么？（一句话概括）
- [ ] 本章的爽点/钩子在哪里？
- [ ] 主角在本章的状态（境界、情绪、处境）？
- [ ] 与上一章的衔接是否自然？
- [ ] 有没有需要回收的伏笔？
- [ ] 有没有需要埋设的新伏笔？

### 每章完成后检查
- [ ] 字数是否达标（3000-3500字）？
- [ ] 开头200字是否有吸引力？
- [ ] 结尾200字是否有钩子（悬念/转折/爽点）？
- [ ] 战斗描写是否有感官细节+心理活动+武学原理？
- [ ] 人物对话是否符合各自的语言风格？
- [ ] 节奏是否合适（快/中/慢）？
- [ ] 有没有逻辑漏洞？

### 每卷完成后检查
- [ ] 卷末是否有大高潮？
- [ ] 境界提升是否合理？
- [ ] 人物成长弧线是否完整？
- [ ] 伏笔是否全部回收？
- [ ] 与下一卷的衔接是否顺畅？
- [ ] 整体节奏是否张弛有度？

## 五、常见问题应对

### 卡文怎么办？
1. **回看细纲**：细纲已经规划好了每章的核心事件，照着写就行
2. **先写战斗**：如果日常戏卡文，先跳到战斗场面写（战斗最容易写）
3. **写对话**：让人物对话推动剧情，对话写起来快
4. **换场景**：当前场景卡了就切到下一个场景
5. **降低标准**：初稿不需要完美，先写完再改

### 节奏拖沓怎么办？
1. **检查是否有连续3章以上的纯修炼/日常**→ 插入冲突
2. **检查是否有"水字数"的描写**→ 大刀阔斧删减
3. **每章问自己：这一章推动了什么？**→ 没推动就重写
4. **参考爽点频率表**→ 该出现爽点了吗？

### 人物OOC（Out of Character）怎么办？
1. **回看人物设定卡**：每写一个主要角色前，快速扫一眼设定
2. **核心性格锚点**：
   - 闰土：沉默+果断+护短
   - 迅哥儿：聪明+敏感+正义
   - 苏婉清：聪慧+善良+有主见
   - 刘振东：豪爽+直率+重义气
3. **如果一个角色说了不符合性格的话**：删掉重写

### 数据不好怎么办？
1. **前30章是关键**：如果前30章数据不好，考虑调整开头
2. **检查爽点密度**：前10章每章至少一个小爽点
3. **检查节奏**：读者最容易在"纯修炼"章节流失
4. **增加冲突**：如果太平淡，加入更多反派和冲突

## 七、AI辅助写作建议

### 可以用AI辅助的环节
1. **战斗描写扩展**：给出关键动作，让AI扩展成完整的战斗场景
2. **历史细节查询**：清末民初的服饰、饮食、建筑、风俗
3. **国术术语解释**：形意拳、八卦掌的具体招式描述
4. **对话润色**：让对话更符合人物性格和时代背景
5. **章节大纲细化**：将单元大纲细化为章节大纲

### 不建议用AI的环节
1. **核心剧情走向**：必须自己决定
2. **人物关键决策**：必须符合人物设定
3. **爽点设计**：需要作者对读者心理的把握
4. **整体节奏**：需要通盘考虑

### AI辅助写作流程
```
作者定方向（细纲）→ AI扩展细节 → 作者审核修改 → 成稿
```
