# 01 - 核心设定

## 一、穿越设定

### 穿越者身份
- **前世**：陈远，28岁，现代退伍特种兵+业余武术爱好者（练过形意拳三年）
- **穿越原因**：执行任务时意外身亡，灵魂穿越到平行世界的清末
- **穿越时间点**：1896年（甲午战败后第二年），闰土14岁
- **穿越地点**：浙江绍兴海边农村（鲁迅故乡原型）

### 闰土原身情况
- **年龄**：14岁，正处于鲁迅笔下"少年闰土"时期
- **家庭**：父亲章福庆，靠种地+打鱼为生的底层农民
- **身体素质**：常年劳作，身体底子好，但营养不良，偏瘦
- **社会地位**：最底层的农村少年，"忙月"（帮工）的孩子
- **与迅哥儿**：此时迅哥儿尚未去南京读书，两人仍是玩伴关系

### 穿越优势（金手指）
1. **现代格斗知识**：特种兵近身格斗技巧+三年形意拳底子，虽在国术世界只是入门，但提供了现代格斗思维
2. **历史先知**：知道未来20年的重大历史走向（甲午→戊戌→庚子→辛亥），可以提前布局
3. **"拳意感知"**：穿越后获得的特殊能力——能"感知"到武学招式中的发力规律和破绽，如同天生的武学奇才。不是数值面板，而是一种直觉，越修炼感知越敏锐
4. **坚韧意志**：特种兵的心理素质，面对生死搏杀不怯场

### 金手指限制
- 拳意感知只对"看到的、接触过的"武术有效，不能凭空悟道
- 需要大量实战来磨练，闭门造车无法突破
- 身体素质需要从头锻炼，不能一步登天
- 现代格斗技巧在国术体系中只是"术"的层面，真正高深的"道"需要从头领悟

## 二、世界设定

### 时代背景
故事开始于1896年，甲午战败后第二年。清廷丧权辱国，民间弥漫着屈辱与愤怒。洋人在华横行霸道，教会势力渗透乡村，买办阶层崛起。

### 关键历史节点（故事时间线）
| 年份 | 历史事件 | 故事对应 |
|------|----------|----------|
| 1896 | 甲午余波，马关条约 | 开篇，闰土觉醒 |
| 1897 | 德国强占胶州湾 | 闰土初入江湖 |
| 1898 | 戊戌变法/百日维新 | 闰土接触维新派 |
| 1900 | 庚子国变/八国联军 | 第一次大战，拳打洋人 |
| 1901 | 辛丑条约 | 闰土创建武馆 |
| 1904 | 日俄战争 | 东北线展开 |
| 1905 | 废除科举/同盟会成立 | 闰土接触革命党 |
| 1911 | 辛亥革命 | 参与推翻清朝 |
| 1912 | 民国建立 | 新篇章开始 |
| 1915 | 二十一条/新文化运动 | 国术vs国运 |
| 1919 | 五四运动 | 收官高潮 |

### 地理舞台
- **第一卷**：绍兴农村 → 绍兴城
- **第二卷**：上海 → 天津 → 北京
- **第三卷**：全国各地（山东、河北、广东）
- **第四卷**：上海（主力）+ 全国
- **第五卷**：上海 + 海外（日本、东南亚）

### 势力格局
1. **清廷**：腐朽但仍有实力，慈禧掌权
2. **洋人势力**：英法美德日俄等列强，在华享有特权
3. **教会**：传教士+信教的中国教民，鱼龙混杂
4. **买办阶层**：依附洋人的中国商人
5. **国术界**：各门各派，武林规矩
6. **维新派**：康有为、梁启超等
7. **革命党**：孙中山领导的反清力量
8. **义和团**：民间排外力量（后期）

### 社会规则
- 洋人在中国享有治外法权，杀了中国人不受中国法律制裁
- 传教士可以庇护教民，形成"国中之国"
- 传统武人地位不高，但民间武术传承不断
- 武林有"以武会友"的传统，但也有门户之见

## 三、核心冲突

### 主线冲突
**个人层面**：闰土从底层少年成长为国术宗师的逆袭之路
**家国层面**：以国术之力对抗列强，维护民族尊严
**思想层面**：国术能否救国？武力vs制度，哪种才是出路？

### 爽点设计原则
1. **打脸爽**：洋人/买办瞧不起中国人 → 闰土一拳打爆
2. **逆袭爽**：所有人觉得闰土不行 → 闰土力挽狂澜
3. **装逼爽**：低调出场，实力碾压，众人震惊
4. **家国爽**：在洋人面前为中国人争光，打出国术威名
5. **成长爽**：每一次突破境界都带来质的飞跃
